Context-Matched Distillation

让教师的“打分上下文”与学生的“生成上下文”严格对齐 —— 面向自回归视频蒸馏的教师因果性
Hmrishav Bandyopadhyay, Xuanchi Ren, Zijian Huang, Jay Zhangjie Wu, Tianshi Cao, Ruilong Li, Bryan Chu, Sanja Fidler, Yi-Zhe Song, Zian Wang
论文 PDF · 项目主页

交互式自回归视频生成需要低延迟与在线可控。少步蒸馏（few-step distillation）解决了延迟， 但主流的 DMD 蒸馏管线存在一个被长期忽视的结构性缺陷：学生是因果的，教师却是双向的。 教师在给第 t 帧打分时能看到 t 之后的帧和控制信号 —— 而这些信息在学生真正生成该帧时根本不存在。CMD 用一个因果教师替换双向教师， 并进一步用 Prefix Scoring 把打分上下文对齐到「学生当时真正用的那段历史」， 用 Prefix Corruption 稳定训练早期的不可靠 rollout。

一句话总结

DMD 的梯度是 (sreal − sfake)。 以往工作只关心「学生怎么采样」，CMD 指出「教师在什么信息集上求这个分数」同样关键—— 把教师的信息集从「整段 clip」收缩到「学生生成该 token 时真实拥有的那段缓存前缀」， 无需改动 DMD 目标本身，就能大幅提升可控性与长程质量。

三个组件，逐层递进

  • Base CMD：因果教师 + block-causal mask，切断未来信息（时间边界对齐）
  • Prefix Scoring：条件换成缓存的学生 rollout 前缀（实际历史对齐）
  • Prefix Corruption：对前缀加噪，抑制早期漂移主导梯度（鲁棒化）
Section 01 · Motivation

核心问题：Teacher–Student Context Mismatch

自回归学生按 pθ(xt | x<t, c≤t) 逐帧生成； 而双向教师在打分时把整段 x1:T 一起看。二者的信息集（information set）不同， 于是「教师告诉学生这帧该长什么样」这句话本身就建立在学生做不到的前提上。

形式化地说：双向教师给出的是全片得分 sreal(x1:T) = ∇x1:T log preal(x1:T | x0=ℐ0, c1:T)， 其第 t 个分量依赖 x>t 与 c>t； 而学生生成 xt 时只有 ht = (x<t, c≤t)。 CMD 直接把教师的打分改写为逐帧因果形式：

sreal,t(xt, ht) = ∇xt log preal(xt | ht),    ht = (x<t, c≤t)

并让 sfake 在同一个信息边界上求值，从而得到逐帧的分数差 sreal,t − sfake,t。 DMD 更新的形式完全没变，变的只是「在哪儿求分数」。

为什么这在相机控制上尤其致命

双向教师看到整条相机轨迹。它可以用「后面镜头要右转」来解释当前帧的内容， 于是给出的分数隐含了未来位姿。而部署时学生只知道当下这一条指令 —— 监督信号从一开始就无法执行。

为什么这在长视频上尤其致命

长 rollout 中，双向教师把每个局部窗口当作自包含的 clip 打分： 既丢掉了产生该窗口早期帧的前置 rollout 上下文，又允许这些早期帧去注意窗口内的后续帧。双重错配。

Section 02 · Preliminaries

预备知识：DMD、自回归分解、Diffusion Forcing

三块拼图撑起了 CMD。如果你已熟悉，可直接跳到方法流水线。

① Distribution Matching Distillation (DMD)

DMD 把多步教师蒸馏成少步学生 Gθ，方式是让学生分布 pfake 逼近教师分布 preal。 它不直接算 KL，而是用两者score function 之差作为分布差异的代理：

∇θ ℒDMD = −𝔼x∼pfake [ ( sreal(x) − sfake(x) ) dGθdθ ] (1)

记号约定：s(x) 表示在加噪版本 xτ = (1−τ)x + τ·ε（ε∼𝒩(0,I)，τ∈[0,1]）上求的 score，为简洁省略了时间步。

关键观察：式 (1) 只规定了「在学生样本上求分数差」，并没有规定教师必须以什么条件求这个分数。 这正是 CMD 切入的缝隙。

② 自回归视频生成的因式分解

记 I2V 潜变量序列 x ≡ x0:T，其中 x0 = ℐ0 是输入图像的 latent， c1:T 是逐帧控制（如相机运动）。

Chunk-wise（块自回归）：把生成 latent 与控制切成 N 个对齐的块 B1:N、C1:N，每块 K 帧：

pθ(B1:N | ℐ0, C1:N) = ∏i=1N pθ(Bi | ℐ0, B<i, C≤i) (2)

块之间是因果的，块内部的帧可以双向交互。K=1 退化为逐帧自回归：

pθ(x1:T | x0=ℐ0, c1:T) = ∏t=1T pθ(xt | x<t, c≤t) (3)

论文强调：输入图像 ℐ0 被当作普通的因果历史，而不是永久保留在局部注意力窗口之外的特殊 token。

③ Diffusion Forcing

Diffusion Forcing 训练因果序列模型时，对每一帧独立采样噪声等级，让模型在「历史本身是带噪的」条件下去噪当前帧。 这样模型在推理阶段面对自己生成的、不完美的历史时更鲁棒 —— 正是自回归 rollout 的常态。CMD 用它来预训练因果教师。

Section 03 · Method Overview

方法流水线：一个模型家族，贯穿三个阶段

CMD 最优雅的一点是结构上的一致性：因果教师训练 → 学生初始化 → 蒸馏打分 → 推理， 全程使用同一套因果架构与条件方式。没有「双向教师 + 因果学生」的接缝， 也不需要额外的 ODE-matching 或 consistency distillation 阶段来初始化学生。

加一个新的控制信号（比如相机）时，传统做法要分别适配一个双向条件教师和一个因果学生。 CMD 只需要训练一个因果条件教师，学生直接从它初始化 —— 少了一套需要单独适配的模型，也少了一处错配来源。（论文只做了这一定性陈述，未量化成本。）

4.1 因果教师预训练：把双向模型改造成 Diffusion-Forcing 因果模型

给定真实视频 latent x0:T（x0=ℐ0 保持干净）， 对每一帧独立随机采样噪声等级加噪；block mask 限制目标帧 t 只能看到 ht = (ℐ0, x̃1:t−1, c1:t)。 用标准 flow-matching 损失训练：

ℒDF = 𝔼 ‖ vt − ηφ(xt,τ, τ, ht) ‖22,    vt = (ε − xt) (4)

学到的 flow field ηφ 按 DMD 中标准的 flow ↔ score 关系换算后，即可用作因果 score sreal(xt,τ, τ, ht)。

4.2 Base CMD：先把时间边界对齐

学生从教师权重初始化，按推理时的方式做 on-policy rollout（backward simulation，同 Self-Forcing）： x̂0=ℐ0，逐帧生成 v̂t,τ = Gθ(x̂t,τ, τ, ht)（历史 latent 从梯度图上 detach）。 每个生成目标 x̂t 被加噪成 x̂DMDt,τ， 然后在 block-causal mask 下由因果教师与 fake-score 网络打分。此时打分上下文为：

hCMDt = ( ℐ0, { x̂DMDi,τ }i=1t−1, c1:t )

✔ 未来帧与未来控制被 mask 挡住了。
✘ 但条件是「之前那些加噪的 DMD 目标」，而不是学生生成当前帧时真正用过的那段历史。

4.3 Prefix Scoring：再把「真实历史」对齐

在 on-policy rollout 过程中，缓存下每个目标所依赖的生成历史 x̂<t 与控制 c≤t。 打分时，冻结的因果教师与 fake-score 网络都用这段缓存前缀作为条件：

ht = ( ℐ0, x̂1:t−1, c1:t )  ⟹  sreal(x̂DMDt,τ, τ, ht),   sfake(x̂DMDt,τ, τ, ht)

效率上的关键设计：朴素实现需要为每一帧单独跑一次教师前向。CMD 的做法是 把输入图像与学生生成帧作为「条件记忆」一并送入，配合 block-causal mask 让每个打分 query 只注意到它自己的因果前缀 —— 于是所有目标在一次教师前向中并行打分（类似 Teacher Forcing 的打包方式）。

4.4 Prefix Corruption：给「不可靠的早期 rollout」上保险

少步学生在刚初始化时会剧烈漂移。如果教师严格地在这些严重 OOD 的伪影上求条件分数， 这些伪影会主导训练信号。CMD 因此对条件前缀注入高斯噪声，降低教师对颜色/纹理类漂移细节的敏感度：

h̃(ρ)t = ( ℐ0, 𝒞ρ(x̂1:t−1), c1:t ),    𝒞ρ(x̂1:t−1) = (1−ρ)·x̂1:t−1 + ρ·ε,   ε∼𝒩(0,I) (5)

最终的 Prefix Scoring DMD 目标：

∇θ ℒDMD = −𝔼x̂DMDt,τ, τ [ ( sreal(x̂DMDt,τ, τ, h̃(ρ)t) − sfake(x̂DMDt,τ, τ, h̃(ρ)t) ) dGθdθ ] (6)
容易读混的两点

① Prefix Corruption 扰动的是 on-policy 前缀，不是 Base CMD 里那条「加噪 DMD 目标」序列；
② 前缀噪声用独立的噪声等级（由调度器时间步 tprefix 决定 ρ）， 与目标侧随机采样的 DMD 时间步 τ 解耦 —— 它只调节「上下文有多可信」，不改动目标侧的 DMD。

Section 05 · Extension A

扩展一：长视频的 bounded prefix

学生和因果教师共用同一个局部注意力窗口。设学生保留 M 帧历史， 则 t > M 时学生在 hMt = (x̂t−M:t−1, ct−M:t) 下生成第 t 帧 —— CMD 让教师在完全相同的窗口下打分。

训练配置与 ρt 调度

  • 训练 (RT+1) 帧的视频：R 段连续 rollout，每段生成 T 帧， ℐ0 只出现在第一段。每段结束后其生成帧被缓存为下一段的上下文， 因此靠近段边界的帧其上下文会跨段包含前一段的帧。
  • 缓存帧同时提供局部注意力上下文与（如适用）sink token，学生与因果教师共享这份缓存。
  • 长视频训练把固定的 ρ 换成随帧位置变化的调度 ρt： 早期帧漂移尚小 → 弱腐蚀；后期帧 rollout 误差累积 → 强腐蚀。
  • 把 score-distillation 损失施加到 R 段中的每一帧， 即可监督完整因果轨迹，而每个目标只需注意 bounded prefix。 视频变长 = 增加待打分的 rollout 段数，而不是扩大教师的注意力窗口 —— 这是它能 scale 到任意长度的原因。

Section 06 · Extension B

扩展二：相机条件的因果蒸馏

相机控制是「上下文错配」暴露得最彻底的场景。CMD 的处理分两步： ① 采用 frame-relative 相机参数化；② 让教师只看到 ≤t 的位姿。

帧相对位姿 + ray map

设 Et ∈ SE(3) 为第 t 帧的 camera-to-world 位姿， Kt 为内参。CMD 把轨迹转成帧间增量：

ΔEt = I,   t = 0
E−1t−1 Et,   t > 0 (7)

再对每个 latent 空间位置 (u,v) 用 Kt 反投影出射线、 用 ΔEt 变换，得到与视频 token 空间对齐的 ray 嵌入：

ct = Φt(u,v) = φ(ΔEt, Kt, u, v) (8)

这种表示保留了指令相机运动的局部几何，同时摆脱了对任意全局坐标系的依赖。

论文强调的关键区分

即使用了相对相机表示，只要把整条轨迹交给双向教师，第 t 帧的分数依然可能依赖 Φ>t —— 教师可以用「后面还要往右转」来解释当前帧。 相机表示的选择与教师的因果性是两个正交的问题，必须同时解决。 消融（Table 6）也证实：ray map 在两个 split 的全部 VBench 指标、平移误差与 CamMC 上优于 PRoPE（旋转误差除外 —— Simple split 上 PRoPE 的 1.2546 反而低于 ray map 的 1.3675），而两种表示下 CMD 都显著优于双向打分。

Section 08 · Ablations

消融分析：增益到底来自哪里

短视频：因果打分贡献了绝大部分增益

从双向打分换到 Base CMD，Total +5.68（82.65 → 88.33）—— 这是全文最大的单一增益， 说明「教师是否因果」比后面所有精修都重要。 在 Base CMD 之上，默认的 prefix-conditioned 模型再提升 Total +0.13、Camera Motion +2.98、Dynamic Degree +5.85。

一个反直觉但很关键的结果

单加 Prefix Scoring（干净前缀，tprefix=0）反而不如 Base CMD：Total 从 88.33 掉到 87.25。 也就是说「让教师看到学生的真实历史」本身并不自动带来提升 —— 因为那段历史在训练早期充满漂移伪影。 必须配合 Prefix Corruption 才能把这条路走通，而且腐蚀强度存在最优点（tprefix=256）： 更弱（128）或更强（512）在 Camera Motion 上都更差。

PS = Prefix Scoring；PCk = Prefix Corruption 且 tprefix=k。Full CMD = PS + PC256。数据来源：论文 Table 4。

长视频：跨段前缀带来额外收益

Base CMD 相对双向打分 Total +3.39；Full CMD（教师收到与学生相同的 bounded 跨段前缀）相对双向打分 Total +4.04、Semantic +0.58。

相机控制：表示与因果性各自的贡献

  • Ray map 表示下：Base CMD 相对双向打分 Quality +0.0216 / +0.0192（Simple/Hard），并降低全部相机误差。
  • 再加缓存前缀：Total 再涨 +0.0313 / +0.0319，主要由 Semantic 大幅提升（+0.1377 / +0.1369）驱动； Simple split 上相机误差进一步下降，但 Hard split 上 Base CMD 的相机误差反而更低。
  • 整体上 ray map 优于 PRoPE：两个 split 的全部 SANA-WM VBench 指标、平移误差与 CamMC 都更好。

Section 09 · Discussion

要点、边界与我的一些保留

值得记住的三点

  1. DMD 里「教师条件」是一个被低估的设计维度。 过去的改进大多集中在学生侧：怎么初始化（ODE matching、consistency distillation）、怎么采样（self-forcing）。 需要公允地说明：Causal Forcing 与 Causal Forcing++ 已经用因果教师来初始化学生（论文 §2 亦如此陈述）， CMD 的真正区分点是用同一个因果教师同时承担初始化与带因果前缀的 DMD 打分。 在这个前提下，CMD 把注意力转向对称的另一半 —— 教师在什么信息集上求分数 —— 并显示这同样值数个点。 需要注意的是，论文没有报告这一改动的成本（延迟、显存、相对逐帧打分的加速比都缺失）； 它支持的是两个较弱的陈述：block-causal 打包让一次教师前向替代逐帧前向，以及教师注意力窗口不随视频变长而扩大。
  2. 因果性应当贯穿整条链路。 教师训练、学生初始化、蒸馏打分、推理使用同一套因果结构，消除了「双向教师 + 因果学生」的接缝， 顺带省掉了 ODE-matching / consistency-distillation 的初始化阶段。
  3. “对齐真实历史” 需要配套的鲁棒化。 Prefix Scoring 单独使用会被早期漂移反噬；Prefix Corruption 不是可选装饰，而是让这条路可行的必要条件。

我在读的时候留意到的几处保留

  • Dynamic Degree 的对比需要小心解读。短视频上 CMD chunk-1 的 DD 是 48.21， 明显低于 Causal Forcing 的 87.15；而长视频上 CMD 的 DD 又远高于 LongLive/Rolling Forcing。 DD 本身不是「越高越好」的单调指标（画面乱动也会拿高分），跨方法比较时它更像一个需要配合视觉检查的诊断量， 而非可直接排序的质量指标。论文用它来说明基线「几乎不动」是合理的，但反过来也提醒：CMD 在短视频上的 DD 并不领先。
  • chunk-1 与 chunk-4 在 Semantic 上的巨大差距（0.2413 vs 0.1810，相机 Simple split）缺少解释。 同一方法两个 chunk 设置之间相差 0.06 以上，比多数方法间的差距还大；论文没有分析这个现象的来源。
  • Prefix Corruption 引入了新的超参敏感性。tprefix 在 128/256/512 之间的 Camera Motion 分数分别是 56.15 / 63.64 / 55.75 —— 最优点附近相当尖锐，说明这个超参需要针对新任务重新搜索。 论文也没有给出 ρ 与 tprefix 的换算关系。
  • Hard split 上的不一致。加入缓存前缀后，Simple split 相机误差全面下降， 但 Hard split 上 Base CMD 仍保持更低的相机误差 —— 前缀条件在困难轨迹下是否总是有益，还没有结论。
  • 缺少速度/显存的定量报告。论文强调 block-causal mask 让所有目标能在单次教师前向中打分， 但没有给出相对 per-frame 朴素实现的实测加速比，也没有报告推理延迟（这对「交互式」这个卖点其实挺重要）。
  • 基线的复现口径。多个 T2V 基线是通过「把首个生成帧替换为输入图像」适配到 I2V 的， 这种适配对基线是否公平（尤其是 I2V Consistency 类指标）值得留意。
一句话收尾

CMD 的贡献不在于某个新模块，而在于把一个一直存在却被默认接受的错配指出来， 并给出一个不改动 DMD 目标本身的修法：让教师只在学生当时真正拥有的信息上说话。
