Hai Nguyen-Truong¹ · Tuan-Anh Vu² · Dang Huynh¹ ¹ Fulbright University Vietnam · ² UCLA arxiv.org/abs/2608.29904

视频生成器"知道世界长什么样，但不可靠地知道世界怎么动"。OMR 的做法是：在流匹配 ODE 采样的中段若干步，把当前的干净隐变量估计 ẑ1 送进一个 33.3M 的小适配器，直接映射到 V-JEPA 2.1 的嵌入空间，用冻结预测器的"惊讶能量"求梯度，并把它从生成器速度中减掉。生成器和世界模型都不训练，全程不解码到像素、不跑 V-JEPA 编码器。

01 问题与现有路线

生成器学会了"看起来像"，没学会"动起来对"

Wan2.2、Cosmos 这类生成器画面质量很高，但 VideoPhy-2 等基准反复显示：物体反重力漂浮、液面失去连续性、手穿过本该抓住的物体、碰撞时没有形变/碎裂/反弹。论文的诊断很直接——标准流匹配 / 去噪目标只拟合视觉统计量，从不显式惩罚物理违规。于是模型能学到世界长什么样，却不一定学到世界怎么行为。

论文用图 1 的后空翻例子把这个缺口具体化：基线每一帧单看都合理，但落地序列里身体姿态突变、腿部运动不连贯、气垫对冲击没有响应——这类时间上的物理错误从单帧质量看不出来。OMR 瞄准的正是"生成轨迹内部的局部物理交互"，而不是画面打磨。

02 核心赌注

同样一份世界模型信号，花在样本完成之前，而不是之后

论文把自己和"验证器/奖励"路线的对照总结成一个问题：候选选择让世界模型去评判完成的视频，每多用一次物理信号就要多生成一整条视频；OMR 问的是——能不能在轨迹还可以移动的时候就把这份信号花掉？

做法是给标准 ODE 步加一个力：生成器速度 uθ 照常算，再叠加 V-JEPA 2.1 惊讶能量在适配器空间里的梯度。这个梯度不必与生成器的向量场对齐——它可以把隐变量从物理上不合理的未校正轨迹上推开，之后生成器再从校正后的状态继续"渲染"。这就是标题里的 off-manifold refinement。

03 背景

两个基本件：流匹配的"干净时间"，与 V-JEPA 2.1 的惊讶能量

3.1 流匹配与隐式干净预测 ẑ1

全文用干净时间 t：t = 0 是纯噪声，t = 1 是干净视频隐变量。生成器学的是一个速度场 uθ(zt, t)，把隐变量沿噪声→视频的路径搬运：

dztdt = uθ(zt, t),  t ∈ [0, 1]
(1)

同一个速度场还给出对最终干净隐变量的估计：从任意中间状态 zt 出发，按常速外推到 t = 1 会落在哪里：

ẑ1(θ)(zt, t) = zt + (1 − t) · uθ(zt, t)
(2)

这个 ẑ1 就是 OMR 施加世界模型校正的对象——注意它不是当前的噪声状态，而是"生成器此刻认为最终会生成什么"的估计。这个选择在第 6 节会再次出现：它是缓解适配器分布偏移的第一道措施。

3.2 V-JEPA 2.1 作为视频世界模型：预测性"惊讶"

V-JEPA 2.1 有一个编码器 Eφ 和一个预测器 Pφ；预测器的训练目标是从可见上下文 token 预测被遮蔽的未来 token 的嵌入。OMR 从每条 81 帧视频里取一个 48 帧窗口打分。记 e = Eφ(v)，C 为可见上下文 token，M 为被遮蔽的未来目标，δM 为携带时空位置的可学习 mask token：

Evjepa(v) = ‖ Pφ(eC, δM) − eM ‖22
(3)

能量低 = 在一个用真实视频训练出来的表征里，"未来"能从"上下文"里预测出来。三个对 OMR 至关重要的性质：它是稠密的（逐 patch，而不是一个标量分数）、可微的，并且只依赖嵌入本身，不依赖嵌入是怎么来的——最后这一点正是适配器能够替换编码器的前提。

04 方法核心

OMR 更新规则：一步 Euler，外加一次能量梯度的减法

标准 ODE 采样只积分生成器速度：

zt+Δt ← zt + Δt · uθ(zt, t)
(4)

OMR 在满足 η(t) > 0 的被调度步上，先用式 (2) 算出 ẑ1，再用适配器 Aψ 把它直接映射进 V-JEPA 2.1 的嵌入空间：

e = Aψ(ẑ1) ∈ ℝN×D,  N = Ttok Hp Wp
(5)

推理时适配器完全取代编码器 Eφ，只跑预测器 Pφ。把适配器输出的 token 重排成 V-JEPA 2.1 的网格，套用同样的 48 帧窗口与 mask，得到推理时的预测能量及其对干净预测的梯度：

EOMRvjepa(ẑ1) = ‖ Pφ(eC, δM) − eM ‖22,   g(zt, t) = ∇ẑ1 EOMRvjepa(ẑ1)
(6–7)

关键约定：把 ẑ1 当作引导变量，不对生成器速度网络 uθ 反向传播。也就是说 uθ 只负责提供 ODE 速度，∇ẑ₁E 只负责在同一坐标系里提供一个局部修正；一次 autograd 只穿过 Pφ 和 Aψ。最终的更新是：

zt+Δt ← zt + Δt · uθ(zt, t) − η(t) · g(zt, t)
(8)

论文把校正写成 Euler 速度更新之后的一个算子分裂步：步长对引导的影响被吸收进标定过的标量 η(t)，等价地也可以参数化为 η(t) = Δt·λ(t)。

交互演示：在一个 2D 玩具空间里看清这一步

这是示意，不是论文数据下面把隐变量空间压成二维：黑色曲线代表生成器 ODE 场偏好的"采样几何"（论文操作性意义上的"流形"），生成器速度把点拉向曲线上离它最近的位置；琥珀色盆地是世界模型认为"物理上可预测"的低能量区域。真实系统是 16×21×60×104 维的隐变量和 13824×6656 的嵌入网格，几何远比这复杂，但一步之内发生的事与式 (8) 完全一致：靛蓝向量是 Δt·uθ，青绿向量是 −η(t)·g。

算法 1：一次完整的 OMR 采样（与上方演示同步高亮）

  1. require 冻结生成器 uθ、冻结预测器 Pφ、冻结适配器 Aψ、干净时间步 0 = t₀ < ⋯ < tN = 1、引导 η(·)、可见/目标索引 C, M、mask token δM
  2. zt₀ ~ 𝒩(0, I)采样初始噪声
  3. for i = 0, …, N−1 do论文设置 N = 40
  4. Δt ← ti+1 − ti
  5. v ← uθ(ztᵢ, tᵢ)生成器速度（照常计算）
  6. ẑ₁ ← ztᵢ + (1 − tᵢ)·v干净隐变量估计；对 uθ 停止梯度
  7. if η(tᵢ) > 0 then只在调度的中段步
  8. e ← Aψ(ẑ₁)适配器取代 VAE 解码 + V-JEPA 编码器
  9. E ← ‖Pφ(eC, δM) − eM‖²masked-future 惊讶
  10. g ← ∇ẑ₁ E一次反向传播，穿过 Pφ 与 Aψ
  11. else
  12. g ← 0其余步只用生成器速度
  13. end if
  14. ztᵢ₊₁ ← ztᵢ + Δt·v − η(tᵢ)·g带引导的 Euler 步
  15. end for
  16. return ztN之后才做唯一一次 VAE 解码

相对标准流匹配 ODE 求解器，OMR 增加的只有：一次适配器前向、一次预测器惊讶评估、一次梯度计算、一次减法。没有内循环、没有重加噪、没有 mask 混合、没有候选池。

05 命名

为什么叫"off-manifold"？

论文很谨慎地把"流形"限定为操作性简称：指冻结生成器 ODE 场在局部偏好的采样几何，而不是声称某个速度向量张成了形式化数据流形的切空间。

对比两种精修方式：生成器内部的精修（例如再去噪一次、自洽地重采样）沿着这个学到的几何走，因为它问的还是生成器自己；OMR 对一个独立训练的世界模型的适配器空间预测损失求导——这个梯度不是生成器的似然分数，所以它不必与未校正轨迹对齐。在这个操作性意义上，更新是"离开流形"的；而之后的生成器速度会从被校正的隐变量继续渲染。

论文第 3.3 节给出机制上的解释：V-JEPA 2.1 的预测器是在真实视频上学会"从可见上下文预测被遮蔽未来"的，这相当于一个关于合理时间延续的先验——物体应当持续存在、运动应当平滑、接触应当产生一致的后续效应。当生成器提出的未来片段在这个先验下"接不上"上下文时，Pφ(eC, δM) 与 eM 分离，能量上升。因此 g 不是一个泛泛的"画质梯度"，而是在生成器隐变量坐标下、最能降低世界模型预测分歧的局部方向。方法并不是用 V-JEPA 2.1 取代生成器，而是给生成器自身的动力学加一个小的外部物理先验。

流形内

生成器自精修（P&P 等）

再次询问同一个生成器：扰动、重去噪、比较样本间分歧。方向来自 uθ 自己，天然沿着学到的几何。

离开流形

OMR

方向来自另一个模型（V-JEPA 2.1 预测器）的预测损失，经适配器折回隐变量坐标。它可以把点推离生成器此刻的轨迹。

再渲染

之后的步

被推开后，生成器继续用 uθ 从新状态积分。校正只是"改了起点"，画面仍由生成器完成。

06 让梯度可算

latent → embedding 适配器：整个方法的承重墙

朴素地计算 g 需要：把 ẑ1 经生成器 VAE 解码成像素 → 经 V-JEPA 2.1 编码器 → 算能量 → 反向穿过两者。论文给出的硬约束：仅一个 16 帧 480×832 片段的 VAE 单次反向传播，就超出单张 96 GB GPU 的显存。适配器 Aψ：Zlat → Zvjepa 离线学一次，把生成器隐变量直接映射到"编码器本来会从解码像素产出的"嵌入空间，同时短路解码与编码。

6.3 训练目标：三项损失，各自守住一件事

训练数据：OpenVid-1M 约 64,000 个片段的子集。对每个片段缓存 Wan2.2 VAE 隐变量与冻结 V-JEPA 2.1 编码器目标，然后只在这些张量对上训练。适配器不被训练去生成像素或评判视频质量——它只被要求复现"冻结编码器在解码同一隐变量后本来会产出的表征"。记目标 e ∈ ℝN×D、预测 ê = Aψ(z)，每个 token 做 L2 归一化（ ēi = ei / (‖ei‖₂ + ε) ）：

Ladapter = 1N D ‖ ê − e ‖22 + 0.5 (1 − cos(ê, e)) + 0.1N2 ‖ Sim(ê) − Sim(e) ‖1
(11)
项 1 · 坐标

逐元素均方重建

让每个 token 的坐标落到编码器目标附近。这是主导监督。

项 2 · 方向

逐 token 余弦对齐

cos(ê, e) = (1/N) Σi ē̂i⊤ēi，系数 0.5。保证方向对，不只是模长对。

项 3 · 关系几何

token–token 相似度矩阵匹配

Sim(e)ij = ēi⊤ēj。无标签的关系蒸馏：保住哪些时空 patch 相近、哪些相远、上下文与未来如何相对排布。系数很小（0.1/N²）——它是稳定器，不是另一个物理奖励。

为什么第三项非有不可OMR 把适配器输出直接喂给冻结预测器。若真编码器把"运动物体的 token"放在其未来延续附近、远离静态背景，适配器也必须保住这种关系；否则预测器会看到一个人造的上下文–未来失配，产出误导性的惊讶梯度——那就不是物理信号，而是适配器的伪影。

6.4 真实视频上训练，生成视频上使用：分布偏移怎么处理

主适配器是在真实 OpenVid-1M 片段编码得到的隐变量上训练的，但 OMR 在生成时把它用在从噪声状态 zt 推断出的临时干净预测 ẑ1 上。论文承认这是真实的分布偏移，同时论证它正是预期用法：Aψ 不被要求判断一个隐变量是真是假，只被要求把任意 Wan2.2 隐变量表达到冻结 V-JEPA 2.1 编码器的坐标系里。两道缓解措施：(1) 作用于 ẑ1 而非高噪声的原始 zt；(2) 调度避开 ẑ1 几乎是噪声的早期步。剩下的是经验问题，由下面的保真度检验回答。

07 何时施力

引导调度 η(t)：只在中段的一个时间带内开启

η(t) = η0 · 𝟙[ tlo ≤ t ≤ thi ]
(12)

与基于子步的方法不同，这个调度直接定义在外层 ODE 时间步上；因为根本不存在内层精修循环，也就不存在与内层循环的交互问题。这一点在第 8 节与 P&P 的对比里会再出现。

10 边界与疑问

论文自己承认的局限，以及我读完后仍未解开的问题

10.1 论文明确列出的局限

OMR 继承世界模型的盲点与数据偏差——"预测上可信"不等于"物理上正确"。评估只覆盖一个世界模型家族、两个生成器、以及训练各自适配器时的分辨率；换一个 VAE 隐空间就要重训适配器。400 条结果每条只生成一次；50 条试点是无配对置信区间的单点估计。保真度只证明表征与排序的一致，不证明适配器–编码器等价、原始噪声鲁棒性或因果归属。方法相对基线采样增加了运行时间与显存（Wan2.2：65.4 → 74.1 GB）。未来方向：共享的多分辨率适配器、更长视频、互补的物理预测器、自适应的不确定性驱动调度，以及"OMR + 小额最终选择预算"的组合。

10.2 我在精读中标记的问题

  1. 调度的具体数值缺失。η₀、tlo、thi 只说"在留出标定集上粗扫后固定"，全文没有数字；40 步里到底有几步被引导也未说明（附录 B 只透露每条轨迹取了 4 个引导中段状态）。这是复现最直接的障碍，也影响对 1.71× 的解读——引导步数越少，相对开销越小。
  2. C / M 的 mask 布局未定义。论文说与冻结预测器使用相同的 48 帧窗口与 mask，但没有说明多少 token 可见、遮蔽的是时间上的"后段"还是时空随机块。这直接决定"惊讶"衡量的是什么样的"未来"。
  3. 81 帧与 48 帧窗口的对应关系。适配器把整段 21 个隐时间帧插值到 24 个时间 token，而目标是从 48 帧窗口算出的（48/2 = 24）。48 帧是 81 帧里的哪一段？是否子采样？隐变量全段与窗口目标之间的时间对齐没有交代。
  4. 表 2 中两个面板的 WMReward-∇+BoN-4 相对时间都是 19.88×。不同生成器、不同分辨率下相对时间精确到小数点后两位一致，可能是巧合，也可能是同一测量被复用；峰值显存两行不同（134 vs 83.2 GB）。值得向作者确认。
  5. "每个类别 PC 与 Joint 不下降"成立，但 SA 有下降。重力类 SA≥4 70.0 → 65.0、"其他"68.3 → 67.2。总体 SA≥4 持平是各类别抵消的结果；论文摘要层面的表述没有错，但读者容易把它读成"全面无损"。
  6. 基线选择的力度。Table 1 只与三个冻结生成器方法比；WMReward-∇ 在 Wan2.2 上只出现在 50 条效率子集且只有"+BoN-4"变体，没有单轨迹 WMReward-∇ 行（CogVideoX 面板有）。在 400 条主结果上没有 WMReward-∇ 对照。
  7. 适配器与预测器的输入契约。适配器输出 6656 维（4 层 × 1664）的分层嵌入，而 V-JEPA 2.1 预测器的输入是经过 MLP 降维的多层拼接上下文 token——适配器输出如何变成预测器的输入（是否复用 V-JEPA 2.1 的融合 MLP），论文未展开。
  8. 代码与项目页。论文给出的项目页 itruonghai.github.io/omr 在本页写作时（2026-09-02）返回 404，也未找到公开代码；论文承诺发布 prompt 列表与全部生成片段以供审计。
一句话判断方法本身简洁且动机清楚：把"世界模型梯度引导"里最贵的两个 Jacobian 换成一个离线训练的小映射，是一个干净的工程取舍；适配器保真度实验是论文最有说服力的部分。证据链的薄弱处在样本量（400 条单次生成、50 条试点）和关键超参数未公开；在代码发布之前，1.71× 与 +5.0 pp 应视为"该团队设置下的报告值"。
