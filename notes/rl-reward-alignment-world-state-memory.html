状态记忆

奖励对齐类后训练做到哪一步了：五族奖励来源、它们各自绕开哪个瓶颈，以及为什么「记忆」到现在还基本不是一个奖励项

问题：有没有专门用 RL / 奖励对齐来强化世界模型「记住世界状态」的后训练架构？

结论：有，但只有一族真的在做这件事，而且刚起步。 2025 年 5 月 RLVR-World 把 RLVR 引进世界模型之后，这条线在一年里长出了完整的工程栈——clip 级 rollout、DiffusionNFT、互补奖励、VLM 偏好奖励模型。 但绝大多数方法奖励的是「这一小段有没有跟上动作」和「这一帧好不好看」，两者都是短程代理。 真正把「转一圈回来，原地还对不对得上」写进奖励函数的，到 2026 年 9 月为止只有 WorldCycle 一家（代数循环闭合）， 加上 GrndCtrl 的位姿 cycle-consistency 算半个。 WorldCompass 自己在附录里承认：「缺乏可靠指标来评估视觉漂移与空间记忆保持，因此奖励信号没有直接约束漂移的项」——这就是这条线目前最大的空洞。

为什么难：对任意开放动作序列，长时程的未来没有 ground truth，所以「记忆对不对」本身不可验证。 这道验证瓶颈是整条线的主轴；五族方法的差别，本质上就是五种绕开它的方式。

00TL;DR

一句话结论，和它的三个限定

如果你只想要一个答案：存在这样的后训练架构，代表作是 WorldCycle（arXiv 2608.04964）， 它用「可逆动作循环必须闭合」这条代数恒等式，造出了不需要任何标注、与场景内容无关的长时程可验证奖励。 但下面三个限定决定了你能不能直接用。

限定一 · 可逆性

只覆盖可逆动作
循环闭合的前提是动作构成群：每个 a 有逆 a−1，且 Tγ−1∘γ = I。 相机 ego-motion 满足；物体形变、接触交互、持久状态变化（开门、破坏方块、拾取物品）不满足——WorldCycle 论文自陈这是主要局限。 而「世界状态记忆」在游戏 / 具身场景里恰恰大量是不可逆的那半边。

限定二 · 代理指标

其余方法奖励的是短程代理
RLIR 用 IDM 反推逐帧动作，WorldCompass 用 3D 基础模型估每个 clip 的相机轨迹， WorldReward 用 VLM 判四个动作一块的局部证据。 这些确实能间接改善长程（WorldCompass 长时程基本动作 64.28 → 76.56）， 但它们看不见「刚才那栋楼现在颜色变了」这类漂移。

限定三 · 基准断层

记忆基准还没接进 RL 回路
MBench（实体 / 环境 / 因果一致性，12 个子维度）、MIND、STEVOBench、LoopNav 都已经把记忆量化了， 但没有一篇 RL 论文把它们当奖励用。 唯一自建的是 WorldCycle 的 CycleBench（ESC / RPS / RCS），而它是为自己的奖励量身定做的。 「benchmark → reward」这个接口是现在最明显的空位。

01The verification bottleneck

验证瓶颈：为什么「记忆」不能直接被奖励

RL 后训练需要一个能给 rollout 打分的函数。对语言模型，数学题有标准答案；对世界模型， 「按这串动作走 381 帧之后世界应该长什么样」没有标准答案。这不是工程问题，是结构性的。

WorldCycle 把这件事形式化得最干净。把交互式世界模型看成一个学到的状态转移系统 Mθ = (S, A, fθ)， 真实动作 a 对应变换 Ta，模型实现的是 T̂a。 即使训得很好，每一步也只是差一个残差变换：

残差累积 T̂a = Ta ∘ Ea,   Ea ≈ I   ⟹   T̂γ = (TaT ∘ EaT) ∘ ⋯ ∘ (Ta1 ∘ Ea1) ≠ Tγ 自回归让上一步的输出成为下一步的上下文，所以这些残差不会相互抵消，而是随时程复合。 要直接度量偏差就得知道正确的 Tγ——而对任意动作序列它是未知的。这就是验证瓶颈。

1.1五种绕法，五族方法

既然长程真值拿不到，所有方法都在做同一件事：找一个便宜的、可计算的东西来代替它。这个「代替物」是什么，就决定了它属于哪一族，也决定了它的天花板。

一个容易混淆的边界

有三篇同期工作也用「循环一致性」，但不是 RL，这一页把它们列为对照而不是主线：

  • Cycle-World（2607.11836）——反向预测 cycle consistency 作为可微损失（CCL），外加推理期把冻结反向模型当 runtime corrector 做梯度引导（CGI）。有 Cycle-Bounded Drift 定理。
  • World Models as Group Actions（2605.24578）——identity / inverse / composition 一致性作为latent 空间正则，配合合成监督；提出 GAC / GAR 指标。
  • WorldCycle 自己在附录里写了这个区分：同一个循环结构有三种用法——反向预测正则、群作用正则、自验证奖励函数。只有第三种是 RL。
03Family I · pixel / GT verifiable

族 I：像素 / GT 可验证

这一族只有一篇真正的代表，但它是整条线的起点：RLVR-World（Tsinghua，NeurIPS 2025，arXiv 2505.13934）。 它证明了一件事——世界模型的预测指标本身就可以当 verifiable reward 用，而且效率高得离谱。

做法很直接：把不同模态的世界模型统一成自回归 token 序列（q(s,a) 当「问题」，o(s′) 当「回答」）， rollout 一组，解码回原空间，跟真实的下一个状态算指标，指标就是奖励，GRPO 更新。

  • 语言世界模型：文本游戏状态预测用二值准确率当奖励。R1-Distill-Qwen-1.5B 从 SFT 的 32.87% → 57.01%（二值奖励）→ 63.24%（任务定制奖励）；7B 版本 65.53%，超过 GPT-4 的 64.76%。网页状态预测 F1 49.94 → 65.11（+30.3%），下游 web agent 成功率 12.06% → 14.29%。
  • 视频世界模型：奖励 = −Σ[L1 + LPIPS]。RT-1 机械臂上 LPIPS 相对提升 9.2%，只用了几百步梯度——相比之下 MLE 预训练要几十万步。PushT / Rope / Granular 上超过 DINO-WM。
  • 顺带修好的毛病：多步视频预测里的重复退化（约 20% 的 token 与前一帧相同，模型学会抄近路），重复率 48.6% → 9.9%。

3.1为什么它到长程就不行了

两条硬约束。第一，必须有 GT 未来——这就把它锁死在 teacher-forcing 式的短程预测上，没法评估任意开放轨迹。 第二，后来的 RLIR 做了一次很有说服力的对照实验：把 RLVR-World 的像素奖励（L1+LPIPS）搬到 MineWorld / NFD 上，几乎没有增益（F1 0.70→0.71、0.77→0.77）。RLIR 给了四条解释：

  1. 与预训练目标高度相关——像素级监督跟交叉熵 / flow matching 损失方向一致，策略初始化就在局部最优附近，RL 没有有效探索空间。
  2. 所有像素等权——L1 和 LPIPS 在整帧上求和，但对动作跟随而言只有智能体运动相关的区域重要。
  3. 与生成目标冲突——世界模型必须合成新内容（探索时揭开的区域），那些区域没有确定的 GT，像素奖励反而惩罚合理的多样性。
  4. 易被 hack——RLVR-World 训出的视频整体偏暗，因为后训练数据里有一部分是暗的，模型可以把整帧调暗来刷分。

RLVR-World 论文自己的 Discussion 也点出了同样的方向：现有视觉指标「仍不能完全捕捉用户意图的质量，纳入物理规则与时间一致性这类约束需要更复杂的奖励设计」。这句话基本预告了后面两年的路线。

给你的直接结论

如果你的目标是状态记忆，不要从像素奖励开始。它在有 GT 的短程任务上很强（几百步就超过几十万步 MLE），但它结构上不可能验证长程状态，而且在动作条件的游戏 / 探索场景里已经被两次实验证明不涨。

04Family II · action-inversion verifiable

族 II：动作反演可验证 —— 这条线的工程主干

核心洞察一句话：与其在高维视频空间打分，不如把视频反推回低维动作空间再打分。 一个动作序列可以对应很多合法视频，但所有高质量生成都必须忠实地编码了输入动作。这一族贡献了目前最成熟的工程栈。

4.1RLIR：用 IDM 当验证器（2509.23958，MSRA）

第一篇专门为世界模型的动作跟随能力设计的后训练方法。用一个训好的 Inverse Dynamics Model 把生成视频反推成动作序列 â1..n， 与输入动作逐帧比对，命中记 1，奖励 = 平均命中率，GRPO 优化。IDM 用的是 VPT 预训练模型（2000 小时 Minecraft 视频，按键预测 90.6% 准确率）。

关键在于 IDM 对细微视觉瑕疵极其敏感：论文手工把树干裂纹 P 掉，IDM 就把 attack 误判成 attack,back， 也就是说「视觉退化」会自动转化成「动作不匹配」，一个奖励同时管住了两件事。这解释了为什么 RLIR 在提升 F1 的同时 FVD 和 PSNR 也一起变好。

4.2WorldCompass：把 RL 重新为自回归世界模型设计一遍（2602.09022，ICML 2026 / 腾讯混元）

这是这条线上工程完成度最高的一篇，三个改动全部针对「自回归 + 交互 + 长时程」这三个特性：

改动一

Clip 级 rollout
不对整段视频采样，而是共享前 n−1 个 clip 的前缀，只在第 n 个 clip 上采 G 个候选。 复杂度从 O(N·G) 降到 O(N+G)，同时奖励从「整段一个分」变成「每个 clip 一个分」。 目标 clip 索引 n 按 (k mod N)+1 循环，天然形成课程学习。

改动二

互补双奖励
动作跟随：3D 基础模型估相机轨迹 → 映射到离散动作空间算准确率（旋转阈值 1°，平移用 5 个阈值 [0.01…0.05] 中任一命中即算对，解决尺度不可比）。 视觉质量：HPSv3，每 4 帧采样求均值。两者互为正则。

改动三

DiffusionNFT 而非 GRPO
关键发现：SDE 采样在同一初始噪声上只改变视觉场景，几乎不改变相机运动， 所以 Flow-GRPO 那套探索不出动作多样性。改成从不同初始噪声采样 + 负样本感知微调，直接用 flow matching 目标训。 省掉 KL 项，改用低学习率 + EMA（0.4→0.8 退火）防过优化。
DiffusionNFT 的最优性概率 r(i) = 12 + 12 clip( λa(i)IF + (1−λ)a(i)VQZ, −1, 1 ) 其中 aIF、aVQ 是两个奖励维度各自的组内标准化 advantage。 损失 L = r(i)‖v+θ − v(i)‖² + (1−r(i))‖v−θ − v(i)‖²， 正 / 负速度由 EMA 旧模型与当前模型外插得到。λ = 2/3，Z = 2，β = 1。
WorldCompass 自己承认的局限（附录 A，逐字）

「目前缺乏可靠的指标来评估长视频生成中的视觉质量漂移与空间记忆保持。因此我们的奖励信号缺少直接惩罚这类漂移的约束， 这导致在长时长自回归视频生成上做大规模 RL 训练时会出现累积性的质量退化。我们目前通过更少的迭代次数和更低的学习率这种保守策略来缓解， 但更根本的解决办法需要一个专门评估视觉漂移与空间记忆的稳健奖励函数。」

这段话是整份调研的核心证据：这条线上工程最完整的那篇，明确地说自己没有记忆奖励。后面 WorldCycle 和 WorldReward 都是在补这个洞——一个从代数下手，一个从奖励模型下手。

05Family III · geometry verifiable

族 III：几何 3D 可验证

把「冻结的 3D 基础模型」当验证器：它从生成视频里恢复位姿和深度，这些量满足的几何不变量就是奖励。 与族 II 的差别在于，几何族约束的是结构而不是指令——它问的是「这段视频能不能被重建成一个自洽的三维场景」。

5.1GrndCtrl / RLWG：把 RLVR 搬到几何域（2512.01952，CMU + FieldAI）

论文提出的框架叫 RLWG（Reinforcement Learning with World Grounding），口号很清楚： 「RLVR 把语言锚定在逻辑上，RLWG 把世界模型锚定在几何上」。基座是 Cosmos-Predict2-2B-Video2World，先做 SFT 适配 6-DoF 导航动作，再 GRPO 后训练。 四个奖励全部来自冻结的评估器（MapAnything 给几何，VideoAlign 给感知）：

  • 平移奖励 rtrans：轨迹 MSE + 终点误差平方
  • 旋转奖励 rrot：轴角累积误差
  • 深度时序重投影内点率 rdtr：用 Dt、(ΔRt, Δtt) 把像素投到 t+1，与 Dt+1 比对，相对误差 < 0.0103 记内点
  • 视频质量 rv：VideoAlign 的 visual + motion 各占一半

最亮的结果在 counterfactual 评测上——场景见过、但动作被镜像 / 反向。基座在这里退化严重（SCAND 上平移误差比 Seen 高 70%）， 而 GrndCtrl 在 CityWalk 上把 counterfactual 平移误差从 13.1 m 降到 4.7 m（−64%）。 这是最接近「记忆」的证据：沿反向动作走回去，场景不再漂走。可靠性分析同样说明问题：200 步后平移误差均值降 77%、标准差降 75%——rollout 从「有时对有时崩」变成稳定。

5.2World-R1：不改架构，用 RL 把 3D 先验「唤出来」（2604.24764，MSRA + 浙大，ICML 2026）

另一条路子：不给视频模型加 3D 模块、也不用 3D 数据集，而是相信视频基础模型本身已经隐含编码了 3D 信息，用 RL 把它逼出来。 Flow-GRPO 优化 Wan2.1-T2V（1.3B / 14B），奖励是 analysis-by-synthesis：

  • 把生成视频用 Depth Anything 3 提升成 3D Gaussian Splatting；
  • Smeta：从一个偏离生成轨迹的新视角（meta-view）渲染，让 Qwen3-VL 当图形学专家打 0–9 分。这一项专治「2D 看着合理、3D 一看是纸板」的幻觉；
  • Srecon = 1 − LPIPS(原视频, 重渲染)；Straj 轨迹对齐；Rgen 通用生成质量。
  • 相机条件用 noise wrapping 隐式注入（Go-with-the-Flow），完全不加参数。
  • 周期性解耦训练：每 100 步暂停 3D 奖励，只在「火焰、流水、人群」这类高熵动态子集上用 Rgen 训——防止几何约束把非刚性动态压死。

121 帧长视频上：Wan2.1-T2V-14B PSNR 18.32 → 26.32，LPIPS 0.534 → 0.257。用户研究里几何一致性胜率 92%。 消融值得注意：去掉周期性解耦训练，重建类分数反而更好（PSNR 27.89），但 VBench 掉到 82.64——模型学会了「尽量别动」这种退化解。

几何族的天花板

几何奖励保证的是「这段视频对应一个自洽的三维场景」，不等于「你转一圈回来，那栋楼还是原来那栋楼」。 重建一致 ≠ 内容记忆：一个模型完全可以生成几何自洽但内容被悄悄替换掉的场景，几何验证器不会报警。 GrndCtrl 的位姿 cycle-consistency 是这一族里唯一带闭环味道的项，也是它 counterfactual 收益最大的原因。

06Family IV · algebraic self-verification

族 IV：代数闭合自验证 —— 唯一直接奖励「状态记忆」的一族

WorldCycle（arXiv 2608.04964，HKUST + 武大 + 腾讯视频 AI 技术中心）。 一句话洞察：验证瓶颈有一个结构性例外——可逆轨迹。 Tγ−1∘γ = I 这条恒等式由动作的代数结构完全决定， 与场景内容、初始状态、中间观测全部无关，因此给出了一个精确的、无需标注的长时程验证器。

6.2结果：以及为什么它对 OOD 复合动作特别管用

最值得注意的一个数字

复合动作（前进 + 转向同时按）上，基座 WorldPlay 的准确率崩到 0.136——因为预训练数据里几乎没有复合轨迹的 GT 视频，这是分布外。 WorldCycle 做到 0.553（4×）。关键在于：循环闭合奖励不需要 GT 视频就能优化这些动作——恒等式对任何可逆动作组合都成立， 包括基座根本不会执行的那些。这是「自验证奖励」相对「模仿式监督」最实在的优势：它能训你没有数据的东西。

这一族的边界，说清楚
  • 只覆盖可逆动作。论文自陈：对物体形变、接触交互、持久状态变化，动作序列无法靠施加逆控制回到初态，当前的循环构造不适用。 而世界模型最需要「记忆」的恰恰是这些——你砸掉的方块、你打开的门、你捡起的物品。
  • 点跟踪是代理，不是状态。底层物理状态不可观测，用图像空间的稠密对应位移代替。遮挡、大视角变化、纹理贫乏区域都会让这个代理失真。
  • 长时程 381 帧上绝对值仍然很差。WorldCycle 的动作准确率只有 0.095，基座 0.073，WorldCompass 0.084——三者都接近崩溃。 循环奖励缓解了漂移（ESC 0.302 → 0.163），但没有解决长时程动作跟随。
  • 论文自己指出的方向：把自验证推广到不可逆过程，需要守恒律、等价终态或其他解析可验证的约束。这是这条线最有价值的开放问题。
07Family V · learned reward models

族 V：学习型奖励模型 —— 用 VLM 判官补上「几何看不见的那半」

前三族的验证器都是规则或几何模型，它们能判「相机转对了没有」，判不了「转对了但纹理在往外漂」。 这一族把验证器换成从人类偏好蒸馏出来的 VLM，代价是引入了奖励模型自身的偏差和被 hack 的可能。

7.1WorldReward：本调研里最新的一篇（2609.03952，复旦 + 腾讯混元，2026-09-03）

它明确地把自己定位成 WorldCompass 的奖励替换——基座、训练数据、评测划分、rollout 流程、DiffusionNFT 配置全部不变，只换奖励信号。 这个受控设置让它的结论特别干净。三个设计：

  • 块级证据而非整段视频：把动作轨迹切成每 4 个连续动作一块（前面补一个 idle 槽对应源帧）。 每块给 VLM 六张图：源图（锚定场景身份、检测漂移）、成对帧网格（每个动作的首 / 中 / 末帧）、四张动作级面板（每个动作的首→末帧转变）。 理由很物理：相机动作留下方向特异的视觉证据——前进时可见内容应逐渐放大，上仰时已有内容应向下移、新内容从顶部进入。
  • 一个模型同时输出两个偏好：动作一致性 + 视觉质量，来自同一份证据的同一次推理；块级裁决再投票聚合成视频级偏好。 投票防止单个强 / 弱片段主导整段判断。
  • 数据管线：Gemini 3.1 Pro 块级推理蒸馏 → GPT-5.5 工具型 agent 多轮审计 → 人工定向校准。 消融显示 agent 审计贡献了绝大部分增益（平均 68.69 → 75.94），人工校准再加一点（→ 77.33）。 结果是蒸馏出来的学生超过了两个老师。

08Optimization layer

机制层：rollout 结构、探索源、算法

这一层不生产奖励，但决定奖励能不能有效地传进模型。 对世界模型来说这不是细节——WorldCompass 的消融显示，同样的奖励换个 rollout 结构，结果从 +35 分变成 −7 分。

8.1探索源：三代人的三个答案

GRPO 需要组内多样性。扩散 / 流模型的采样是确定性 ODE，所以「多样性从哪来」是个真问题，这条线上给出了三个不同的答案：

KVPO：唯一把「记忆结构本身」当成 RL 探索维度的方法

KVPO（2605.14278）的 Causal History Routing：sink cache（最早三帧）不动，local cache 固定 9 槽——最后 3 槽永远是最近帧， 前 6 槽从更旧的非 sink 历史里随机重填，每个分支填法不同。初始噪声在所有分支间共享，所以分支之间的差异只能归因于「模型对不同历史上下文的确定性响应」。 消融很干净：扰动 6/9 槽最好（8.14 VQ），扰动 3/9 太少（6.22）、扰动 9/9 破坏了近程时序锚定（6.97）； surrogate policy 用 Trajectory Velocity Energy 而非 latent ℓ₂ 距离：8.14 vs 6.02。

这是一个被低估的方向：如果记忆是 KV cache，那么对记忆做 RL 的最自然方式，就是让策略优化直接作用在 cache 的读取上。 KVPO 用它做偏好对齐，没有用来做记忆一致性——但机制是现成的。

8.2RAVEN：让历史表征本身进入监督

RAVEN（2605.15190，Imperial College）指出了一个「历史监督缺口」： Teacher Forcing 用真实历史（分布不匹配）、Diffusion Forcing 给每个 token 独立加噪（同样不匹配）、 Self-Forcing 虽然用自己的 rollout 当历史，但那份 KV cache 是 detach 的——历史表征不接收来自后续 chunk 损失的梯度。

RAVEN 的做法：把 self rollout 重打包成交错序列 [ẑ(u)1, x̂1, ẑ(u)2, x̂2, …]—— 干净的 rollout endpoint 提供因果历史，同一 rollout 的带噪状态作为被监督的去噪目标，两者在同一次前向里。 于是后面 chunk 的损失可以塑造前面 chunk 的缓存表征，而不必对整条自回归采样轨迹反传。 再配一个 chunk 级损失缩放（future participation score，早期 chunk 权重更大）。

VBench 上 RAVEN 85.15 → 叠加 CM-GRPO 85.46，全部维度都是最高。成本：RAVEN 约 70 H200 GPU-时，CM-GRPO 约 170（LoRA rank 256）。 论文在 Discussion 里明确说：这个交错序列构造不限定历史的形式，滑窗、attention sink、memory token 都能塞进去被端到端优化—— 「把历史处理从固定元素变成可学习元素」。这句话是这一族对记忆研究最直接的接口。

8.3PROWL：反过来做——训一个策略去找世界模型的破绽

PROWL（2605.18803，UCL + Odyssey）不是奖励对齐，而是对抗课程：训一个 KL 锚定的策略去暴露世界模型的高误差轨迹， 世界模型再在这些轨迹上微调（只更新 cross-attention + 动作文本适配器，约 280M / 1.3B），PAT buffer 按 「潜空间 regret + 光流动作保真 AFS + 学习进展 Δ」优先回放。

最有教育意义的是它的失败案例：KL 约束不够强（ckl=0.5）时，对抗策略学会了疯狂甩相机—— 技术上确实可学习，但只是在消耗容量、产生视觉伪影，不产生有用的动力学。论文的结论值得记住： 「高预测误差本身不是有用的奖励信号；对抗方必须暴露世界模型能够有效吸收的失败。」 长时程（18 chunk、10.8 秒）上，LPIPS 相对基座 −6.5%、SSIM +10.9%；而同算力的非对抗微调基线在长时程上几乎没有改善（LPIPS 0.7447 vs 基座 0.7432）。

奖励加权蒸馏 ≠ 在线 RL

还有一批方法把奖励塞进蒸馏损失里：Reward Forcing（2512.04678，Re-DMD 按 VLM 评的动态强度给样本加权，配 EMA-Sink）、 Stream-R1（2605.03849，按 rollout 可靠性 × 时空困惑度双重加权 DMD 监督）、 Reward-Forcing（2601.16933，先用 ODE 轨迹学运动、再用 ImageReward 精修纹理）、 Astrolabe（2603.17051，forward-process RL + 滚动 KV cache 的流式训练）。 它们便宜、稳定，但没有主动探索——RAVEN 的表格里 Reward Forcing 84.39，明显低于带在线 RL 的 85.46。 如果目标是「让模型学会它现在还不会的东西」（比如 WorldCycle 的 OOD 复合动作），加权蒸馏这条路走不通。

09Three empirical laws

三条经验定律（每条都有至少两篇独立复现）

定律一奖励粒度必须匹配「误差在哪里独立」

RLIR 明确提出：人类偏好模型给的是粗到 video 级的奖励，直接套 RLVR 给的是细到 pixel 级的信号，两个极端都次优； IDM 给的是语义对齐的 frame 级奖励，刚好匹配世界模型的训练需求。 WorldCompass 从另一个角度说了同一件事：动作跟随在 clip 之间相对独立，聚合成一个分会让成功与失败互相抵消； 视觉质量有很强的时序依赖，整体分反而能代表整段保真度。

定律二单一奖励必崩，互补奖励互为正则

这条在四篇论文里独立出现，方向惊人地一致：

  • WorldCompass：只用动作跟随 → 动作准确率 36.39 但 HPSv3 掉到 −2.67（基座是 −0.33）， 「视觉保真的退化严重损害训练稳定性，经常导致模型崩溃」；只用视觉质量 → HPSv3 涨到 4.19 但准确率掉到 11.51（基座 64.28），生成静止不动的内容。
  • WorldReward（长时程组合动作）：无奖励 19.70/−0.33；只动作 52.73/0.21；只视觉 27.82/0.89；两者 56.40/1.02。
  • World-R1：去掉 3D 奖励 → PSNR 崩到 18.93；去掉通用生成奖励 → VBench 掉到 83.44。而且去掉周期性解耦训练，重建分数反而更高但 VBench 更低——模型学会了「尽量别动」。
  • GrndCtrl：完整奖励集（T+R+DTRI+V）在三个数据集上都是最均衡的；只加深度奖励会牺牲全局轨迹对齐。

定律三探索必须在流形上，而且要探到「对的维度」

WorldCompass 发现 SDE 采样在同一噪声上「只让视觉场景多样化，相机运动几乎不变」，因此换掉整个算法。 KVPO 从理论角度讲了同一件事：噪声驱动的探索里，样本差异 Δxi0 ≈ ∇xTΦ · (σδi) 与随机种子本身耦合——距离大不代表策略概率低，可能只是采到的噪声幅度大，这会污染真正的策略梯度信号。 RAVEN 则指出 Euler-Maruyama 的随机转移根本不出现在推理用的 ODE 采样器里。 三篇从三个角度指向同一个修法：让探索发生在模型自己的动力学里。

PROWL 提供了这条定律的反面教材：探索方向不受约束时，策略会去找「误差高但学不到东西」的区域（甩相机）。 它的判据借自 Hughes 等人的「新颖性 + 可学习性」标准——无锚定的探索只有新颖性。

13Gaps

缺口与判断

读完这 18 篇之后，我认为下面五个空位是这条线上最值得做的。前两个是接口问题——机器都造好了，只是没接上。

缺口 01 · 接口

记忆基准 → 奖励函数，没人接
MBench（2606.00793）把记忆分解成实体一致性 / 环境一致性 / 因果一致性三个层级、12 个可量化子维度，用规则矩阵 + VLM 评估； MIND（2602.08025）、STEVOBench（2603.13215，视野外状态演化）、LoopNav（2505.22976，空间一致性回环）各自也定义了可计算的记忆指标。 没有任何一篇 RL 论文把它们当奖励用。 而 WorldCompass 缺的正是这个。这是最短路径的工作：把 MBench 的规则型子维度做成可微 / 可采样的奖励，接到 DiffusionNFT 上， 在同一个 HY-WorldPlay 基座上跑一遍受控对比。

缺口 02 · 接口

KV / 显式记忆模块没被 RL 优化过
RAVEN 在 Discussion 里明说：它的交错序列构造不限定历史的形式，中间噪声态、memory token、滑窗、attention sink 都能放进被监督的前向里， 「把历史处理变成 rollout 中可学习而非固定的元素」。KVPO 已经证明了在 KV cache 上做探索是可行且更优的。 而仓库里 Long-Horizon Memory 那一节的一百多篇， 全部是用监督 / 免训练方式设计记忆结构的。 「用 RL 训练记忆的读写策略」这件事目前是空白。

缺口 03 · 理论

不可逆过程的自验证
WorldCycle 自己指出：循环闭合依赖动作有显式逆或解析已知的闭合关系；形变、接触、持久状态变化不适用。 而这些恰恰是「世界状态记忆」最重要的部分。可能的方向（论文提到但没做）：守恒律（质量 / 物体计数 / 拓扑不变量）、 等价终态（不同路径到同一状态应该一致）、以及交换性约束（互不干涉的动作应可交换）。 World Models as Group Actions 的 identity / inverse / composition 三元组是现成的形式化起点，但它是正则不是奖励。

缺口 04 · 度量

没人报「后训练之后记忆变好了吗」
这条线的论文报的是 VBench、HPSv3、动作准确率、位姿误差。 除了 WorldCycle 的 ESC/RPS/RCS，没有一篇在记忆基准上报数。 连 WorldReward 这样明确说自己修好了「时序颜色 / 纹理漂移」的论文，用的证据也是定性对比图 + HPSv3。 结果是：我们不知道现有的 RL 后训练到底把记忆改善了多少，只知道它没变差。 跑一遍 MBench / MIND 就能回答，成本极低。

缺口 05 · 效率

长时程 rollout 的成本墙
WorldCompass 的 clip 级 rollout 把复杂度从 O(N·G) 降到 O(N+G)，这是关键工程突破。 但循环闭合奖励需要完整走完前进 + 反向，重复循环还要乘 K——WorldCycle 靠「每步只采一个层级」把成本压平。 更长的时程（分钟级）上这套还成不成立，没人验证过。 对比一下：GrndCtrl 是 13 帧序列、100–200 步；WorldCycle 是 16 clip；都远短于 Genie 3 那种分钟级交互。

缺口 06 · 收敛

「几百步就收敛」是普遍现象
RLVR-World 明确列为开放问题：「RLVR 收益显著，但训练通常在几百步内收敛；要解锁持续改进，需要更深入地分析模型、数据、算法上的瓶颈。」 RLIR 约 1000 个样本即收敛；WorldCompass 说「在非常少的训练步数内就取得显著提升」。 这可能意味着：当前的奖励很快就被榨干了，而不是模型已经学到头。更丰富的奖励（比如真正的记忆奖励）也许正是打破这个天花板的东西。
如果只做一件事

把 MBench 的实体一致性 + 环境一致性子维度做成可采样奖励，用 WorldCompass 的 clip 级 rollout + DiffusionNFT 流程， 在 HY-WorldPlay 上跑一次受控替换（正好复现 WorldReward 已经建立的实验协议）， 然后在 CycleBench + MBench + MIND 上同时报数。 这个实验能一次性回答两个问题：记忆能不能被直接奖励，以及现有方法的记忆到底改善了多少。

14Decision tree

如果你要自己搭：一个决策树

按照上面三条定律 + 各篇的实测失败案例，把选择压缩成五个问题。

Q1 · 你的动作空间可逆吗？（相机 ego-motion / 导航 = 是；接触、形变、持久状态改变 = 否）
是
走 WorldCycle 路线。构造 γ∘γ−1 闭合循环 + 重复执行，稠密点跟踪做状态代理，spatial 奖励打底、warm-up 300 步后叠加 temporal。这是唯一能直接优化长程状态的路子，而且能训你没有 GT 数据的动作组合。
否
目前没有现成方案。退而求其次：族 II（动作反演）拿短程动作跟随，族 V（奖励模型）拿时序外观一致性，两者叠加。同时考虑推理期的补丁（Cycle-World 的 CGI、RoboAlign-R1 的 SWR）——它们不需要重训。
Q2 · 你有可靠的逆动力学模型 / 3D 基础模型吗？
有 IDM（离散动作，如游戏）
RLIR：逐帧动作命中率当奖励，GRPO。天花板 = IDM 自身精度（VPT 在 Minecraft 上 0.87 F1）。样本效率极高，约 1000 个样本收敛。
有 3D 基础模型（连续相机）
WorldCompass / GrndCtrl：估轨迹 → 离散动作准确率，或直接用位姿 / 深度重投影误差。注意平移尺度不可比——WorldCompass 的做法是多阈值任一命中即算对。
Q3 · 你的基座是自回归 / 长时程的吗？
是
必须用 clip 级 rollout。共享前缀只采目标 clip，O(N·G)→O(N+G)，且奖励粒度对上「误差在哪里独立」。目标 clip 索引循环推进形成课程。不要用 sample 级——WorldCompass 实测会把动作跟随训坏（54.82 → 12.45）。
是蒸馏过的少步模型
用 CM-GRPO（策略目标定义在一致性采样核上）或 KVPO（KV 路由探索 + 速度场 surrogate）。不要套 Flow-GRPO 的 Euler-Maruyama——那个随机转移在推理时根本不存在。
Q4 · 用几个奖励？
至少两个，且必须互补
一个管「世界有没有按指令变化」，一个管「画面成不成立」。单目标一定坍缩，方向已被四篇独立验证。合成方式：各自组内标准化成 advantage，再线性组合 + clip 成最优性概率（WorldCompass 式），或按维度分别做 win-rate（WorldReward 式）。
加第三个之前先想清楚
GrndCtrl 的深度重投影奖励强化局部一致但牺牲全局对齐；World-R1 的三个 3D 子项去掉任一个都掉分但方向不同。多奖励的权重方案两篇都列为未解决问题——没有现成的最优配比。
Q5 · 怎么防崩？
算法侧
低学习率（普遍 1e-5）；EMA 旧策略（WorldCompass 用 0.4→0.8 退火，替代 KL）；只在前 60% 去噪步上算似然比（GrndCtrl，省显存也更稳）；时间步子采样 + Best-of-N（WorldCompass 只取 top3 / bottom3，训练开销减半而结果不掉）。
诊断侧
开训前确认基座能产生可区分的好坏 rollout（GrndCtrl：组内方差不足时标准化会把噪声放大成信号）；训练中监控一个 tripwire 指标——PROWL 监控相机动作速度，一旦翻倍就是在甩相机刷分。

15.1速查表

验证瓶颈
对任意开放动作序列，长时程未来没有 ground truth，因此「长程状态对不对」不可直接打分。WorldCycle 用这个词。
ESC / RPS / RCS
CycleBench 三指标：终点状态闭合（终点帧 vs 首帧）、反向路径对称性（镜像帧对平均距离）、重复循环稳定性（跨循环同相位距离）。均用 RoMa 稠密匹配的平均像素位移，越低越好。
clip 级 rollout
共享前 n−1 个 clip 的前缀，只在目标 clip 上采 G 个候选。复杂度 O(N+G) 而非 O(N·G)，且奖励粒度落在「误差相互独立」的层级上。
DiffusionNFT
negative-aware fine-tuning：把组内 advantage 折成一个最优性概率 r，用它加权正 / 负速度目标的 flow matching 损失。不需要似然比，也不需要 KL 项。
CM-GRPO
把一致性采样步写成条件高斯转移核 πθ(z̃(s)|z̃(u)) = N(αsx̂θ, σs²I)，策略目标直接定义在推理时用的那个更新规则上。
CHR
Causal History Routing（KVPO）：sink KV 不动，local 9 槽里后 3 槽保持最近帧，前 6 槽从更旧历史随机重填，构造分支特异的语义上下文。
counterfactual 评测
GrndCtrl 提出：场景见过、但动作被镜像 / 方向反转。用来测「模型是否把几何结构外推到新运动模式」，是最接近记忆的现成评测制度。
RLWG
Reinforcement Learning with World Grounding。RLVR 在语言域把模型锚定在逻辑上，RLWG 在具身域把世界模型锚定在几何与时间不变量上。
