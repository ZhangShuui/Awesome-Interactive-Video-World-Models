TANGO

让扩散模型当自己的裁判：往前多生成一块，检查它预测出来的噪声还像不像各向同性高斯；不像，就说明脚下是死胡同，于是就地搜一条别的路。

这篇论文提出的不是一个新损失，也不是一次新训练。它提出的是一个诊断信号：自回归视频扩散模型在条件序列跑出训练分布时，它预测出的噪声残差会失去高斯性——因为在那些区域，训练目标从来没有约束过它的输出。把这个偏差当成可微的分数，在推理时用 LoRA 做一次带约束的小幅优化，就能把轨迹从死胡同里拽出来。代价是每生成一块画面都要顺带训练一次，端到端慢约 7 倍。

00The whole thing in one figure

一图看懂：多看一步，然后就地改权重

自回归视频扩散的正常循环是「读 KV cache → 去噪出下一块 → 写回 cache」。TANGO 在「写回 cache」之前插了一个回路：拿还没定稿的 x̂₀ⁱ 当条件，让冻结的自己再往前试一块，把试出来的噪声残差丢进四项统计检验；检验分数对 LoRA 参数 φ 可微，于是反传、更新、重出一版 x̂₀ⁱ(φ)，这一版才是真正写进 cache 的结果。

一句话 · 问题
自回归模型只被教过「给定真实历史，接下一帧」。推理时历史是它自己造的，越走越不像训练数据，最后崩。
一句话 · 新诊断
已有方法都在保证每一帧像真的。作者说：每帧都像真的也不够——存在「本身合法、但接不下去」的状态，即终点。
一句话 · 新手段
模型在没学过的条件下，预测出的噪声会失去高斯性。把这份偏差当损失，推理时小幅改权重，换一条走得通的路。
01Two ways to drift

两种跑偏方式，这篇只治第二种

长视频自回归生成崩掉这件事，大家都知道。分歧在于为什么崩。作者把原因拆成两条，并且明确说：现有工作全在修第一条，而第一条修到极致也不够。

把这个区分讲得再直白一点。想象模型学过一万段「人在厨房切菜」的视频。生成到第 8 秒时，画面里的人举着刀、身体转了 40 度、锅在冒烟——每一帧单独看都毫无问题，任何单帧判别器都会说「真」。但训练集里从来没有「举刀 + 转 40 度 + 锅冒烟」这个组合往下继续的样本。模型这时只有两个选择：要么原地冻住（于是 dynamic degree 掉到 0.36），要么硬编一个后续（于是画面开始融化）。

作者的正式表述是：真实分布 p(𝒱) 在无限时间视野下，任何前缀都有非空的后续支撑集；但模型学的是有限训练集上的 pD(𝒱)，这个保证没了。于是存在 终点（terminal point）——支撑集内部的「悬崖」。

我的读法：这个概念是有用的，但论文给的形式化撑不住它

严格按定义走，有限训练集的支撑集就是那有限条有限长的轨迹本身：那么每条训练视频的最后一帧都是终点，而任何一个生成出来的连续值帧几乎必然根本不在支撑集里。论证在「经验分布的支撑集」和「模型学到的流形」之间悄悄换了一次概念——后者是被网络平滑过的、大得多的集合，而「模型流形里是否真的存在终点」恰恰是需要证明的那件事，论文是断言的。

这不影响方法能不能用（实验是独立成立的），但意味着第 3.1 节是装饰性的，不是承重的。真正承重的是 §03 那个噪声先验。详见 §10‑D4。

02Play with it

终点到底长什么样：一个可以自己走两遍的玩具

把「学到的流形」抽象成一张有向图：节点是状态，边是「训练数据支持的合法后续」。基线走法只看下一步好不好；TANGO 走法在落脚之前先看一眼「落脚点还有没有出边」，没有就在半径 r 的球里换一个有出边的落点——这个球就是 λreg 那一项。拖动滑块看两者的分岔。

03Where the critic comes from

裁判是怎么凭空长出来的：一条没人约束过的输出

这是全文最漂亮的一步。它没有引入任何新模型，而是指出：扩散模型的训练损失从来没有规定过它在 OOD 条件下该输出什么——那片区域是自由的。既然自由，就会露馅；露的馅正好可以测。

3.1先看训练目标里到底写了什么

前向加噪把真实样本 x₀ 和各向同性高斯噪声混在一起，模型学着把噪声认出来：

(1)(3)xt = αtx₀ + σtε,　ε ~ 𝒩(0, I)　　⟹　　ℒ(θ) = 𝔼t,x₀,ε ‖ εθ(xt, t) − ε ‖² 全局去噪时，测试期 ℒ(θ) > 0 的唯一来源是「模型没学好」。这时噪声预测的统计性质是被训练目标直接约束的。

换成自回归分解，条件里多了一段历史 x⁰<i：

(4)s(xti, t, x⁰<i) = ∇ log p(xti | x⁰<i) ≈ − εθ(xti, t, x⁰<i) / σt 关键：任何 x⁰<i ∉ supp(pD(𝒱)) 的历史，从来没有参与过 ℒ(θ) 的最小化。即使假设无限噪声样本、无限模型容量，εθ 在这些区域依然完全没有定义，可以随便输出任何东西 —— 包括不再像高斯的东西。
核心假设，用大白话

「模型在它熟悉的地方，会老老实实吐出白噪声；在它陌生的地方，吐出来的东西会带上结构。」所以不用外部判别器——让模型自己往前踩一步，看它吐出来的噪声脏不脏就行。

3.2flow matching 下这句话怎么落地（以及一个被掩盖的衰减项）

正文用 score matching 推导，但实现用的是 Wan2.1 的最优传输 flow matching。附录 A1 给了转换：路径是直线插值，模型回归的是速度场。

(A1)(A5)xt = (1−t)x₀ + tε　　⟹　　推出隐含噪声：　ε̂ = xt + (1−t) vθ(xt, t) 代入 v* = ε − x₀ 可以验证这是恒等式：ε = xt + (1−t)v*。所以 ε̂ 只有在 vθ 犯错时才偏离真正的 ε。

于是前瞻残差就是把第 i+1 块的状态喂进去，条件挂上刚生成的候选块：

(A6)r̂i+1 = xti+1 + (1−t) vθ( xti+1, t, {x⁰<i, x̂₀i} )

两边减一下，就能看清这个裁判的灵敏度写在哪里：

ε̂ − ε = (1−t) · ( vθ − v* ) 这一项是我自己推的，论文没写。它说明：flow matching 版本的裁判灵敏度正比于 (1−t)。在块的起点 t = 1（纯噪声）处，系数是 0 —— 无论模型错得多离谱，ε̂ 都恒等于输入的 ε，损失是常数，梯度为零。
一个顺手的重建：这个「高斯性检验」实际上在测什么

论文没说 xti+1 是怎么造出来的（第 i+1 块还没生成，哪来的干净信号去加噪？）。最自然的重建是：从纯噪声 x₁ = ε 出发，用模型自己走一个欧拉步到 xt₂，然后在那里问隐含噪声。代进去算：

ε̂ = ε + (1−t₂) · [ vθ(xt₂, t₂) − vθ(x₁, 1) ]

也就是说，在这个读法下 TANGO 测的其实是模型自己相邻两步的速度预测差——一个关于「它的 ODE 直不直、自不自洽」的量。条件正常时流是直的，两步一致，ε̂ 就是当初抽的那个 ε，四项统计自然全过；条件是终点时速度场前后打架，差值 Δv 带着内容状的低频结构叠到残差上，于是偏度、峰度、谱平坦度同时报警。

这个重建也解释了为什么低频那一项必须单独加（§04）：Δv 是图像内容，能量压在低频；而 r̂ 整体被高频的 ε 主导，不单独看低频就被淹了。作者在 (8) 式的动机里正是这么说的。

但请注意这只是重建。另一个同样说得通的读法是 xti+1 = (1−t)x̂₀i + tε，即「把刚生成的块当作下一块的干净信号去加噪」。两种读法的梯度含义不一样，而论文的记号无法区分。

附录 A1 那句「可以直接 drop-in 替换」并不成立

论文说，flow matching 推出的 r̂ 可以作为正文 εθ 的 drop-in replacement 去喂 ℒ_N。但两者在信息量上并不等价：

  • ε-参数化：εθ(xT, T, hist) 是网络的直接输出，哪怕输入是纯噪声，输出也带满信息，误差 1:1 传递。
  • flow 参数化：ε̂ := xt + (1−t)vθ，在 t=1 处恒等于输入，误差被乘以 0。

两者只有在模型完美时才重合。既然作者只实现了 flow 版本，那么「在哪个 t 上取 r̂」就不是细节而是方法的一部分。

04The four probes, live

四项检验拆开看：哪一项在什么时候报警

ℒ_N 由四块拼成，测的都是「r̂ 还像不像 𝒩(0, I)」，但各管一个方向。下面这个面板是在你的浏览器里真算的：现场生成 64×64 的残差场 r̂ = ε + a·Δv，做二维 FFT，按论文的公式和权重算出每一项。拖 a 就是在模拟「条件序列有多接近终点」。

(5)(6)ℒa = λμ(μr̂)² + λσ(σ²r̂ − 1)²　　　ℒb = λγ μ(z³)² + λκ(μ(z⁴) − 3)² z 是 r̂ 的 z-score。一阶二阶管「整体偏没偏、能量对不对」；三阶四阶管「对不对称、有没有重尾」——重尾正是结构化伪影的签名。
(7)(8)ℒs = λs( 1 − exp(1⁄|F| Σ ln(S(f)+ζ))
1⁄|F| Σ (S(f)+ζ) )²　　　ℒl = λlμ μ((zl)³)² + λlσ(μ((zl)⁴) − 3)² ℒs：白噪声在所有频率上能量相等，功率谱应当是平的；一旦不平，说明残差里有空间相关性，即模型把内容当噪声一起减掉了。ℒl：r̂ 被高频主导，所以再对低通滤波后的版本单独算一次三阶四阶矩。
把 a 拖回 0，看一眼 SFM 的读数 —— 这是我对本文最实在的一条技术质疑

a = 0 时残差就是一份完美的白高斯噪声，按论文的期望，ℒs 应该归零。但读数停在 SFM ≈ 0.56，ℒs ≈ 1.9×10⁻²，而其余三项都在 10⁻⁶ ~ 10⁻⁵。

原因是纯数学的：单次实现的周期图在各频点上近似独立同分布的指数变量，几何均值 / 算术均值 → e−γ = 0.5615（γ 是欧拉常数），而不是 1.0。我按论文的张量尺寸（3×16×60×104）模拟验证过：0.5620 ± 0.0010。

提示：上面的面板是 64×64 的演示；论文的真实张量是 3×16×60×104，那里 ℒa/ℒb/ℒl 在理想点上分别是 1.5×10⁻⁶ / 4.4×10⁻⁵ / 4.9×10⁻⁵，而 ℒs 仍然是 1.9×10⁻²。

后果有两层：（一）目标值错了——把 SFM 往 1.0 推，是在要求周期图的幅度处处相等，那是一个随机相位、恒定模长的信号，恰恰不是高斯噪声；（二）量级失衡——ℒs 在理想点上就比其他三项大 2~4 个数量级，会直接吃掉整个 ℒ_N 的梯度。

现在把上面那个 「功率谱先在 48 个通道上平均」 勾上：SFM 跳到 ≈ 0.99，ℒs 落到 1.1×10⁻⁵，和另外三项刚好同量级。所以我的判断是：作者的实现几乎一定做了这一步平均，而论文的公式 (7) 没写。否则消融表里四项贡献不可能是那种均衡分布。这对想复现的人是决定性的一行代码。

为什么需要低频那一项
按 §03 的重建，叠进残差的 Δv 是图像内容，能量集中在低频（Field 1987 的自然图像统计）。而 r̂ 整体被 ε 的高频主导，直接算矩几乎测不到低频的异常。消融也支持：去掉 ℒl，FVD 从 413.3 涨到 486.3。
但这个理由有个跳跃
Field 1987 说的是自然图像的 1/f 谱。TANGO 的一切计算都在 3D VAE 的潜空间里（8× 空间 / 4× 时间压缩，16 通道）。VAE 编码器本身就有部分白化/去相关作用，潜空间的「低频」没有既定的物理含义。这一项经验上有效（消融摆在那里），但给出的理论依据搬错了地方。详见 §10‑D6。
05The loop, line by line

每生成一块，就地训练一次：逐行点开看

这不是 classifier guidance 那种「加一个梯度项」的便宜做法。它是在推理循环里嵌了一段真正的训练：前向、反传、AdamW 更新、再前向。点任意一行看它在干什么。

(10)𝒥(φ) = 𝔼ε~𝒩(0,I)[ ℒN ] + λreg ‖ x̂₀i(φ) − x̂₀i(θ) ‖²₂ 第二项把搜索拴在原始预测的邻域里，防止优化跑向「让噪声看起来高斯」的平凡解。λreg = 0.9，而所有噪声项的权重是 0.1 ~ 0.2 —— 正则项的权重比任何一个目标项都大 4.5 ~ 9 倍。
一个没写清楚、但会决定复现成败的尺度问题

ℒ_N 的四项都是统计量（均值、方差、偏度、峰度、谱比），天然是 O(1) 的无量纲数，它们的平方偏差在理想点上是 10⁻⁶ 量级。而正则项写的是 ‖·‖²₂ —— 如果这是在 3×16×60×104 ≈ 30 万维张量上的求和，那么 λreg=0.9 会让它比 ℒ_N 大五个数量级，优化等于什么都不做；只有当它是均值平方误差时，0.9 : 0.1 这个配比才说得通。

论文没有写任何一项的归一化约定。加上 §04 那个谱平坦度的量级问题，这两处合起来意味着：照着公式抄，得不到论文的行为。

被优化的是什么
rank-8 LoRA，挂在因果 DiT 的 self-attention 的 Q/K/V 上。lr 2×10⁻⁶，AdamW，梯度检查点省显存。裁判 εθ 全程冻结。
优化多久
B = 10 个噪声向量、batch size 2、1 个 epoch ⇒ 每块 5 个梯度步。B=20 时 FVD 更好（399.4 vs 413.3），作者为了算力选了 10。
论文没说的一件事
φ 在下一块开始时会不会重置回 θ。若不重置，LoRA 本身就成了一条新的累积通道——而这篇论文的主题恰恰是累积误差。见 §10‑D7。
06What actually changed

漂移曲线：它改的不是起点，是斜率

消融表（Tab. 2）里最有信息量的不是哪一行最低，而是每一行随时间怎么涨。把每 3 秒一段的 FVD 画成折线，基线和 TANGO 的差别一眼就出来了：两条线的起点几乎重合，斜率完全不同。

算一下增幅就更清楚：baseline 从 367.9 涨到 715.6（+94%），TANGO 从 365.1 涨到 438.8（+20%）。所以这个方法的作用不是把画质整体提一档，而是把随时间的劣化压平——这跟「避免终点」的叙事是自洽的，也是我认为全文最站得住的一条证据。

但这条曲线同时也戳了论文自己的一句话

1–3 s 段：TANGO 365.1 vs baseline 367.9，差 0.8%；连所有消融变体（除了去掉正则的那个）都挤在 363.7 ~ 380.3 之间。也就是说，按论文自己最细粒度的仪器看，噪声引导在前 3 秒几乎什么也没做。

而附录 A3 用 VBench 得出的结论是「终点在任何时刻都可能出现，不是长视频专属」，依据是 5 s 视频上 TANGO 也领先（0.868 vs 0.836）。两个结论可以并存（不同指标、不同 pipeline：Tab. 2 是 v2v + FVD，Tab. A1 是 t2v + VBench），但论文没有指出这个张力，而是各说各的。我倾向于相信 Tab. 2：它的真正战场在中后段。

读法二 · 动态度的位置
TANGO 的 dynamic degree 0.769，仅次于 CausVid 的 0.872——而 CausVid 的语义分是全场最低（0.794）。锚定类方法（LongLive 0.361 / RollingForcing 0.403）拿稳定性换掉了运动。TANGO 确实同时守住了两头，这是它最有说服力的一格。
读法三 · 「4.8%」的口径
正文说语义分比前 SOTA 高 4.8 个点。但语义列的最高基线是 RollingForcing 的 0.814，0.860 − 0.814 = 4.6。4.8 这个数是相对 LongLive（0.812）算的——即把「前 SOTA」统一钉在总分最高的那个方法上。口径本身可辩护，但与「逐列最优」的直觉读法不一致。
附录 A1 里一个反直觉的非单调，值得警惕

RewardForcing 的 Quality：5 s 0.808 → 10 s 0.807 → 15 s 0.835。Self-Forcing：0.834 → 0.817 → 0.832。视频越长，画质分越高。

这几乎一定是度量伪影：VBench 的 quality 里有 motion smoothness（0.98+）和 temporal flickering（0.99+）这类「越静止分越高」的项，一个崩到几乎静止的长视频反而在这些项上刷分。所以跨长度比较 VBench 总分，本身就不太可靠——这反过来说明 §06 那张 FVD 曲线才是这篇论文更硬的证据，而那张表里没有任何外部基线（§10‑D5）。

08What the ablations really say

消融：四项检验各有贡献，但真正的主角是那个正则项

论文把消融解读成「四项都重要，尤其是高阶矩」。这没错。但同一张表里还藏着一个更大的数字：去掉正则项之后，结果比完全不用这个方法还差 15%。

这说明方法的实质是什么
ℒ_N 提供方向，λreg 提供幅度上限。权重配比（0.9 对 0.1~0.2）也指向同一件事：这是一次被拴得很紧的小幅修正，不是自由的轨迹搜索。论文的叙事（「搜索一条不通向终点的替代轨迹」）比实际做的事听起来更激进。
而这个上限的窗口不宽
λreg：0.1 → 656.5（比基线差）、0.5 → 449.3、0.9 → 413.3、10 → 475.6。一个跨两个数量级只有中间一段能用的超参，而它是在 MSR-VTT 上 5 秒 v2v 调出来的，却用在 15 秒的评测上。迁移性是假设，不是验证过的。
一个我确实介意的表格细节：三处精确到 0.1 的重复值

Tab. 3 的这些格子本应来自互相独立的跑：

  • λσ = 0.01 → 482.8　与　λlσ = 0.02 → 482.8
  • λlμ = 2 → 464.7　与　λlσ = 2 → 464.7
  • λμ = 1 → 449.3　与　λreg = 0.5 → 449.3（后者在 Tab. 3a）

FVD 值域约 400~660，保留一位小数即约 2600 个可能取值；约 20 次独立跑里出现一次碰撞的期望约 0.07 次，出现三次的概率在 10⁻⁴ 量级。三种可能：(a) 实现里 λlμ 与 λlσ 其实绑在同一个「低频权重」上（能解释第二条，解释不了另外两条）；(b) 表格有复制粘贴；(c) 某些行共用了同一次跑。

顺带一提，同一张表里 λκ=0.01 那格写的是「479」而不是「479.0」——小事，但说明这张表是手工拼的。我不认为这动摇主结论（主结论靠 Tab. 1 和 Tab. 2），但超参敏感度这一节的可信度要打个折。

09The bill

算力账：用 1.3B 打到 27B 的分数，代价是推理慢 7 倍

Tab. 4 是这篇论文最好的卖点，也是最容易被误读的一张表。它把 TANGO 放在「把模型做大」的那条曲线旁边比——1.3B + 测试时优化 0.863，对上 27B 的 SVI-2.0-Pro 0.869，而耗时只有五分之一。

粗算一下这 7 倍花在哪
每块 5 个梯度步 × batch 2 ≈ 10 个样本；每个样本要「生成器前向 + 裁判前瞻前向」，再加约 2 倍前向代价的反传 ⇒ ≈ 40 次前向当量，对比正常去噪的 4 步。量级对得上实测的 7.2×（其余差距来自 KV cache 复用与优化器开销）。
一处对不上的数字
附录 A2 说「每生成一 RGB 帧约 900 ms」。15 s × 16 fps = 240 帧 ⇒ 3.6 min，但 Tab. 4 写的是 8.6 min（其 VBench 值 0.863 / 0.827 正好对应 15 s 设定）。要么 900 ms 不含优化，要么两张表不是同一配置。论文没有交代。
最该有却没有的那一列
所有基线都是零额外算力跑的。没有任何一个「把这 7 倍算力花在别处」的对照：更多去噪步、更大 NFE、或者最朴素的 best-of-B。这是我认为全文最大的实验缺口，见 §10‑D1。
10Where I'd push back

我的存疑清单

先说清楚立场：我认为这篇论文的核心观察是真的、也是新的——「模型在没学过的条件下，预测噪声会失去高斯性」是一个干净、可操作、不需要任何额外数据的信号。下面的质疑针对的是论证的完整性和实现的可复现性，不是针对这个想法。按严重程度排序，点开看依据。

D1影响结论没有算力对齐的对照，也没有和任何一个同类 test-time 方法比过▸
事实

TANGO 的推理耗时是基线的 7.2 倍（8.6 min vs 1.2 min），显存 +61%。Tab. 1 里所有基线都是零额外算力跑的。而论文自己在相关工作里引了至少四个测试时方法——Self-Refining Video Sampling [24]（ICML 2026）、Pathwise Test-Time Correction for Autoregressive Long Video Generation [56]、TTOM [44]、test-time alignment [27]——一个都没有进对比表。其中 [56] 的题目几乎就是同一个问题。

为什么要紧

现在无法区分两个解释：(A) 噪声一致性这个信号是有价值的；(B) 在推理时多花 7 倍算力做任何合理的搜索都会涨这么多。

最便宜的反驳实验（作者本可以做）

best-of-B：抽 B 条候选续写，用 ℒ_N 挑最小的那条，一个梯度都不算。这能把「判据是否有信息量」从「优化是否有用」里剥出来。它几乎免费，而且正好复用已有代码。论文里已经有一个提示：B 从 10 加到 20，FVD 从 413.3 降到 399.4——再增加采样就还在涨，这恰恰是 best-of-N 式收益的形状。

我的判断

主结论（能涨分）不受影响；归因（是因为终点避免）没有被证明。

D2影响结论全文的中心假设，从头到尾没有被直接测量过一次▸
假设
for well-modeled future trajectories the distribution of the predicted noise should match the one of the forward noising process.
缺的是什么

一个直接的诊断：把 ℒ_N 分别画在 (a) 真实留出视频的条件序列上、(b) 后来崩掉的生成序列上、(c) 没崩的生成序列上。如果假设成立，三条曲线应该分得很开，而且 (b) 的 ℒ_N 在崩之前就该抬头。哪怕只是一张 ℒ_N-随时间 的折线图，或者一个 AUROC 数字，都能把这篇论文从「有效的启发式」抬成「被验证的机制」。

现在的所有证据都是下游的：FVD 降了、VBench 涨了。但下游改善可以由很多原因造成（见 D1），并不能回推「ℒ_N 确实识别出了终点」。

附带的一个理论隐患

即使在分布内，ℒ_N 也不会是 0——模型永远不完美。论文把目标钉在「完美高斯」上，意味着优化在条件完全正常时也一直在推。没有任何校准（比如「先在真实条件上测出 ℒ_N 的基线水平，只惩罚超出部分」）。唯一拦着它乱动的是 λreg。

D3影响结论谱平坦度这一项：目标值 1.0 是错的，而且量级上会压垮其余三项▸
数学

白高斯噪声的周期图在各频点上近似 i.i.d. 指数分布。SFM = 几何均值 / 算术均值 → exp(𝔼[ln X]) / 𝔼[X] = e−γ ≈ 0.5615，不是 1.0。

我的复核

按论文张量尺寸（T=3, C=16, H=60, W=104）模拟 20 次：逐场 SFM = 0.5620 ± 0.0010。而理想残差下四项损失的量级是

ℒa = 1.5e-06   ℒb = 4.4e-05   ℒs = 1.9e-02   ℒl = 4.9e-05

ℒs 比 ℒa 大 四个数量级，比 ℒb/ℒl 大 两个半数量级。若真按公式 (7) 字面实现，ℒ_N 的梯度基本就等于 ℒs 的梯度，而这个梯度指向一个错误的目标：周期图幅度处处相等的信号是随机相位恒模信号，并不服从高斯分布。

但更可能的真相

如果功率谱先在 48 个（16 通道 × 3 潜帧）实现上平均再算比值，SFM → exp(ψ(48) − ln 48) = 0.9896，ℒs 落到 1.1e-05，和另外三项同量级、配比合理。所以我判断作者的实现做了这一步平均，只是公式没写——(7) 式里 S(f) = |F(r̂)|² 是对单个场写的。§04 的面板可以直接切换两种模式验证这个差别。

对复现者的意思

照公式抄会得到一个既跑偏又压过其它项的损失。这一行必须猜对。

D4影响复现前瞻用哪个去噪时刻 t 没说；flow matching 版在 t=1 处梯度恒为零▸
推导

由 ε̂ = xt + (1−t)vθ 得 ε̂ − ε = (1−t)(vθ − v*)。在块的起点 t = 1（纯噪声）处系数为 0，ε̂ ≡ ε，ℒ_N 变成一个与 φ 无关的常数。

缺口

论文只说「采用四个去噪时刻」，没说裁判站在哪一个上；也没说 xti+1 是怎么构造的（第 i+1 块还没有干净信号可加噪）。我在 §03 给了两种自洽的重建，二者的梯度含义并不相同。

连带问题

附录 A1 称 flow 版可以「drop-in replacement」替换正文的 εθ。不成立：ε-参数化里网络输出直接就是噪声预测，误差 1:1 传递；flow 参数化里误差被乘上 (1−t)。二者只有在模型完美时才等价，而整个方法恰恰建立在模型不完美之上。

状态

代码可以解决这个问题——但摘要说「code is available」，项目页目前写的是 Code soon。

D5影响复现「FVD 降低 28.3%」是相对自家 baseline，不是相对 SOTA，而摘要把两句并排放▸
核对

(576.8 − 413.3)/576.8 = 28.35%，其中 576.8 是 Tab. 2 里的「w/o ℒ_N (baseline)」，也就是 Self-Forcing 本身。13–15 s 段的 38.7% 同理：(715.6 − 438.8)/715.6。数字本身准确。

问题

摘要写的是「achieves a 3.1% absolute improvement on VBench over state-of-the-art, while reducing Fréchet Video Distance by 28.3%」。两句并列，很容易读成两个都是对 SOTA 的。而 Tab. 2 里只有 TANGO 自己的消融：RollingForcing / LongLive / CausVid / RewardForcing 的 FVD 一个都没报。

这不是造假，是口径没写清。但它让「FVD 上也是 SOTA」这个印象缺乏支撑——尤其考虑到 §07 说的，跨长度 VBench 本身就不太可靠，FVD 才应该是这篇的主证据。

D6影响复现「终点」的形式化在支撑集和学到的流形之间换了概念▸
论文的论证

训练集 D 有限 ⇒ supp(pD(𝒱)) ⊂ supp(p(𝒱)) ⇒ 存在 v = {x<i, xi}，xi ∈ supp(pD(xi|x<i)) 但不存在合法的 xi+1。

两个问题
  • 过强的结论：严格按有限集算，supp(pD(𝒱)) 就是那有限条有限长轨迹本身。那么每条训练视频的最后一帧都是终点，而任何生成出来的连续值帧几乎处处不在支撑集里——这个框架下「终点」不再是稀有的陷阱，而是常态，也就不解释任何现象。
  • 概念替换：真正相关的是模型学到的流形（被网络平滑过、大得多的集合），而不是经验分布的支撑集。「模型流形里存在终点」是需要论证的命题，论文是从前者直接断言到后者的。
还缺一个尺度

定义里只有「存在 / 不存在」，没有测度。一个概率极小但非零的续写按定义不算终点，实际效果却和终点一样糟。真正想刻画的多半是「条件密度在某处坍缩得很低」，那是连续的量——而 ℒ_N 恰好也是连续的量。所以方法其实比它的理论更合理。

影响

不影响实验结论。但 §3.1 是装饰性的：真正承重的是 §3.2 那个「训练目标没约束 OOD 输出」的观察，那一段是扎实的。

D7影响复现把自然图像的低频先验直接搬进 VAE 潜空间▸
论文的理由

ℒl 的动机引的是 Field (1987)：真实视觉内容的能量主要在低频。

问题

TANGO 的所有计算都在 3D VAE 的潜空间（8× 空间 / 4× 时间压缩，16 通道，h=60, w=104）。1/f 统计是像素空间自然图像的性质；VAE 编码器为了让潜变量接近各向同性先验，本身就带有部分去相关/白化的作用。潜图的「低频band」没有既定含义，DFT 的坐标轴也不是像素坐标轴。

附带的统计问题

低通滤波会把独立自由度砍掉一大截（按 §04 面板里的 1/8 半径，约剩 1.6%），于是 zl 的三阶/四阶矩估计方差大幅上升：即使残差完美，ℒl 也有一个不可忽略的噪声地板，梯度会很抖。这和 D3 是同构的问题，只是轻一些。

但要公平地说

消融是站得住的：去掉 ℒl，FVD 413.3 → 486.3。所以这一项确实有用，只是给出的理由搬错了地方，正确的解释多半是「低频是 Δv（内容残留）能量所在，而不是自然图像先验」。

D8影响复现LoRA 参数 φ 每块重置吗？没说。不重置的话，它自己就是一条新的累积通道▸
原文
we introduce a set of adaptive parameters φ, initialized with the pre-trained weights θ. At each autoregressive step i, we optimize φ …

「initialized with θ」只交代了最开始；每个新块开始时 φ 是回到 θ 还是接着上一块的结果，全文没有一句话。

两种读法后果完全不同
  • 每块重置：每块 5 个梯度步、lr 2e−6 的更新量极小，方法几乎等价于一个可微的小幅修正算子；也更贵（优化器状态反复丢弃）。
  • 持续累积：20 块 × 5 步 = 100 步的持续漂移。那么这篇治的是「条件序列的累积漂移」，却引入了「模型权重的累积漂移」——需要证明后者不会自己变成问题。
一个间接线索

Tab. 3a 里 LoRA rank 从 8 升到 16 反而变差（413.3 → 425.6）。更大的容量更容易过拟合到「让残差像高斯」的捷径上——这更像是持续累积读法下会出现的现象，但只是猜测。

D9影响复现全文没有一个误差棒；而 Tab. 3 里有三处精确到 0.1 的重复值▸
随机性来源

每块抽 B=10 个噪声向量、AdamW 的更新、生成本身的采样——这是一个随机的推理过程。论文报的是单次结果，没有种子数、没有方差、没有置信区间；LV-Bench 上用来算 FVD 的样本量也没报。

FVD 本身在小样本下偏差和方差都很大，且高度依赖 I3D 特征提取器。在这种情况下把 413.3 与 425.6（rank 8 vs 16）的差异当成结论，是超出了数据的分辨率的。

重复值

λσ=.01 与 λlσ=.02 都是 482.8；λlμ=2 与 λlσ=2 都是 464.7；λμ=1 与 λreg=0.5 都是 449.3。粗估：值域 ~400–660、精度 0.1 ⇒ 约 2600 格，约 20 次独立跑的期望碰撞数 ≈ 0.07，出现三次的概率 ~10⁻⁴。

可能的良性解释：实现里把 λlμ 和 λlσ 绑成了同一个「低频权重」（能解释第二条）。另外两条解释不了。不必上纲上线，但这一节的数字不该被当成精确证据引用。

D10值得留意高斯性是必要条件不是充分条件；真正在兜底的是正则项▸

残差完全可以「统计上像高斯」而内容一塌糊涂——ℒ_N 里没有任何一项关心画面对不对。论文自己也意识到了，所以才有 (10) 式的约束。但证据表明这个约束不是保险丝而是主承重：

  • 权重上：λreg = 0.9 vs 噪声项 0.1~0.2；
  • 消融上：w/o ℒreg 的 FVD 664.2，比完全不用这套方法（576.8）还差 15%。

所以更准确的描述是：ℒ_N 提供一个方向，λreg 决定允许走多远，而后者决定了绝大部分结果。论文标题里的「search for an alternative trajectory」听上去比实际做的事激进不少。

D11值得留意为什么是改权重，而不是改隐变量？没有对照▸

名字叫 noise guided optimization，做的却是在 self-attention 的 Q/K/V 上挂 LoRA 做权重更新。测试时引导更常见、也更便宜的做法是直接优化样本或初始噪声（FreeNoise 一系、test-time noise optimization 一系）——既然 (10) 式本来就用 ‖x̂₀(φ) − x̂₀(θ)‖² 把输出拴住了，直接在输出/噪声空间做约束优化是更直接的路线。

论文消融了 LoRA 的 rank，但没有对照「优化 φ」和「优化隐变量」。权重空间的好处（隐式平滑先验、能改变整个块的生成过程而不只是终点）是可以论证的，但论文没有论证。

D12值得留意超参在 MSR-VTT / 5 秒 / v2v 上调，用在 15 秒 / t2v 的评测上▸

附录 A2 交代得很坦白：λ 们是在 MSR-VTT test split 上、5 秒 v2v 设定下、以最小化 FVD 为目标调出来的，之后不再使用该数据以避免过拟合。这个做法是干净的。

但要注意迁移的跨度：5 s → 15 s、v2v → t2v/i2v/v2v 全都用同一组值。而 §08 显示 λreg 的可用窗口并不宽（0.1 崩、0.5 次优、0.9 最佳、10 明显变差）。在长视频上是否仍然是 0.9 最优，是假设而非结论——尤其是如果 φ 不重置（D8），有效学习率其实随时间在变。

D13值得留意跨视频长度比较 VBench 总分，方法论上不成立▸

Tab. A1 里 RewardForcing 的 quality 从 5 s 的 0.808 升到 15 s 的 0.835，Self-Forcing 也是先降后升。视频越长质量分越高，只能是度量伪影：motion smoothness（0.98+）、temporal flickering（0.99+）这些项对「几乎静止」的视频给高分，而崩坏的长视频往往趋于静止或高度相关。

论文用这张表论证「终点在任何长度都会出现」。结论我信（§06 的 FVD 曲线也不反对），但这张表支撑不了它，而且和 Tab. 2 「前 3 秒几乎无差别」的细粒度证据存在张力。

12Where it sits

谱系与定位：同一个病，五条治法

所有对比方法都从 Wan2.1-T2V-1.3B 出发，差别只在「怎么对付自回归漂移」。把它们按在哪个阶段动手排开，TANGO 的位置就很清楚了。

它真正的贡献
把「OOD 检测」这件事免费地接到了扩散模型自身的训练目标上。不需要判别器、奖励模型或真实视频：训练损失约束了分布内的噪声统计，那么统计失效的地方就是分布外。这个观察本身干净、通用，而且可以搬到其它自回归扩散场景（音频、动作序列）。
它的边界（作者自己说得很诚实）
测试时搜索只能在已学到的流形内找更好的解；流形里没有的东西，搜不出来。Fig. 4 的失败案例是「异域物理」和「纳米生物学」两个冷门题材——画面赏心悦目，但技术上完全错误。作者的结论是「测试时自适应与数据/模型扩展是互补而非竞争」，这个定位我认为是准确的。

C名词对照

终点（terminal point）
本文自创概念：一个位于学到的流形内部、但没有任何合法后续的状态。与「掉出流形」区分开——终点本身是合法的。
噪声一致性（noise consistency）
本文的核心先验：如果条件序列在分布内，模型预测出的噪声残差应当保持各向同性高斯的性质（零均值、单位方差、零偏度、峰度 3、谱平坦）。
隐含噪声（implied noise）
flow matching 模型不直接预测噪声，需从速度场反解：ε̂ = xt + (1−t)vθ。
谱平坦度 SFM
功率谱的几何均值 / 算术均值。1.0 = 完全平坦。注意：单次白噪声实现的期望是 e−γ ≈ 0.56，不是 1.0。
自回归漂移 / exposure bias
训练时喂真实历史、推理时喂自己生成的历史，两者分布不同，误差逐步累积。
注意力 sink / 锚定
RollingForcing、LongLive 等把注意力固定在开头若干帧，以收窄生成流形换取稳定性——代价是动态度下降。
DMD 蒸馏
Distribution Matching Distillation。把多步双向扩散模型蒸成少步因果模型的主流路线，CausVid / Self-Forcing / 本文基座都建立在它之上。

D一眼看完的判断

值得抄的
「训练目标没约束过 OOD 输出 ⇒ 那里的噪声统计会失效」这个观察。它不依赖视频，任何条件扩散模型都能用来做免费的 OOD 自检。
要小心的
公式 (7) 的目标值与量级；所有损失项的归一化约定；前瞻时刻 t。三处都会让照抄的实现跑不出论文结果。
等作者补的
一张「ℒ_N 在真实 / 崩坏 / 正常生成序列上的分布」图（D2），以及一个算力对齐的 best-of-B 对照（D1）。这两个做出来，这篇就从启发式升级成机制。
