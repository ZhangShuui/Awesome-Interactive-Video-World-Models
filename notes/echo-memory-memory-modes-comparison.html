共享管线（所有记忆行完全相同，仅钩子处不同）

挂载 ①原始上下文 context_k1 / k5 / k20

  • 存什么：K 帧检索历史（首帧＋FOV 重叠 top K−1），逐帧 VAE → K 个干净 latent token。
  • 怎么读：与目标在时间轴拼接后走全序列 3D self-attention 直接读取；context 用独立 RoPE 时间 id，loss 只算 target。
  • 代价：零新增参数（全量微调骨干）；序列长度与注意力开销随 K 线性增长。
wan_video_new.py · training_loss() 拼接＋损失掩码 · model_fn_wan_video() RoPE　｜　检索：fov_retrieval.py

挂载 ①＋②压缩 framepack_weight / len_r2 / len_r4 / hybrid

  • 存什么：前置整段 81 帧 → 整段 VAE → 21 个 context token（历史更长，但必须压缩）。
  • weight：长度不变，context token 按离目标距离乘 0.9d 衰减——patchify 后、进 block 前一次完成。
  • length r=2/4：拼接前相邻 r 个 latent 分组 mean-pool，21 → 11 / 6 token；hybrid = 0.95 衰减 ＋ ÷r 池化叠加。
  • 代价：零新增参数，纯张量重加权 / 池化。
framepack_weight.py · apply_framepack_token_weights()　｜　framepack_length.py · framepack_length_compress_context_latents() ＋ align_context_actions()

挂载 ② 写 → ④ 读空间网格 spatial_mem · SpatialGridMemory

  • 存什么：在 K=1 锚帧拼接之上，把 context token 沿时间平均 → 8×8 自适应池化 → 可学 softmax 混合矩阵 → 64 个记忆 token（每 chunk 写一次）。
  • 怎么读（3 种消融）：拼入 text cross-attn KV（30 块共读）／目标 token 经门控 MHA 直读 x＋tanh(g)·Attn(x, mem)／完全不注入。
  • 特性：容量恒定 64 token；时间信息被平均掉——保空间布局、丢时序。新增参数仅 64×64 混合矩阵（＋可选读出头）。
  • 注意：这是 token-grid 基线，无 3D 几何；geometry_spatial_mem 才是独立几何路径（深度＋相机 → TSDF 点云 → 沿目标轨迹渲染 → VAE 编码）。
spatial_grid_memory.py · SpatialGridMemory / SpatialCrossAttnReadout / inject_spatial_memory()　｜　读写调用点：wan_video_new.py · model_fn_wan_video()

挂载 ③状态空间 block_wise_ssm / videossm_hybrid

  • 挂哪里：在 K=5 拼接之上，每 4 个 DiT block 挂 1 个（block 0,4,…,28，共 8 处），位于 self-attn 之后、cross-attn 之前；沿每个空间位置的时间轨迹扫全序列，仅 action 条件下激活。
  • block_wise_ssm（paper 对齐）：逐通道可学衰减 α=σ(decay_logit) 的真递归，感受野=全部历史（指数淡出）；含 tanh/σ 非线性与输入依赖门控。
  • videossm_hybrid（legacy）：depthwise 因果 Conv1d（k=3，expand=2），感受野固定 3 帧硬截断，且支路全程线性（无激活）——形似 SSM 实为时间滤波器。
  • 共同：门控残差 x＋tanh(g)·y，g 零初始化（起点＝恒等）；两者互斥。
  • 扫描方向：suffix 下序列＝[target｜context]，递归先扫 target 后 context——context 不经递归链直接流入 target，跨块信息仍靠 self-attn；块间也不携带 state。

SSM 深入图解（block_wise_ssm 逐步拆解 ＋ 与 legacy 对比）

第 1 步迷你例子：f=3 帧 × 2×2 网格（S=4），追踪位置 B　reshape → permute → reshape
真实模型 f=23、S=880。patchify 输出按「帧优先」拉平，B 的 token 相隔 S 散落各处，没法沿时间扫：
reshape(b,f,S,d) 读成表格 → permute(0,2,1,3) 行列互换（数据不动，只换索引方式）
reshape(b*S, f, d)：把每行摞进 batch 维 → 880 条序列并行、互不通信
第 2 步沿时间递归扫描：本质是「带输出门的逐通道指数滑动平均（EMA）」
第 3 步细节in_proj = nn.Linear(1536, 3072)　＋　.chunk(2, dim=-1)：一次矩阵乘，切成两路
对每个 token 向量独立进行（不看相邻帧/位置）——跨帧混合全部发生在递归循环里。合并成双倍宽再切开与两个独立 Linear 数学等价，但一次矩阵乘对 GPU 更高效。LSTM（一次投影 4 门）、Mamba（in_proj 切 x/z）都是同一惯用法。
相同的骨架，不同的"心脏"：两者都是 拆轨迹 → 【时间混合 ← 唯一区别】 → out_proj → 门控残差
