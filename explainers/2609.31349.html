DyMD 精读

这是一篇少步蒸馏论文，领域是机器人操作视频。PF-Wan 是 14B 的"首帧 + 指令 → 5 秒视频"模型，DyMD 把它蒸成只用 4 步去噪的 1.3B 学生。作者先观察到：用标准 DMD（分布匹配蒸馏）蒸出来的学生画面清楚，但不怎么动，机械臂比划几下，箱子没被抬起来。DyMD 在训练时改了两处：① 重加噪的时间步怎么采，更多地放到极高噪声段，比例按每个样本"动得对不对"来调；② critic（fake score）的损失按"预测拟合难度"重新加权。推理时不加任何模块。

我的判断。主结果可信，也有用：同样 4 步，R-Bench 任务遵循度 TAC 从 34.6 升到 44.2。但"为什么有效"的说法要打折：
  1. +9.6 分里，单独一个 Shift-25 对照（把 flow shift 从 5 调到 25）就拿回了 +5.4，这是现成的旋钮。教师先验又比 Shift-25 多出 +2.5，可这组对照只在 σ>0.5 上配平了采样质量。我从论文的矢量图里抽出 Fig.5 的原始数据，重建了教师先验：σ>0.99 的采样占比是 43%，Shift-25 只有 18%，相当于 shift≈90。
  2. 组件二（critic 重加权）在组件一之上只多了 +0.7，落在评测噪声带内。它的动机也有两处站不住。第一，高噪声下 FM 损失主要是不可约误差，完美 critic 同样会让损失和运动正相关。第二，按 x0 加权会改变 critic 的最优解，在理想极限下反而会压低运动。
  3. 论文的核心主张是"恢复运动"，却没有报告 R-Bench 自带的运动幅度指标 MAS。它用来证明"画质持平"的 Quality 指标本身偏爱静止视频：Base DMD 的 Quality 甚至高于教师。
  4. 蒸出来的 1.3B 学生，TAC 仍低于蒸馏前的 1.3B 初始化（44.2 vs 47.3），离教师的 75.3 也还很远。

§1一页读懂

先照论文自己的逻辑走一遍。我的判断放在 §4 以后。

Problem · 问题

视频世界模型给机器人"想象未来"，需要多步采样，太慢。DMD 能把它压成 4 步，但作者发现，蒸出来的学生会丢掉机器人和物体之间的交互运动：画面锐利，动作却没做完。R-Bench 的 TAC 从初始化的 47.3 跌到 34.6。

Diagnosis · 病因

(i) 教师"锁死"：学生样本加噪太轻时，教师对"原视频长什么样"的猜测仍然贴着这个静止样本，给不出"应该动起来"的信号（命题 2）。(ii) critic 跟不上：在固定噪声下，运动越大的样本，critic 的 FM 损失越高（Fig.3），作者把它解读为"更难拟合"。

Fix · 两个训练期组件

(i) 亲和度调节的重加噪采样：用教师速度的"转向率"离线造一个偏向高噪声的时间步先验 νκ。再用 V-JEPA 特征比较学生和真实视频的运动，比较结果 Ai 决定这个样本在先验和基础分布之间怎么混。(ii) 动态引导的 critic 重加权：用一个小 MLP 从潜空间运动统计预测"拟合难度"，按 eβr̂ 给 critic 的 FM 损失加权。

§2DMD 在做什么：人话版

这篇论文的两个改动，一个改"在哪个噪声水平上比较"，一个改"critic 怎么学"。所以得先把 DMD 的主回路说清楚。

一句话：DMD 让学生出一段视频，再请两个"鉴定师"看它。教师冻结的大模型，知道真视频长什么样。critic一个边训边学的小模型，只负责记住学生最近出的视频长什么样。两者的差，就是"学生离真分布还差在哪"。

但两个鉴定师都是扩散模型，只会看加过噪的视频。所以每次先把学生的 rollout 加噪到某个水平 σ，再让两者给出"得分"（score，即对数密度的梯度），学生沿两者之差往回改：

∇θLG ≈ 𝔼[ (∂x₀S/∂θ)⊤ ( sφ − sT ) ]，　 xt = (1−σt)x₀S + σtε(1)
sφ(xt) = −[xt + (1−σt)vφ(xt)] / σt，　 LFM ∝ 𝔼‖vφ(xt) − (ε − x₀S)‖²(2)(3)

critic 实际学的是一个速度场 vφ，训练方法是标准的流匹配：给它学生的加噪 rollout，让它回归"噪声 − 原视频"。附录 C.1 有一个更好懂的写法（式 19）：

sq − sT = (1−σt)/σt² · ( μq − μT )(19)
μ_T
教师看到加噪视频 xt 后，对"原本的干净视频"的平均猜测（后验均值，Tweedie 公式）。
μ_q
critic 代表的"学生分布"对同一个 xt 的平均猜测。
梯度
学生被推向 μT − μq 的方向。两个猜测一样，学生就收不到任何信号。
这一节要带走的两件事
  • 噪声水平 σ 决定两个鉴定师能看出什么差别。σ 小，xt 几乎就是学生原样，两个猜测都贴着它，能纠正的只是细节。σ 大，xt 几乎是纯噪声，两个猜测都回到各自分布的"平均画面"，差异才体现在整体结构和运动上。σ 从哪个分布里采（论文记作 ν），就是组件一要改的地方。
  • critic 必须实时跟上学生。学生一变，critic 学到的"学生分布"就过时了。critic 学得不准，sφ 的误差会原样进入学生的梯度。组件二改的是 critic 的损失。

§3病因：为什么 DMD 会让视频"定住"

论文给了两个病因。第一个我认为讲得清楚，而且能量化。第二个的证据有另一种解释，见 §5。

3.1 教师侧"锁死"（命题 2）

最简化的模型：教师只认两种干净视频，一种静止 xs，一种动了 xm，两者之差是 d。学生已经塌缩到静止版本。把它加噪到 σ 后，教师判断"原视频其实是运动版"的对数几率是：

𝔼ε[ log pT(xm|xt) / pT(xs|xt) ] = log(πm/πs) − ½ · SNRt · ‖d‖²，　 SNRt = (1−σt)²/σt²(20)

我按式 (20) 自己推了一遍，没有问题。人话：xt 里残留的学生信号越强（SNR 大），或者"动"和"不动"差得越多（‖d‖² 大），教师就越确信原视频是静止的，μT 贴着学生，梯度约等于零。论文没点明一点：视频潜变量的维度极高，‖d‖² 是个大数，所以要 SNR 小到 1/‖d‖² 量级，锁才解得开。你可以在下面拖动看看。

我从这里读出的东西

在我认为合理的范围里（运动区域占画面 2–20%，δ 取 0.3–1），解锁阈值 σ* 落在 0.98–0.998。Base DMD 用 shift 5，只有约 0.5–8% 的样本落在这么高的噪声上。所以把重加噪往极高噪声段挪，本身就该有大收益。这不需要"转向率"，调大 shift 就能做到。后面 §4.2 和 §6.4 的数据也是这么说的。

3.2 critic 侧"跟不上"（Fig.3）

作者拿 step-1500 的 critic，在 32 个冻结的学生 rollout 上测 FM 损失，发现运动越大（VAE 潜空间的 RMS 差分），损失越高，而且 σ 越大，这个相关越强。下图是从论文矢量图里抽出来的原始点，不是我目测描的。

§4组件一：重加噪的 t 从哪里采

这个组件分两层：先离线造一个固定的"教师先验"νκ，再在线用亲和度 Ai 决定每个样本在先验和基础分布之间怎么混。

4.1 教师速度的"转向率" κ

拿冻结的教师 PF-Wan，从纯噪声出发，用官方的 40 步采样器（shift 5，CFG 5）生成 32 条轨迹。每一步教师都会给一个速度 v̂T，意思是"往哪个方向去噪"。作者先把这个速度中心化：丢掉首帧所在的块，每个未来块再减去所有未来块的平均。剩下的只是"随时间变化的那部分方向"，可以理解为和运动相关的去噪方向。然后看相邻两步之间，这个方向转了多少角度，再除以两步之间的 Δσ：

um(σ) = C v̂T / ‖C v̂T‖，　 κ̂m,k = arccos( um(σk)⊤um(σk+1) ) / |σk+1 − σk|(5)(6)

转向率小，说明这个噪声段里教师"去哪儿"的主意很稳定。转向率大，说明教师正在改主意，也就是在决定运动的大结构。命题 1 把两者联系起来：

𝔼m[ Im(σ) ] ≥ CI · κ̄(σ)²，　 Im(σ)：教师后验沿 σ 的 Fisher 信息(9)

命题 1 说了什么

方向转得快的噪声段，教师对"原视频是什么"的整体判断（后验分布）一定在快速变化。我逐行核对了附录 C.3 的证明（式 23–32）：从 μ = x − σv 求导，用得分函数恒等式，再用 Cauchy–Schwarz 和 Jensen，推导正确。

没说什么

① 它只是个下界，而且只有一个方向：转向大能推出后验变化大，反过来推不出来（方向不变、只有幅度变，后验也可以剧烈变化）。② 它没有推出"采样密度应该 ∝ κ̄²"，这一步是设计选择。③ 命题针对的是精确的条件流，实际统计量来自 CFG=5 的离散轨迹，作者在附录里自己承认了这一点。④ 轨迹是教师从纯噪声出发走出来的，而 DMD 用的是学生样本加噪后的状态，两者不一定落在同一片区域。

hκ(t) = ( κ̃(σt) + ϵκ )²，　 νκ(t) = hκ(t) / ∫𝒯 hκ(u)du，　 ϵκ = 0.1·median(κ̃)，　 𝒯 = [0.020, 0.999)(10)

4.2 重建教师先验，并和 shift 调度对比

论文的 Fig.5 是矢量图，我从 arXiv HTML 版的 SVG 里抽出了 39 个均值点和四分位带。按式 (10) 重建先验：点间线性插值，超出 σ=0.9965 后取常数，ϵκ = 0.1 × 39 个点的中位数 = 0.868。算出 σ>0.5 的质量是 95.73%，论文附录 B.3 报告的是 95.69%，基本吻合。所以下面的数字可以当作对论文实际所用先验的可靠近似。

附带观察：这条曲线有多少是"这个教师"特有的

PF-Wan 的骨干来自 Wan2.2-I2V-A14B 的高噪专家。官方配置里，高、低噪专家的切换边界是 boundary = 0.900。PhysisForcing 把这个专家适配到全部时间步，发布的 PF-Wan 只有一个 28.6 GB 的 backbone.pth，推理是单骨干，不再切换专家。Fig.5 用黄色标出的"高噪区 σ∈[0.9, 1]"恰好从这个边界开始，曲线在 σ≈0.876 附近还有一个小鼓包。这不能证明什么，但提示转向曲线可能部分反映教师的训练经历，而不是蒸馏问题的普遍规律。作者在 Limitations 里也承认，换个教师要重新测。

4.3 时间亲和度：学生"动得对不对"

先验对所有样本都一样。DyMD 的第二层是：每个学生 rollout 先解码成 RGB，均匀取 16 帧，过 V-JEPA 2.1-L，在 3×3 空间网格内池化，得到 8 个时间块的特征。拿训练集里同一首帧和指令对应的真实视频做同样的处理，然后比较两者在 lag = 1、2、4 上的时间差分，权重分别是 0.2、0.3、0.5：

Ai = 2[ (δziS)⊤δzi⋆ ]+ / ( ‖δziS‖² + ‖δzi⋆‖² )，　 gi = α / ( α + (1−α)Ai )，　 νi = (1−gi)νbase + giνκ(12)(13)

Ai 是一个 Dice 式的相似度：两段运动完全一样时等于 1，学生不动时等于 0，方向偏了或幅度不对都会让它变小。gi 是"这个样本从教师先验里采 t 的概率"，最低是 α = 0.3，也就是 A=1 时；最高是 1，也就是 A=0 时。

4.4 为什么用 V-JEPA 而不用 VAE：证据的强度

作者用 CoTracker3 在 32 对"学生—目标"视频上算了一个点轨迹一致性 Ti 作参照，比较两种空间里算出的亲和度和它的排序相关。我从 Fig.7a 的矢量点复算：VAE 空间 ρ = 0.162，Kendall 0.117；V-JEPA ρ = 0.374，Kendall 0.246；最差 8 个的召回率分别是 25% 和 50%。和论文完全一致。但 n = 32 时，95% 置信区间很宽：

V-JEPA 亲和度和轨迹一致性的相关 ρ = 0.374，p≈0.035，只解释约 14% 的排序方差。换句话说，Ai 作为"交互保真度"的代理是弱信号，而且它只在 [α, 1] 的范围里调节 g。训练结果上，V-JEPA 比 DINOv2 在 TAC 上高 1.7（43.5 vs 41.8，Table S5），也在单次运行的噪声带内。

§5组件二：给 critic 的损失加权

机制本身很简单，问题出在动机和副作用上。这一节是全文我最不认同的部分。

5.1 机制

ri = sg[ log ℓiFM − bk(ti) ]，　 r̂i = f( di, e(ti) )，　 di = Dtemp(sg[x₀,i])(14)(15)
wi = exp(β r̂i) / ( B−1Σj exp(β r̂j) )，　 LC = B−1 Σi sg[wi] ℓiFM(φ) + λpredLpred(16)(17)
b_k
每个噪声分箱里 log FM 损失的指数滑动平均（衰减 0.99）。减去它，是为了让不同噪声水平的样本能放在一起比。
d_i
20 维描述子。在潜空间里，对 lag 1/2/4/8 的块间差分和"相对首块的位移"各取 RMS 序列，每条序列再算 mean/std/max/末值，最后取 log(1+x)。
f
有两个隐藏层的 MLP，输入 di 加上噪声水平的 Fourier 嵌入，在线用 Huber 损失回归 ri。
w_i
β = 0.5，在全局 minibatch 内归一化到均值 1（论文的有效 batch 是 32）。critic 的更新次数不变，只是更"照顾"预测为难拟合的样本。

5.2 疑问 A：高噪声下的 FM 损失，大部分根本"不可约"

论文把"FM 损失高"解读为"critic 对这个样本拟合得不好，需要多花力气"。可是单个样本的 FM 损失并不等于 critic 的误差。假设 critic 已经完美，也就是 vφ 等于真实的条件速度 v* = (xt − μ*)/σ，那么：

𝔼ε[ ℓFM(x₀, σ) ] = 𝔼ε‖ x₀ − μ*(xt) ‖² / σ²　 →σ→1　 ‖ x₀ − 𝔼[x₀ | 首帧, 文本] ‖²我的推导

人话：在 σ = 0.97 时，xt 里只剩 3% 的信号，critic 根本看不出"这个样本具体怎么动"，只能按首帧和指令猜"通常会怎样"。样本动得越多、离首帧越远，猜不中的部分就越大。这部分误差训练再久也消不掉。而描述子里恰好有"相对首块的位移"这一项。

这个解释能说明论文里的三个现象：Fig.3b 中 ρ 随 σ 上升（0.35→0.69）；Table S2 中预测器的 ρ 同样随 σ 上升（0.758 → 0.898 → 0.952）；以及 σ = 0.97 时预测器几乎完美。这些都是"不可约部分占比随 σ 变大"应有的样子，不能说明 critic 在高运动样本上"滞后"。

5.3 疑问 B：加权会改变 critic 学到的"学生分布"

Fig.4 的图注说，这些权重"不改变 FM 的回归目标"。对单个样本来说确实如此。但 wi 取决于 x₀（通过 di），而 critic 只能看到 xt。带权回归的最优解是：

vφ* (xt) = 𝔼[ w(x₀,t)·(ε − x₀) | xt ] / 𝔼[ w(x₀,t) | xt ]　 =　 qw(x₀) ∝ w(x₀,t)·q(x₀) 的速度场我的推导

也就是说，即使 critic 容量无限、训练充分，它学到的也是一个向高运动样本倾斜的"学生分布"。代入式 (19)：critic 以为学生已经比实际动得多，μq 偏向运动，教师把学生往运动方向拉的力 μT − μq 就变弱了。理想极限下，平衡点满足 q ∝ pT/w，学生最终的运动比例会低于教师，方向和论文的动机正好相反。

§6实验重排

6.1 设置一览

§7存疑清单

按对结论的影响排序。"高"表示会改变你对标题结论的理解，"中"表示削弱某个分论点，"低"是细节或复现问题。每条都附了能自己核对的证据位置。

01高增益的大头是"更多极高噪声"，而对照组没有在极高噪声段配平

TAC +9.6 里，Shift 从 5 改成 25 就拿到了 +5.4。教师先验又比 Shift-25 多 +2.5，论文说这是在"相近的高噪声质量"下比较的，但只配平了 SNR<1，也就是 σ>0.5。按 Fig.5 重建（σ>0.5 的质量 95.73%，论文写 95.69%，可信），各段的质量如下：σ>0.9，教师先验 84%，Shift-25 73%；σ>0.99，43% 对 18%，等效 shift≈89。锁死计算器（§3.1）表明，解锁恰好发生在 σ≈0.98–0.998。所以"转向几何"带来的额外好处，可能只是"更多样本落到 σ>0.99"。

证据：Table 3；附录 B.3；Fig.5 的 SVG 数据；§4.2 重建；§3.1 计算器。补救：加 shift = 50、100 的对照，或者直接按 σ>0.99 的质量配平。

02高"按样本自适应"没有被单独验证：缺一个固定混合权重的对照

论文的第二个卖点是"按每个 rollout 当前的交互保真度来调节"。可是亲和度调节对照的是纯教师先验（g≡1），两者同时差在两处：一是"混进了基础分布"，二是"混合比例按 Ai 变"。差值只有 +1.0 / +0.6 / +0.1，在噪声带内。要说明自适应本身有用，需要一个 g 固定为训练中 𝔼[gi] 的对照。论文也没报告 Ai 和 gi 的分布。α 扫描（39.2 → 43.5 → 43.8 → 42.5）同样可以用"平均高噪声质量"来解释。另外，Ai 作为保真度代理本身就弱：它和轨迹一致性的 ρ 只有 0.374，95% CI 是 [0.03, 0.64]。

证据：Table 3、Table S6、Fig.7a；§4.3、§4.4。

03高组件二的诊断把"不可约误差"当成了"critic 拟合得不好"

完美 critic 下，单个样本的 FM 损失等于 𝔼‖x₀ − μ*(xt)‖²/σ²；σ→1 时，趋近于 ‖x₀ − 𝔼[x₀|首帧, 文本]‖²。运动大、离首帧远的样本，这一项天然就大，而描述子里正好有"相对首块位移"。Fig.3b 的 ρ 随 σ 上升，Table S2 里预测器的 ρ 也随 σ 上升（0.758 → 0.952），这正是不可约部分占比变大的表现。§5.2 的玩具模型里，critic 误差为零，同样能复现这个形状。论文没有做任何拆分可约和不可约部分的实验。

证据：Fig.3、Fig.7b、Table S2、附录 D.2/D.3；§5.2。补救：冻结生成器，让 critic 多训 N 步，测每个样本损失下降多少，再看下降量和运动的相关。

04高核心主张是"恢复运动"，却没有直接测运动；报告的画质和物理指标都偏爱静止

R-Bench 自带运动幅度分 MAS，专门针对"平滑但不动"的失败，论文只报告了 TAC。PAI 的 Quality 上，Base DMD 78.1 高于教师 76.9。主体一致性 SC 上，DyMD 和 Base DMD 同为 95.3，教师 90.3。两个 Physics 轴都是 Base DMD 高于 DyMD（82.8 对 81.2，86.0 对 84.4）；EZS 的 Physics 上，Base DMD 还高于未蒸馏的 1.3B（83.9）。论文用 Quality 持平来说"画质没有损失"，但这个指标本身会奖励静止。光流幅度、MAS、轨迹一致性，一个都没有在评测集上报告。

证据：Table 1、Table S4；RBench 原文附录 B.4；§6.2、§6.3。

05高全部是单次训练、单个种子、没有置信区间；多数消融差值落在噪声带内，超参数还是在测试集上挑的

TAC 只有 400 条、5 档打分，只算评测抽样的配对差，95% 噪声带就有约 ±3（单样本标准差取 0.30–0.35、配对相关取 0.5 时，是 ±2.9～3.4）。PAI（174 条）和 EZS（196 条）约 ±2～3。消融里的 +2.5、+1.0、+0.7，β 扫描的 0.7 极差，编码器之间的 1.7，都在带内，这还没算训练种子的方差（DMD 训练的方差出了名的大）。α、β 和编码器是在报告结果的同一批基准上选的（Shift-25 除外，它按采样质量配平来定）。评委 GPT-5 和 Qwen3-VL 本身也有随机性，论文没说解码温度和重复次数。

证据：Table 2–4、Table S5–S6；§6.4 的噪声带控件。

06高蒸馏后的学生，任务遵循度仍低于它自己的初始化

未蒸馏的 Wan2.1-Fun 1.3B（即学生的初始化，100 NFE；论文没提对它做过机器人数据微调）TAC 是 47.3，DyMD 是 44.2。四种形态里，DyMD 只在单臂上高 0.4。所以"从 14B 机器人专用教师迁移交互能力"这件事，在 TAC 上还没有发生，DyMD 只是把 DMD 造成的损失补回了一部分。论文把 Wan2.1-Fun 列为"参考模型"，但没有讨论这一点。更有说服力的基线应该包括：直接用 32,897 段数据微调 1.3B，或者先微调、再在同尺寸上做 DMD。

证据：Table 1；§6.2。

07中给 critic 损失按样本加权，会改变它的最优解；理想极限下这会压低运动

权重 w(x₀, t) 依赖 critic 看不到的 x₀，带权回归的最优解就变成了倾斜分布 qw ∝ w·q 的速度场。critic 会以为学生动得比实际多，于是往运动方向拉的梯度变弱。平衡点满足 q ∝ pT/w，学生的运动比例会低于教师。Fig.4 图注里"不改变回归目标"的说法只对单个样本成立，对总体最优解不成立。偏差有多大，取决于 r̂ 的分布，论文没报告。反过来，论文说 critic 误差"妨碍学习交互动态"，也没有分析误差的符号：一个跟不上、还以为学生不太动的 critic，给出的反而是更强的"往动的方向走"信号。

证据：式 (16)(17)、Fig.4 图注；§5.3 的计算器。

08中只和 Base DMD 比；相关工作里的 DMD 改进一个都没比，而 DyMD 其实用了配对的真实视频

相关工作列了 DMD2（带 GAN 项）、Phased DMD、Adaptive Matching Distillation、CoDMD、Adaptive Video Distillation、RTDMD，实验里一个都没有。更关键的一点：亲和度需要真实的配对目标视频，这是 Base DMD 用不到的额外监督。最自然的对照是同样利用真实数据的 DMD2 GAN 项，或者"DMD + 配对回归"。

证据：§2 相关工作；式 (11)；附录 B.2（目标特征缓存为 8×9×1024 fp16）。

09中WorldArena 的领先几乎全部来自一个任务，上下两段协议不同，检查点怎么选的没说

按铃 31 → 66，差异显著。调瓶 1 → 2，不显著，和上半段的 TesserAct（1%）、Vidar（2%）持平，低于其余四个模型（8–20%）；18 分的平均提升里，17.5 分来自按铃。上半段的模型在 RoboTwin 上后训练过；本文是冻结骨干 + 每个任务单独训练的 VPP 头。PhysisForcing 原表里 "+ PhysisForcing 24.0" 那一行没抄。VPP 头的评测检查点是 13,904 / 15,010 / 4,509 / 5,319 这些"零碎"步数，挑选规则没写。每个骨干、每个任务只训了一个头（论文没提多种子）。教师和未蒸馏的 1.3B 都没评，所以不知道 VPP 头本身贡献了多少。

证据：Table 5、附录 F.1；PhysisForcing Table 3；WorldArena §4.1。

训练预算是 2,500 步。但 Fig.S1 的图注写明用的是 "step-1500 checkpoints"，并说和正文定性结果（Fig.6）"matched"，可以推断 Fig.6 也是 step-1500，critic 难度分析（D.2）用的是 step-1500 的 critic，预测器分析（D.3）用的是 step-2000。主表的数字是 2,500 步的最终模型，还是某个中间最好的检查点，论文没交代。如果是在测试基准上挑的检查点，又多了一层乐观偏差。

证据：§4.1、附录 D.2、D.3、Fig.S1 图注。

11中不可复现：没有代码，关键训练超参没给，训练开销也没报告

没有代码链接。DMD 的学习率、优化器、critic 与生成器的更新比（DMD2 用的是 5:1）、Base DMD 的损失归一化方式、GPU 数量和型号、训练时长都没写。每一步都要把生成器和 critic 的 rollout 解码成 81 帧 RGB，再跑 V-JEPA 2.1-L，这笔开销没有量化。Table S3 只列了 DyMD 自己的超参数。好在教师 PF-Wan 的权重是公开的。

12中亲和度只和一段真实视频比，另一种合理的动作也会被判成"不忠实"

给定首帧和指令，合理的未来有很多种。Ai 却只和训练集里那一段对齐：学生如果换了一种合理的抓法或路径，也会得到低亲和度，被多分配高噪声采样。在机器人数据里多样性比较低，这个问题可能不严重，但论文没讨论。这也意味着采样分布里掺进了"模仿这一条轨迹"的偏好。

证据：式 (11)(12)、论文 §3.3；本页 §4.3。

13低命题 1 只是动机，不是推导：下界是单向的，也推不出"密度 ∝ κ̄²"

证明本身没有问题。但转向大只能推出后验变化大，反过来不成立；"按 κ̄² 采样"是设计选择；统计量来自 CFG 引导的离散教师轨迹，而且是从纯噪声出发，不是从学生样本加噪出发。作者在附录 C.3 末尾承认了第三点（CFG 引导的离散轨迹不等于精确的条件流），也说命题只提供动机、不构成推导，但没有提到下界是单向的。一个更直接的检验是：换一个形状不同、但极高噪声质量相同的先验，看结果变不变。

证据：附录 C.3 "Connection to the empirical statistic"。

14低转向曲线可能部分反映 PF-Wan 自己的训练经历

PF-Wan 的骨干是 Wan2.2-I2V-A14B 的高噪专家（官方边界 boundary=0.900），后来被适配到全部时间步。Fig.5 标出的高噪区 σ∈[0.9, 1] 正好从这个边界开始，曲线在 σ≈0.876 附近还有一个小鼓包。这不构成反驳，但说明"转向曲线"不一定能推广到别的教师。作者也写了"换教师需要重测"。

证据：PhysisForcing 附录 A；Wan2.2 的 wan_i2v_A14B.py；PF_Wan 模型卡（单骨干）。

15低表征选择的证据太弱：n = 32，还用 4 折交叉验证

VAE 和 V-JEPA 亲和度的 ρ 是 0.162 和 0.374，95% CI 分别是 [−0.20, 0.48] 和 [0.03, 0.64]，大幅重叠。critic 那边，V-JEPA 描述子在 4 折 CV 下"一致负相关"（−0.35 到 −0.24）。只有 32 个 rollout 时，折外负相关常常是小样本过拟合的产物，不一定真表示"反向"。结论方向也许没错，但这些证据撑不起论文里那么确定的措辞。

证据：Fig.7、附录 D.1/D.2。

16低评测细节偏离官方协议：单视频、改写提示词、稀疏抽帧

R-Bench 官方是每个样本生成 3 个视频取平均；本文只说所有模型用相同的首帧、提示词和随机种子，没说每条生成几个视频。EZS 的原始描述先被 GPT-5 压成 40–60 词，这是沿用 PhysisForcing 的做法。VLM 评委只看 6 帧或 8 帧，对"动作做没做完"这种时序判断比较粗。全文没有人工评测。R-Bench 和训练数据 RoVid-X 出自同一个团队，论文说 400 对是"held-out"，但没报告有没有做去重。

证据：附录 F；RBench §5.1。

  • Table S3 的 "Latent measurement / spatial size: 21 blocks" 缺了空间尺寸。
  • Table S4 的文本层里残留了一个 "dymd" 字样（可能只是 PDF 文本层的痕迹，渲染后未必可见）。

§8公道话，以及对交互式视频世界模型的启示

做对了的地方

  • 问题找得准，现象讲得清楚。"DMD 让机器人视频定住"是真实存在、而且很多人会碰到的失败。Fig.2 用同一个静止 rollout 在不同噪声下让教师重画，一张图就讲明白了。
  • 把 DMD 的梯度讲成"两个后验均值之差"（式 19），再用两点模型量化锁死，这个视角干净，也有用。
  • 推理时零额外开销，所有辅助模块只在训练时用。
  • 主动做了 Shift-25 对照，让读者能看出单是调大 shift 就能拿回一半以上的增益。主动报告了反例：Base DMD 的 Physics 更高。
  • 附录很完整，数字也经得起核：图是矢量的，能复算的表我都复算了，只发现两处 0.1 量级的小不一致（见 §6.7）。

对交互式视频世界模型的启示

1 · 自回归蒸馏也要看尾部

Self-Forcing 和 CausVid 这一系的实时世界模型，都用 DMD 类方法把教师压到 4 步以内。如果动作响应变弱、画面变"静"，先查重加噪采样在 σ>0.99 上有多少质量。按 §3.1 的估算，高维潜变量要到这个区间，教师才会给出"应该动"的信号。

2 · 评测要直接测"动没动"

一致性、平滑度、I2V 保真度这类画质指标都会奖励静止。交互式世界模型最关心动作能不能跟上，应该报告运动幅度（MAS、光流）和动作跟随度，而不只是 Quality 和 VLM 打分。

3 · 给 critic 重加权要小心

如果权重依赖 critic 看不到的量（比如 x₀），就会改变 critic 学到的分布。想"多照顾难样本"，更稳妥的做法是用 xt 上可观测的量来定权重，或者做重要性校正，并且把可约和不可约误差分开来看。

4 · 真实配对视频可以用得更直接

DyMD 只用真实视频来决定"在哪个噪声上比较"。既然已经有配对数据，DMD2 式的 GAN 项或配对回归，可能是更直接的"把运动拉回来"的手段，值得作为基线。

最值得补的实验（按性价比排序）

  1. shift 扫描（10 / 25 / 50 / 100）和按 σ>0.99 配平的教师先验对照。
  2. 固定 g 的混合（取训练中 𝔼[gi]），并报告 Ai 和 gi 的分布。
  3. 报告 R-Bench MAS 和光流幅度，并在 R-Bench 全部 650 条上给出 TC 和 VQ 总分。
  4. 3 个训练种子加上按样本的 bootstrap 置信区间。另留一个验证集，用来挑 α、β 和检查点。
  5. 拆分 FM 损失：冻结生成器、延长 critic 训练，看高运动样本的可约误差是不是真的更大。
  6. 补基线：DMD2（GAN 项）、同尺寸的 SFT、在 1.3B 上做 SFT 再做 DMD。WorldArena 上补教师和未蒸馏模型，多跑几个任务和种子。
