因果可写性A Chosen Future Can Still Be Rewritten: Causal Writability in Video Models

视频模型生成了物理上错误的运动——是“没学会”正确的运动，还是“学会了却没用上”？

作者造了一个弹簧玩具世界：训练时红球永远慢、蓝球永远快；测试时给一个红球配一段快运动的历史。模型经常跟着颜色走、生成慢运动。作者发现：在网络前几层往“观测帧 token”里加一个只由 4 个系数决定的编辑，就能让它改生成快运动；这种改写只在某个深度之前有效（闭合 / commitment），训练会让这个深度前移，而早期还能在更深处改写的错误，更可能被后续训练修好。

我的判断：实验工程非常讲究，“先在无颜色数据上学运动，再见有偏数据”那组结果最硬（冲突物理跟随 9.4% → 80.5%）。但标题级结论——“正确运动学会了只是没用上”——被高估了：写回去的其实是“蓝色＋快”的整个训练模式（球的颜色也一起被改了），而“被物理状态组织”的那 4 维编辑，用一个只知道“球落在哪几个 token 上换了色”的编码，就能复现论文 Fig.12 的全部统计（§6 可以自己玩）。

§1 · 概览

三句话读懂，外加八个主张的证据账

  • 捷径从哪来：真实视频里外观和速度高度相关（高速路的车快、居民区的车慢）。模型可以“从历史外推运动”，也可以“看外观猜速度”。训练分布上两条规则预测一样，只有外观和运动冲突时才分得开——这就是 predictive underspecification。
  • “可写性”怎么测：拿一对只差球颜色的输入（aligned：颜色和运动一致；conflict：颜色和运动冲突），在第 ℓ 层把 conflict 的观测帧 token 激活换成（或加上）aligned 那一份，完整解码视频，追踪球、拟合频率，看运动能不能被改回来。能改回来的层叫“可写”，从某一层起改不回来叫“闭合”。
  • 论文的三类发现：①这种改写可以压缩成 4 个由边界相位预测的系数；②闭合在深度上很集中，训练使其前移，更多可见运动/先学运动使其后移；③闭合之后，放大某个注意力头的 K/V 写入仍能把运动改回来，但增益过大会越界。

§2 · 任务

一个被精心设计成“有捷径”的弹簧世界

每条视频 129 帧、20 fps、128×128。前 65 帧（0–64）是观测，后 64 帧（65–128）由模型生成。每种设置训练集 2,048 条：1,024 条红球 ω∈[2.2, 3.0] rad/s，1,024 条蓝球 ω∈[5.2, 6.4] rad/s；归一化振幅 0.10–0.17，相位均匀随机。训练里从没出现过“红＋快”或“蓝＋慢”。

Long 让 65 帧全部可见；Short 把第 0–56 帧整帧涂成背景色 RGB(28,30,34)，只留最后 8 帧（57–64）的真实运动，时间线和 token 数不变。测试时固定运动历史和生成噪声，只把球的颜色在红→蓝之间插值 11 档，解码后用确定性追踪器找球，拟合 x(t) = a·cos ω̂t + b·sin ω̂t + c（ω̂ 在 [1.21, 8.64] 上 1,601 点网格搜索，RMSE ≤ .035），看 ω̂ 落在哪：历史所在频带 = physics-following，颜色配对频带 = shortcut，两带之间 = compromise，其余 = off-family / invalid。

读指标前先记住两个参照

physics-follow rate 在完整 64×11 网格上，纯“看颜色”的规则就能拿 50%（一半色调与运动一致）；只看冲突端点时，它是 0%。所以 15 个 Short run 的平均物理跟随从 .52 升到 .60，意思是：模型整体只比“纯看颜色”好一点点，捷径是主导策略。另外，色调网格上的 11 个点是同一段历史的重复测量，统计单位是 64 段历史，不是 704 个样本——这一点论文处理得很规范。

论文在行为层面看到的四件事

  • 颜色主要在两个频带之间“二选一”，不是连续调速（Fig.2a）。
  • 紫色（模糊）提示下，运动重新占上风：Run A 在端点上走捷径的 26 条历史里，23 条在紫色提示下改走历史一致频带（Table 2：快 8/10、慢 15/16）。三个 run 的端点捷径失败平均频率移动 1.68–2.76 rad/s，颜色移动 .50–.71（归一化）。
  • 运动也能反过来“补全颜色”：模糊色调下，快运动倾向生成蓝色未来、慢运动倾向红色——模型学到的是（颜色, 频率）的联合模式（Fig.2b）。
  • Long 比 Short 更扛得住冲突色调（Fig.2c，每点 32 段历史）。15 个独立训练的 Short 模型在“折中”输出的比例上差异很大，但都呈现同样的证据依赖模式（Fig.8，10,560 个 rollout 全部有效）。
§3 · Token 账本

129 帧如何变成 2,112 个 token，以及颜色差异落在哪里

冻结的 Wan2.1 VAE 在时间上压 4 倍、空间上压 8 倍：129 帧 → 33 个 latent 帧（第 0 帧单独成一帧，之后每 4 帧一个），每帧 16×16×16 通道。1×2×2 的 patch 之后每个 latent 帧 64 个 token。前 17 个 latent（对应像素帧 0–64）是条件，后 16 个是目标，只有目标进 loss。两者拼成一条序列送进 30 块双向 DiT——这是“前缀条件”，不是交叉注意力。

§4 · 干预手术

往哪儿写、写什么、怎么打分

所有干预都遵守同一个“手术规范”：只改 1,088 个条件 token；只在一个位点（第 0 块之前，或第 k 块之后，共 31 个位点）；20 次 FM 调用每次都注入；注入那一刻 1,024 个目标 token 一个数都不动，之后正常演化。两种算子：

  • 替换 hCℓ,cond ← hAℓ,cond：用于层扫描和可写性。
  • 加性 hCℓ,cond ← hCℓ,cond + d̃：d̃ 可以是完整配对差 d = hA − hC、它的 Top-4 投影、跨 run 迁移的版本，或控制器预测的版本。

打分：R、W(ℓ) 和 D

对第 i 对轨迹，归一化频率恢复 Ri(ℓ) = (ω̂edit − ω̂C) / (ω̂A − ω̂C)：0 = 冲突 run 本来的频率，1 = aligned run 的频率。注意基准是模型自己在正确颜色下的输出，不是真值 ω。写入“成功”= 输出有效且 .75 < R < 1.25。W(ℓ) 是严格失败库里在位点 ℓ 仍能成功改写的比例；单条轨迹的 Di 是 31 个位点里成功的个数，D 是其期望。严格失败对 = aligned 有效且在真频带、conflict 有效且落在对面捷径频带、两者只差颜色、|ω̂A − ω̂C| ≥ 2.0。

理解整篇论文最关键的一句

在第 0 块之前（位点 −1）做替换，就等于直接把 aligned 输入喂进去——同一份噪声、同一个模型，R≡1 是构造出来的。所以可写性曲线必然从 100% 出发，它测量的是：目标 token 在第几层之前还在“等”条件 token 的信息。“闭合”= 目标 token 已经把（冲突版的）条件信息读进来并定下了模式，此后条件 token 再怎么换，后面的层都读不进去了。这是一个关于信息在深度上何时从条件流到目标的测量，和 LLM 激活修补里“主语 token 的信息在某层之后已被搬走”是同一类现象。

§5 · 4 维控制器

从“供体差”到“由边界相位预测的 4 个系数”

在三个 Short 50K run 上，先做层扫描，挑一个“仍能改写的最深位点”作为功能位点（Runs A/B/C 分别是 B3、B6、B4）。然后在拟合集的配对差上做无中心 PCA，每个 held-out 轨迹只保留它在前 4 个主轴上的分量：87.8% 的 Top-4 写入落在恢复窗口里，完整配对差是 92.4%。

接着发现 Top-4 坐标随边界相位 θ* = atan2(−v*/ωtrue, x*) 形成光滑的环（简谐运动里 cos θ* 像位置、sin θ* 像归一化速度），于是对“目标快 / 目标慢”各拟合一个一阶谐波：ẑ1:4(θ*) = β0 + βc cos θ* + βs sin θ*。held-out 坐标 R² 从仅用方向的 .51–.60 升到 .83–.88；冻结的控制器对新轨迹合成编辑，85.9% 落在恢复窗口里——不需要该轨迹的 aligned 供体。

§6 · 反例玩具（我的计算，不是论文结果）

一个“不懂物理”的换色编码，能不能复现 Fig.12？

aligned 和 conflict 的输入只在球的像素上不同。Short 下，在输入端这些像素只出现在 latent 15、16 的少数几个 token 上；而球在帧 57–64 的位置，完全由 (x*, v*, ω) 决定。那么，一个只记录“哪些 token 被换了色”的向量，天然就会“被位置和速度组织”。

下面这个玩具不经过任何神经网络：编辑向量 = 球在帧 57–64 覆盖 16×16 像素格子的面积（按论文渲染几何，latent 15/16 各一张 8×8 图），目标快取 +、目标慢取 −（颜色差方向相反）。然后照搬论文的流程：64+64 对拟合、64+64 对 held-out；无中心 PCA 取前 4 维；分别拟合“仅方向”“共享相位”“目标相关相位”三种线性模型；再做“相位对齐平面”投影。

这说明了什么，没说明什么

说明了：论文用来支撑“物理结构化编辑”的统计（相位环、R² 阶梯、PC1/PC2–4 分工）不能区分“模型内部有位置-速度表征”与“编辑只是在球所在的 token 上换色”。在像素世界里“球在哪”天然由 (x*, v*) 决定，任何“在球的位置上改点什么”的编辑都会被 (x*, v*) 组织。

没说明：它不证明模型没有运动表征——玩具忽略了网络，真实编辑是经过 3–6 块处理后的激活。作者在项目页也写了 “does not establish a pure physics representation”。一个能分出胜负的便宜实验：仓库已经公开了 wan-neutral-only-10k（只在灰球上训练、对色调不敏感）。在它上面算红−蓝配对差，走同样的 PCA 与相位拟合——如果仍出现同样的环和 R²，那“组织”来自位置，而不是运动计算。

§7 · 闭合

未来在第几层“定下来”

把 §3 的完整配对编辑在全部 31 个位点各做一遍：早写能把捷径未来改回来，过了一个窄窄的深度区间就改不动了。论文把这个边界称为对该写入的承诺（commitment）——注意限定语“对该写入”：这是相对“gain 1 的替换 + .75–1.25 窗口”而言的，§10 会看到更强的写入能在闭合之后重新改写。

D 是怎么数出来的

单条轨迹的 D = 31 个位点里“有效且 .75 < R < 1.25”的个数。点下面的格子（琥珀 = 该位点成功）。三个预设分别对应：早闭合、晚闭合，以及论文在 Wan 上观察到的“闭合后又重开”的非单调情形——D 只数个数，不关心是否连续。

“更多可见运动推迟闭合”的混杂

Long 的边界确实更深（A: B3→B16，B: B6→B8，C: B6→B10）。但回到 §3 那张图：Short 里颜色差异只在 2 个条件 latent 上，Long 里在全部 17 个。gain-1 替换在 Long 里天然覆盖多 8 倍的 token、范数更大，论文没有做范数对齐；而且 Short/Long 的严格库不配对（Table 6 自注），Long 的慢目标在 Runs B、C 里 4,096 个候选一个都没合格，所以只能比快目标。更干净的设计：Long 历史里的早期帧用灰球（只加运动证据、不加颜色证据），或把编辑范数对齐。Pendulum 的 Short/Long 比较（Long 使 D 增加 10.53 / 8.05 个位点）是同样的设计，带着同样的混杂。

§8 · 训练动力学

训练修好一些错误，同时让剩下的错误更“顽固”

15 个 Short run 训练到 100K，在 5K/10K/20K/50K/80K/100K 各评一次。全网格物理跟随从 .52 升到 .60，同时剩下的捷径错误平均可写位点从 10.88 降到 9.55。作者类比分类器：准确率上升，同时对剩余错例越来越“自信地错”。

  • “剩下的错误变顽固”有一半是样本构成：总体下降 10.88→9.55（−1.33 个位点）混合了“容易的错误被修掉”的构成效应。冻结同一批持续失败的身份后，下降是 −0.62 [−1.48, −0.11]，15 个里 13 个下降（Fig.23）。方向成立，量不大（约 31 个位点中的 0.6 个）。
  • 早期可写性预测命运：5K 时全都走捷径的轨迹里，后来在 80K 和 100K 都改走物理的（n=157）比六个 checkpoint 都走捷径的（n=953）多可写 3.79 个位点 [1.57, 6.53]。控制自然误差严重度和边界状态后仍在；论文没有在文字里给出 AUC 数值，Fig.24b 的坐标轴只画了 .6–.8 这一段。
  • 换个说法更好懂：“决策发生得越深”≈“模型对这个错误越不确定”，这类错误更容易被后续梯度翻过来。这是一个合理的置信度代理，但论文没有和更便宜的置信度代理（比如多 seed 输出一致性）比预测力。
  • 可复现性：这一节依赖的 15 seed × 6 checkpoint 集合没有发布（仓库明说），只能重训。
§9 · 预训练 Wan 1.3B

先在灰球上学运动，再见有偏数据

同一个预训练 Wan 1.3B DiT，两条适配路径。Direct：直接学红慢/蓝快。Neutral-first：先在 2,048 条灰球视频（RGB 92,92,92，快慢各半）上训练 10K 步，再用新优化器、对齐的数据顺序学同样的有偏数据。评估集是事先冻结的 128 段历史（每频带 64 段），与训练和机制队列都不相交。

  • 闭合被推后：在同样 17 条慢目标持续失败上，Direct 的中位数恢复在 B12→B13 之间丢失，Neutral-first 保持到 B14、在 B14→B15 丢失（Fig.9c）。
  • 控制器也能迁到 Wan：held-out 坐标 R² .858/.771（快/慢），无供体控制器的中位恢复 .953/.923，接近 Top-4 上限 .968/.952。
  • 闭合不是吸收态：在 11 个固定身份上，B13/B14 的可写性会在相邻 checkpoint 间关上又打开；2K 时的深度排序对 4K、5K 的行为预测很强，到 10K 就衰减了。
  • 灰色输入更物理：Neutral 路径里，同样历史的灰球输入比彩色冲突输入的物理跟随率高 17.2 / 15.6 / 11.7 个百分点（2K/5K/10K）——颜色偏差并没有完全被挡住。
需要打折的地方

①论文和代码都没有给 Wan 适配超参（分辨率、学习率、是否全参、文本条件、条件帧怎么注入）；仓库文档明说复现 runner 只覆盖 Spring，只发布了 7 个 checkpoint。②闭合证据是 17 条、单方向的中位数。③Neutral 路径多训了 10K 步。④“先学到的可用特征会压制后来的捷径”与 simplicity bias / feature availability 的已有结论一致（如 Hermann & Lampinen 2020；Shah et al. 2020），论文没有讨论这条线——行为效应本身并不意外，新东西是闭合深度随之移动。⑤“跨模型尺度的普适性”只在同一个玩具任务上成立。

§10 · 注意力写入

闭合之后：信号还在吗？谁把它写进了未来？

论文先在更早的可写位点写入，再看后续每一层未来帧 token 的编辑−冲突差在 aligned−conflict 方向上的投影，发现从“第一个不可写 block”一直到最后一层，这个信号在三个 run 里都仍可测（Fig.6a）。然后做组件恢复：把编辑后 run 的某个组件换回自然冲突 run 的值，看恢复还剩多少。

“K/V 介导”有多少是结构必然

编辑只动条件 token，而跨 token 的信息只能通过注意力的 K/V 流动——“必须经过 K/V”是架构决定的；目标 token 的 Q 在注入瞬间也按构造不变。正文说 “Restoring Q tests the queries issued by future-frame tokens”，但 Table 7 的标题是 “restore natural-conflict condition components”，公开的 attention.py 也只改条件 token 的行、并断言未来 token 不被直接改动——即被恢复的是条件 token 的 Q，它检验的不是“未来帧怎么问”。真正有信息量的是“哪一个头、K 还是 V”，而这在三个 run 之间并不一致：

Run起作用的实现（Fig.29 / 33）含义
A单个 K 头 6 ×2 ≈ 整体 K/V ×1集中在一个 K 头
BK 头 2 即使 ×8 仍不如整体 K/V ×2分散在整体 K/V
C整体 K/V ×1、×2、×4 都跨不过；V 头 8 ×8 可以瓶颈在一个 V 头

放大一个头能把运动改回来——配上分母再看

Run C 在 B9（已过闭合）只放大条件 token 上 V 头 8 的写入：VC + λ·(VM − VC)，M 是施加了控制器编辑的那次 run。λ=8 时 48 条 held-out 严格失败里物理跟随 56.3%；λ=16 时输出都有效但大多越界。

什么时候写：flow-matching 调用的后半段才算数

“信号在闭合后仍然存在”是怎么测的

Fig.6a 的“替代运动信号”是在已经被早期写入成功改写的 run里测的；V 头放大用的 ΔV 也来自控制器改写后的 run M。论文没有在自然冲突 run 上做探针（比如在深层解码历史频带）。所以 Kalman“可观测但不可控”类比里，“可观测”那一半并没有被直接测量——观测帧 token 里当然一直有运动信息，因为那就是输入。

§12 · 存疑

18 条存疑，按严重度排

“高”= 影响标题级结论；“中”= 影响某一节的解读；“低”= 口径、可复现性或措辞。每条都写了论文怎么说、实际是什么、为什么重要。

H1 · 高被“恢复”的正确运动，其实是整个换成另一个训练模式——球也被改了颜色›
论文说
摘要：“a low-dimensional edit … restores the correct fast motion”；开篇的问题是“没学会，还是学会了没用上”。
实际
§3 只有一句 “The edits also rewrite associated appearance: slow→fast shifts future color toward blue”；Free Fall “moves appearance toward the training-associated target color in all 64 outputs”；Fig.31b 标注 “red/slow → blue/fast”；仓库 docs/models.md：“A successful motion edit may also change generated appearance.” Spring 编辑后的颜色没有定量报告。
为什么重要
真正物理正确的“红球快振”从来没被生成过。被写回的是训练里存在的“蓝＋快”联合模式。开篇问题更准确的答案是：模型学到的是（颜色, 频率）的联合模式，可以被推进另一个模式；没有证据表明存在一个与颜色解耦、“学会了但没用上”的正确运动。
建议
报告编辑后未来颜色的分布；把“物理跟随且颜色保持”单列为一个类别。
H2 · 高“被位置和速度组织”的 4 维编辑，一个纯换色位置编码也能复现同样的统计›
论文说
“Boundary position and velocity organize the write”；目标相关相位 R² .83–.88 vs 仅方向 .51–.60；方向定 PC1、相位定 PC2–PC4；held-out 出现相位有序的环。
实际
aligned/conflict 只在球像素上不同；Short 下只落在 latent 15/16 的少数 token；球的位置由 (x*, v*, ω) 完全决定。§6 的玩具不经过任何网络，得到 仅方向 ≈.55、共享相位 ≈.59、目标相关 ≈.89、相位平面 .93/.89（σ=.45）；σ=0 时也是 .48/.50/.78。B.6 里一个与状态无关的常量编辑已能拿到 47.6% 严格成功。
为什么重要
“物理结构化”是全文从“能改写”走到“模型内部有物理解”的桥。这些统计分不开“物理表征”和“视网膜式位置编码”。作者在项目页承认 “does not establish a pure physics representation”，但正文措辞容易被读成更强的结论。
建议
在已发布的 wan-neutral-only-10k（对色调不敏感）上算红−蓝配对差，走同样流程；再报告 Top-4 基在 token 上的空间分布。
H3 · 高“更多可见运动推迟承诺”与“编辑本身大 8 倍”混在一起›
论文说
“More visible motion delays commitment”（Fig.4d、Table 6、Fig.32；Pendulum 同）。
实际
Long 中彩色球出现在全部 17 个条件 latent，Short 只有 2 个；gain-1 替换的覆盖面和范数都不可比，没做范数对齐。严格库不配对；Long 慢目标在 B、C 里 0/4,096 合格，只能比快目标；三个 run 的差 +13 / +2 / +4 很不均匀。
为什么重要
这是论文“支持物理解就能保持可写”的两条证据之一；另一条（Wan 课程）才没有这个混杂。
建议
Long 历史的早期帧用灰球，或对编辑做范数/覆盖面对齐后再比。
M1 · 中“承诺之后信号仍在”不是在自然冲突 run 上测的›
论文说
“The motion signal nevertheless remains”；与 Kalman 可观测/可控的类比。
实际
Fig.6a 的信号 = 在更早可写位点成功写入后，未来 token 的差在 aligned−conflict 方向上的投影；V 头放大的 ΔV 也来自控制器改写后的 run。
为什么重要
“可观测”那一半没有被直接测量。观测帧里始终有运动信息（它就是输入），这本身不说明未来 token 里保留了被放弃的那个未来。
建议
在自然冲突 run 的每层 future token 上训练线性探针解码历史频带。
M2 · 中Q/K/V 分解：正文说测的是未来帧的 Q，表格和代码恢复的是条件 token 的 Q›
论文说
“Restoring Q tests the queries issued by future-frame tokens … Future-frame queries therefore obtain the motion-controlling information from observed-frame K/V.”
实际
Table 7 标题 “restore natural-conflict condition components”；attention.py（“Condition-only Q/K/V hooks reused from the paper experiments”）只改条件行并断言未来 token 不被直接改动。另外，“必须经过 K/V”是结构必然。
为什么重要
“恢复 Q 无效”并不检验未来帧的查询；§5 的新增信息主要在头级别，而头级别在三个 run 间不一致，聚合的单 V 恢复 ΔR = −.003 [−.456, +.005]。
M3 · 中跨 run “迁移”用的是目标 run 自己的 PCA 基›
论文说
“Different natural behavior can coexist with a shared causal edit space … behavioral differences may arise from how downstream computation uses a shared physical solution.”
实际
源控制器预测 4 维坐标 → 在配对轨迹上拟合的“尺度 + 4×4 正交”映射 → 用目标 run 的基重建（B.11）。
为什么重要
它证明的是“各 run 的 4 维坐标都是同一组相位特征的相似函数”——H2 的位置编码下这也必然成立；不等于一个模型的激活编辑能直接用于另一个模型。结论句是假说。
M4 · 中“物理正确”只是“落在哪个频带”›
论文说
physics-following / restores the correct motion。
实际
物理跟随 = ω̂ 落在历史频带（带宽 0.8 / 1.2 rad/s）；R 以 aligned 输出为 1，而不是 ωtrue；没有报告带内 ω̂ 与 ωtrue 的关系；控制器只在两个目标族上验证（附录自承不能控中间频率）。
为什么重要
任务本质上是嵌在视频里的二分类。“模型会外推物理”与“模型会在两个模板间选一个”在这些指标下分不开。
M5 · 中标题数字要配上分母›
论文说
“At λ = 8, the physics-following rate peaks at 56.3%”；控制器 85.9% 落入窗口。
实际
同一批 48 条上 oracle 全编辑物理跟随 50.0%；V 头写入 22.9% 越界；λ 在同一批上扫峰；λ=16 大多越界；仓库单例自检 R=1.82。B.6：oracle 的严格频带成功率只有 75.3%，控制器 68.9%。“恢复窗口”(.75<R<1.25) 比“落进频带”宽松得多。
为什么重要
“能恢复”是真的，但离“稳定地把运动改对”还有明显距离，且强依赖增益标定。
M6 · 中训练动力学的效应量偏小，且依赖未发布的 15-seed 集合›
实际
总体 D 从 10.88 降到 9.55（−1.33），固定身份后 −0.62 [−1.48, −0.11]——约一半是构成效应；命运预测 Δ=3.79 位点，调整后的 AUC 没有给出数值（Fig.24b 坐标轴范围 .6–.8）；Wan 版在 10K 衰减，可写性可“关上又打开”。
为什么重要
“early writability predicts which errors training later corrects”是摘要级主张，证据方向成立但预测力中等，也没有和更便宜的置信度代理比。
M7 · 中Free Fall 并没有复现“捷径接管”›
实际
色调只让 ĝ 在历史一致的族内偏移，不切换区间（Fig.19）；“失败”定义为 |ĝ−g| ≥ .002；边界状态固定，控制器只有 g 一个变量；64 个输出颜色全被改。
为什么重要
它复现的是“小偏差可纠正 + 很早闭合（B1→B2）”，不是论文主线的模式选择。正文说它“extends it to non-oscillatory dynamics”时没点明这一点。
M8 · 中预训练 Wan 部分：细节缺失、n 小、行为效应在意料之中›
实际
无适配超参与代码；闭合证据 17 条、单方向；Neutral 路径多训 10K 步；与 simplicity bias 文献一致但未讨论；“跨模型尺度”只在同一玩具任务上。
为什么重要
摘要写 “supporting generality across model scale and training regime”，但离“真实预训练世界模型里的自然捷径”还很远——作者在讨论节也承认这是开放问题。
L1 · 低Pendulum 的评估器明显更宽松，且只有单 seed›

检测 ≥50%（Spring ≥90%）、缺失段 ≤12 帧（≤3）、跳变 ≤30 px（≤12）、拟合 RMSE ≤.12（≤.035）。结论方向一致，但数字不宜与 Spring 并列比较。

L2 · 低两个“持续失败”队列大小对不上：953 vs 886›

Fig.4c / 24 用 n=953（“六个 checkpoint 都走捷径”），Fig.23 用 886（“六个 checkpoint 都是严格捷径失败”）。定义不同可以解释，但论文没对账。

L3 · 低极小数据、极多 epoch›

每种设置 2,048 条视频，50K × bs32 ≈ 781 个 epoch（100K ≈ 1,562）。这是一个接近记忆的训练状态，与大规模世界模型的训练很不一样；捷径如何形成可能也不同。

L4 · 低“donor-free”控制器依赖仿真器真值›

输入是真值 x*、v*、ωtrue；基用供体对拟合。作为可解释性工具没问题，但不能直接迁到真实视频模型（那里没有“物理变量”可读）。

L5 · 低“闭合”“尖锐”“point of no return”的措辞偏强›

闭合是相对“gain 1 替换 + .75–1.25 窗口”定义的，更强的写入能在闭合后改写；Spring 的“尖锐”主要体现为总体曲线上的窄区间，逐轨迹尖锐性是断言；Wan 的闭合是 17 条的中位数。论文正文多处写了“for that write”，讨论节的 “point of no return” 则没有这个限定。

L6 · 低分析分叉很多，没有预注册›

严格库、selection-clean、qualified intersection、common-strict、checkpoint-local……；R 窗口、功能位点规则（≥75%）、头的选择、增益取峰。fit/held-out 切分和冻结清单缓解了很多，但自由度仍大。作者声明大量使用 AI 编码智能体参与假设、实验设计、分析与写作（最终决定由作者作出）——透明，但也提示需要独立复现。

L7 · 低复现包的文档与状态有出入›

几处文档仍写着“私有 / 未发布”；Pendulum 基不分发、需重建；Free Fall 未做独立 GPU 复现；Wan 无代码。可复现性声明承诺“all hyperparameters”，目前 Wan 部分未兑现。

§13 · 做对的地方

值得学的方法论

  • 用解码后的像素打分。确定性追踪器 + 频率拟合，不靠内部探针、不靠 VLM 打分。“内部有信息”和“能改变输出”被严格分开，这个框架本身有价值。
  • 严格反事实配对。同轨迹、同噪声、只换球的颜色；代码里用去掉球像素后的 hash 检查非球像素完全一致。
  • fit / held-out 分离。基、系数、尺度、模型选择都只在拟合集上定，冻结后再测；多 seed（3 个机制 run + 15 个纵向 run）和分层 bootstrap。
  • 附录很诚实。颜色耦合、“不是纯物理表征”、跨组件剂量不可比、Free Fall 的失败定义、Long 慢目标无样本，都写出来了。
  • 数字自洽。我核对过的每一处都对得上（见下）。
  • 发布了可以跑的东西。16 个 checkpoint、3 个控制器、带冒烟测试的编辑 CLI。
我核对过的数

  • Fig.2 的 “23/26” = Run A：(8+15)/(10+16)
  • Table 3 每行加总 = 100%（±0.1 舍入）

§14 · 对交互式世界模型的启示

能带走什么，以及五个最值得做的后续实验

  • 历史 K/V 就是方向盘。在“前缀条件”模型里，历史帧只能通过 K/V 影响未来；对自回归世界模型，这对应 KV cache。编辑或放大历史 K/V（而不是改输入）是一条可控性通路；反过来，KV 压缩 / 驱逐可能恰好丢掉“弱但正确”的那部分信号。
  • “决策深度”可以当诊断信号。一个错误在第几层之后改不动，大致反映模型对它有多确定——可以用来挑训练或蒸馏时值得重点照顾的样本，但得先证明它比便宜的置信度代理更好。
  • 课程顺序很便宜也很有效。游戏、驾驶数据里外观和速度高度相关；先在外观无信息的数据上学动力学，再引入真实分布，是一个几乎零成本的实践建议——Wan 实验里效果是 9.4% → 80.5%。
  • 不能直接搬的地方。论文模型是双向 DiT + 20 次 FM 调用，频率在 σ′≈.83 之后才锁定；4 步蒸馏的因果学生模型的“时间分配”完全不同，闭合位置和写入窗口都需要重测。
