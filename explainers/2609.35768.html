PDMD — 把 critic 误差"投影掉"的一行 DMD · 精读

分布匹配蒸馏（DMD）能把几十步的视频扩散模型压到 4 步。它的毛病是训练越久，画面越"油"：先过饱和，再出斑点纹理，最后崩掉。作者把病根归到在线 critic 的误差上。PDMD 只改一行：对每个样本连一条"学生样本 → critic 去噪端点"的线 r，把 DMD 更新里平行于 r 的分量删掉。在 Wan2.1-1.3B 和 MiniMax-H3-33B（音视频联合）上，DMD 会退化的训练 PDMD 能稳住。4 步 VBench 83.73（同配置 DMD 82.70），H3 上 83.17（最强基线 82.76），音频 6 项全部第一。

我的判断。方法确实有用，但它起作用的方式比论文说的更"粗"，代价论文也没讲。
  1. 稳定性的证据扎实。在 H3 上用同一学习率，DMD 过了 500 步就一路下滑，2500 步时掉到 70.07；PDMD 在 3000 步内总分一直停在 82.7–83.1。Wan 上也一样：DMD† 在 1500 步见顶，5000 步掉到 63.04，7500 步掉到 56.09；PDMD 5000 步是 83.44，到 10000 步都在 83.5 以上。作者还做了三组对照：把投影换成另外四种方向、把删掉的分量放回一半、把学习率调到 1.25 倍。这三组基本排除了"只是步长变小了"的解释。
  2. 两个与 PDMD 完全等价的写法。论文附录 A.2 已经把投影放进"从 d 里减掉一部分 R"这一族，并指出它的系数渐近等于最优系数；我补的是两个精确恒等式。第一种：先把样本直接拉向教师的去噪端点（这就是 SDS 式回归），再删掉沿 r 的分量。第二种：对每个样本，在 DMD 更新和 SDS 更新之间插值，权重 λ̂ = ⟨d,r⟩/‖r‖² 由数据自动决定。这一族的另一端（整个减掉）恰好就是 SDS，论文没点破。两种写法都说明，critic 端点离学生样本多远这个信息被整个丢掉了，只剩一个方向。
  3. 理论的衡量尺子没对准。论文比的是"单个样本的更新离理想更新有多近"，但 SGD 累积的是期望梯度的偏差。投影把一部分 critic 误差换成了"把样本拉向它自己的后验均值"这一项，这一项在期望里不会被平均掉。我在高维高斯玩具里验证过：critic 只带无偏噪声时，DMD 学到的学生标准差停在老师的 1.00，PDMD 缩到 0.74（噪声能量为条件方差的 1/4）甚至 0.30（两者相等）。论文 Table E1 里，PDMD 的饱和度和色度在两个底座上都低于 50 步老师，方向与此一致（不过 Wan 上的 DMD2† 同样偏灰）。多样性论文没有测。
  4. 分数上的领先很薄。H3 上领先的 +0.41，全部来自 dynamic degree 这一维：它贡献 +0.62，其余维度合计 −0.20。我从 Fig D3 复原了 PDMD 稳定训练段的各检查点，它们总分的标准差约 0.22。Wan 上去掉 DD 重算后，PDMD 的 Quality 从第 1 名掉到第 5 名。H3 人评中，50 步老师对 PDMD 的净胜率仍有 37 个百分点。

01它在解决什么

少步蒸馏要把一个几十步的"老师"压成只跑几步的"学生"。DMD 是其中最常用的一类，自回归视频世界模型里的 CausVid、Self Forcing 也用它。DMD 的已知毛病是训练会自己变坏：分数先升后降，画面越来越饱和，出现与提示无关的纹理，最后塌掉。论文 Fig 2 显示，在 MiniMax-H3 上，DMD 和 DMD2 到第 500 步就已经"油"了。

病根（论文的说法）

DMD 的学生更新是 critic 分数减教师分数。critic 边训边学，拟合有误差，还会跟不上一直在变的学生。它的误差原样进入每一步学生更新，一步步累积下去。

改动

把 critic 的分数换算成一个去噪端点 x̂₀ᶜ（DMD 本来就算），连一条线 r = x̂₀ᶜ − x̂₀ˢ，再把更新 d 在 r 方向上的分量删掉。整个改动就一行，零额外成本。

证据

① 定理：在固定查询下，r 是 critic 误差的无偏估计。高维下，投影删掉常数比例的误差，而理想信号只损失趋于零的比例。② 2D 玩具。③ 两个视频底座，外加"换成另外四种方向"的投影消融。

为什么 critic 的误差会越滚越大（直观版，我的举例）

设想学生正在变得越来越"鲜艳"，而 critic 跟得慢，还以为学生的画面比较灰。那么 x̂₀ᶜ 会偏灰，更新里"远离 x̂₀ᶜ"这一项就继续把学生往鲜艳的方向推。学生更鲜艳了，critic 又没跟上，于是形成正反馈，这就是过饱和的一种来源。论文 A.3 用延迟反馈方程 dΔ/du = −λΔ(u−τ) 把它形式化了（§06）。

03一行改动，和我推出的两个等价写法

论文的 Algorithm 1 就是下面这段。高亮行是与 DMD 唯一的不同。

x_0_s = G(z, cond)                      # 学生样本
x_t, t = renoise(x_0_s)                 # 式 (1)
s_t = T.score(x_t, t, cond)             # 教师分数
s_c, x_0_c = C.score_end(x_t, t, cond)  # critic 分数与端点（本来就有）
d = s_c - s_t                           # 式 (2)
r = x_0_c - x_0_s
d = d - dot(d, r) / dot(r, r) * r       # 式 (4)：删掉平行于 r 的分量
update(G, dmd_loss(x_0_s, d))
d⊥ = Pr⊥ d = d − (⟨d, r⟩ / ‖r‖²) · r , r = x̂₀ᶜ − x̂₀ˢ论文式 (3)(4)；r = 0 时不改

人话：在固定的 xt 下，理想 critic 的端点是"会被加噪成 xt 的那些学生样本的平均"。所以 r 可以拆成两部分：critic 的误差，减去"这个样本偏离平均的那部分"。后一部分平均下来是 0，所以 r 平均起来就指向 critic 误差。PDMD 的做法是：既然这个方向上混着误差，就把更新在这个方向上的分量整个删掉。

我的推导 · 两个与 PDMD 完全等价的写法（精确的代数恒等式，已用数值验证到 1e-15）

在端点空间记 uDMD = x̂₀ᵀ − x̂₀ᶜ（DMD 的移动方向），uSDS = x̂₀ᵀ − x̂₀ˢ（直接把样本拉向教师端点，也就是 SDS 式回归），rT = x̂₀ᵀ − x̂₀ˢ。标量系数 αt/σt² 不影响方向，下面省略。

(A) uPDMD = −d⊥ = Pr⊥ ( x̂₀ᵀ − x̂₀ˢ )因为 d = r − rT，而 Pr⊥r = 0
(B) uPDMD = (1 − λ̂) · uDMD + λ̂ · uSDS , λ̂ = ⟨d, r⟩ / ‖r‖²逐样本插值，权重由数据决定
  1. critic 的输出只剩一条轴。由 (A)，把 x̂₀ᶜ 沿着 x̂₀ˢ→x̂₀ᶜ 这条直线任意挪动，甚至翻到另一侧，PDMD 的更新都不变。DMD 里 critic 那一项"把样本推离自身均值"的力，被整个删掉了。
  2. 两个极端。当 λ̂ → 0（critic 误差远小于样本自身的散布）时，PDMD 就是 DMD。当 λ̂ → 1（critic 误差占主导）时，它退化成 SDS：只剩教师回归，不再有 critic 的反推。SDS 本身很稳，因为它不依赖 critic；但它的已知毛病是 mode-seeking，会把样本往后验均值拉，于是方差缩小、画面发灰发平。
  3. 论文附录 A.2 的"无偏减法"（λ=1）就是 SDS。论文考察了 d − λκR 这一族，指出投影的系数渐近于其中的最优值 κλ*，并说 λ=1 会"注入全部条件噪声 κ²τ"。其实 d − κR 按代数就是纯 SDS 更新，那个"条件噪声"正是 SDS 回归到均值的问题。论文通篇没有用 SDS 这个词；所以 (B) 与论文的渐近说法一致，我补的是它的精确形式，以及 λ=1 那一端是什么。
  4. 高维下 λ̂ ≈ a/(a+τ)（端点单位；a 是 critic 误差能量，τ 是条件方差 tr Σ，并假设 d* 与 e 弱相关）。这与论文推导的"最优固定减法系数 λ* = a/(a+τ)"吻合。也就是说，PDMD 每个样本都在自动估计"这次 critic 有多不可信"，并按这个比例往 SDS 那边偏。

这对理解消融有用。论文的 2D 实验和 H3 实验都试了"删掉别的方向"，其中两个对照恰好是镜像：

  • 删掉教师残差方向：更新 = −P⊥rT r。教师的"拉力"整个没了，只剩 critic 的"推力"。2D 中它在第 3000 步附近出现能量距离尖峰，后 1000 步的平均能量距离被拉到 2.04；H3 上它也会退化。
  • 只保留平行分量（critic endpoint residual ∥）：只剩 PDMD 删掉的那部分。在 H3 上它退化得最快，到 3000 步时每条提示都生成同一种与提示无关的"鹅卵石纹理"（Fig D1）。

05论文的理论：为什么 r 能估计 critic 误差

把一次查询 q = (xt, t, c) 固定住，考虑"会被加噪成这个 xt 的学生样本"构成的条件分布。

c*(q) = 𝔼[x̂₀ˢ | q]
理想 critic 的端点（ℓ₂ 去噪损失的最优解，Lemma A1）
e = x̂₀ᶜ − c*
critic 误差，在固定 q 下是一个确定的向量。记 a = ‖e‖²
ξ = x̂₀ˢ − c*
这个样本相对条件均值的偏离，也就是"加噪后无法从 xt 推断出来的细节"。𝔼[ξ|q] = 0，记 τ = 𝔼‖ξ‖² = tr Σ(q)
R = x̂₀ᶜ − x̂₀ˢ = e − ξ
PDMD 实际用来投影的方向。𝔼[R | q] = e（式 7），所以说它是 critic 误差的无偏估计
γe(R) = ‖PR e‖² / ‖e‖² , 𝔼[γe | q] ≥ a / (a + τ) , 高维下 γe ≈ a / (a + τ)式 (9)(10)(11)，Thm A2

下界来自 Cauchy–Schwarz，推导没问题。高维近似要求两个集中条件：‖ξ‖² 集中在 τ 附近，且 ξ 与固定方向 e 几乎正交。另一方面，理想信号 d* 的方向如果与 e 和 Σ 都只是"弱对齐"（假设 A28），被删掉的比例 γs = O(1/deff)。两者合起来就是论文的卖点：误差删掉一个常数比例，信号几乎不损失。

我的改写 · 投影后的残余误差就像"并联电阻"

把论文式 (A35) 展开（Lagrange 恒等式），投影后残下的 critic 误差能量是

‖PR⊥ e‖² = (‖e‖²‖ξ‖² − ⟨e,ξ⟩²) / ‖e − ξ‖² ≈ a·τ / (a + τ)比 a（DMD）和 τ（SDS）都小

DMD 保留全部误差 a；"把误差估计直接减掉"（也就是 SDS）换来的是全部条件噪声 τ；PDMD 得到两者的"并联值"，永远小于 min(a, τ)。这就是论文说投影逐样本更接近理想更新的原因。但要注意：这里比的是逐样本的均方误差，而残留部分的"方向"在 §07 里会出问题。

存疑 · 一个方向带走 ¼ 的能量，与"弱对齐"假设有张力

06critic 滞后与稳定性

附录 A.3 讨论的是另一种误差来源：critic 不是"学不准"，而是"跟不上"。它看到的永远是若干步之前的学生。

模型（Lemma A7–A8）

目标分布有两个分离的模态，学生把比例 π 的质量放在模态 +。记偏差 Δ = π − π*。如果 critic 是最新的，偏差按 dΔ/du = −λΔ 回归。如果 critic 滞后 τ，就变成

dΔ/du = −λ Δ(u − τ)

它稳定当且仅当 λτ < π/2。这是经典的延迟方程结论（Hayes 1950），证明我核对过。

PDMD 的作用（Cor A9 + 启发式）

纯滞后时，𝔼[r|q] 正好等于滞后误差，投影后在均方意义上最多保留

ρ = τ / (‖elag‖² + τ) < 1

把 ρ 当作常数增益，稳定条件就变成 ρλτ < π/2。论文自己说明这只是启发式：ρ 是期望能量比，会随查询和 critic 状态变化，而且投影也会作用在理想更新上。

07我的推导：投影不是免费的——收缩偏置

论文所有的保证（式 A35、A36、Cor A6）比较的都是同一件事：单个样本的更新离理想更新 d* 有多近。可 SGD 是把成千上万个样本的更新加起来。零均值的误差会在求和里抵消，不抵消的是偏差。

推导（沿用论文记号，κ = αt/σt²）

令 d = d* + κe。因为 e = R + ξ 且 PR⊥R = 0，有 PR⊥e = PR⊥ξ。于是 PDMD 更新 u = −d⊥ 相对理想更新 u* = −d* 的误差是

u − u* = PRd* − κ PR⊥ξ ≈ PRd* − κ·τ/(a+τ)·e − κ·a/(a+τ)·ξ高维近似；D=16384 时相对误差 0.5%（我的蒙特卡洛）
  • 第二项是剩下的 critic 误差，按 τ/(a+τ) 缩小了。这就是论文强调的部分。
  • 第三项是新多出来的：−κλ·ξ = κλ·(c* − x̂₀ˢ)，把每个样本拉向它自己的后验均值，权重 λ ≈ a/(a+τ)。DMD 里没有这一项，因为 d = κ(x̂₀ᶜ − x̂₀ᵀ) 中 ξ 恰好抵消了。
  • 在固定 q 下 𝔼[ξ|q] = 0，所以论文认为它是"会平均掉的噪声"。但学生的参数梯度是 Jθ(z)⊤u，而 ξ = Gθ(z) − c* 由同一个 z 决定：𝔼[Jθ⊤ξ] = ∇θ 𝔼 ½‖Gθ(z) − sg(c*)‖² ≠ 0。这正是 SDS 那种"回归到均值、压缩方差"的梯度，它不会被平均掉。

结论：如果 critic 误差中有一部分是与样本无关的零均值噪声（小批量、单步更新的 critic 必然有），DMD 在期望里不受这部分影响，PDMD 却会把它转化成一个方向一致的收缩力。如果误差是系统性的（例如滞后），PDMD 能把它压小，但同时引入这个收缩力。两种情况下它都是在拿偏差换方差。

10存疑清单

一共 15 条，按严重程度排。"高"指会动摇主要结论或核心解释，"中"指影响结论的力度，"低"是细节。

01高理论比的是逐样本误差，SGD 累积的是偏差；投影引入了一个不会被平均掉的收缩项

Cor A6 保证"单个样本的更新更接近 d*"。但投影后的残差是 κPR⊥ξ ≈ κ[(a/(a+τ))ξ + (τ/(a+τ))e]，其中 ξ 那一项把样本拉向它自己的后验均值。经过生成器雅可比之后，它在参数空间的期望不为零，是 SDS 式的方差收缩梯度。零均值的 critic 噪声本来会在 SGD 里抵消，现在被转换成了方向一致的偏差。高维高斯玩具中，无偏 critic 噪声 ρ=0.5 时 PDMD 的不动点标准差为 0.74，DMD 为 1.00。

依据：§07 推导与图 9；论文式 A35–A38 只分析了能量，没有分析方向。

02高PDMD 本质上是逐样本的 DMD↔SDS 插值，critic 的幅值被整个丢掉；论文没有报告插值权重

恒等式 uPDMD = Pr⊥(x̂₀ᵀ − x̂₀ˢ) = (1−λ̂)uDMD + λ̂uSDS。论文 A.2 已经给出这个系数的渐近形式，但没有点明插值的另一端是 SDS。在 critic 误差大的区域（λ̂→1），PDMD 退化为纯教师回归，SDS 的已知毛病（mode-seeking、过平滑、方差塌缩）就会回来。论文把它描述为"过滤误差"，但 λ̂ 按噪声水平和训练阶段的分布一次都没报告。视频上唯一能看到的相关量是范数保留比，约 88%。

依据：§03 恒等式（数值验证到 1e-15）；论文 A.2 "Projecting versus subtracting" 里 λ=1 的选项就是 SDS。

03高"饱和度更低"不等于"更像老师"：两个底座上 PDMD 都比 50 步老师更灰；多样性完全没测

Table E1：Wan 上 PDMD 饱和度 0.476、色度 17.9，老师 0.587、21.5；H3 上 PDMD 0.357、14.0，老师 0.405、15.0。H3 上 rCM† 和 AnyFlow† 离老师更近。PDMD 偏离老师的方向，与 01 推出的收缩偏置一致；但 Wan 上 DMD2†（GAN 正样本来自更灰的 H3）也一样偏灰，所以这只是方向一致，不是独立证据。作者在局限里承认"没有确立跨提示、跨种子的多样性保持"。对需要多样未来的世界模型来说，这一项恰恰最要紧。

依据：图 10；论文 §F。

04高H3 上 +0.41 的领先全部来自 dynamic degree；Wan 上 "Quality 第一"也全靠它

按 VBench 权重拆解，H3 上 PDMD − DMD† = DD +0.62，语义 −0.04，其余六个质量维度 −0.16。去掉 DD 重算，DMD† 84.15 高于 PDMD 83.93。Wan 上去掉 DD 后，PDMD 的 Quality 为 85.57，排在 AnyFlow 87.43、DMD2† 86.60、老师 86.39、rCM 85.73 之后，列第 5。DD 是只看"动没动"的二值光流指标。PDMD 在 H3 上确实动得更多（多 39 段，人评运动项 +12.1），所以这一维不是噪声；但论文把这写成"领先总分"，而不是"动得更多"。

依据：图 11、图 12；VBench constant.py（DD 权重 0.5，归一化区间 [0,1]）。

05中基线配置对 PDMD 有利：Wan 上的 DMD† 是"慢 critic"，缺少 DMD+TTUR；DMD2† 用了外部模型的正样本

Wan 上的 DMD† 采用 1:1 更新，critic 学习率只有学生的 1/5。按论文自己的理论，这正是 critic 最容易滞后、PDMD 最占便宜的设置，而且 Wan 上没有做学习率搜索。最自然的强基线是"DMD + 5 步 critic（不加 GAN）"，但 Wan 上没有这一组。DMD2† 的判别器正样本来自 MiniMax-H3 生成的视频，已经不是标准的 DMD2。H3 上 DMD2† 的最佳点是第一个检查点（500 iter，约 83 次学生更新），说明这套配方在 H3 上几乎没有被调好。

依据：Table C1、§C.1–C.2。

06中没有多种子，也没有置信区间；检查点在测试提示上挑选；领先幅度只有约一个检查点标准差

Wan 上三条自训练曲线都报告"在评测集上最好的检查点"（1500 / 6500 / 5500），而 rCM、ADV、AnyFlow 用的是官方发布的权重，没有这个待遇。对 DMD† 来说，挑峰值反而是照顾它（它 5000 步就掉到 63.04），所以这一条影响的是与外部基线的比较，而不是与 DMD† 的比较。H3 上 PDMD 稳定段各检查点的标准差约 0.22，对 DMD† 的领先是 0.2–0.4。Wan 上 PDMD 对 AnyFlow 高 0.19、对 DMD2† 高 0.29，都在常见的评测噪声之内。项目里 UnStep 的笔记记录过：同一配置换一种 GPU，VBench 会漂移 0.2–0.34。

依据：§C.1 检查点说明；图 16。

07中高维"弱对齐"假设无法验证，且与"一个方向带走 23% 能量"有张力

在百万维的潜空间里，单一方向平均只该分到约 1/D 的能量，而 PDMD 中位删掉 23%。按论文理论，这部分几乎全是 critic 误差，于是 critic 误差至少占更新能量的 23%；另一种可能是 A28 不成立，删掉的里面有真信号。2D 里 PDMD 的 γs = 0.57，也高于随机方向的 0.50。论文拿"解码后的被删分量看起来像斑点"（Fig E1，只有一个 step 的 12 张图）作为间接证据，这比较弱。

依据：图 6、Table B1、Fig E1。

08中自动指标与人评方向相反：H3 上 Total 超过老师，人评却以 −37 输给老师

H3 上 PDMD 的 Total 83.17 高于 50 步老师的 82.41，但人评总体 −37.0、视觉 −35.4。Wan 上反过来，PDMD 在人评中赢了 50 步老师（视觉 +17.6、运动 +24.3）。作者在局限中也提到了"自动指标的局限"。这说明在这个精度上，VBench 式总分不足以支撑"领先"的结论；论文最硬的证据是训练稳定性，而不是分数排名。

依据：Table 2、C3、C4。

09中滞后稳定性只是标量启发式；在同一个滞后模型里，PDMD 可能掉进"零方差吸收态"

把 ρ 当作常数增益、得到 ρλτ < π/2，作者自己说是启发式。我用论文 A.3 的滞后模型（critic = L 步之前学生的精确后验）做了高斯实验：滞后 25 步时，PDMD 确实压住了振荡；滞后 30 步时，DMD 振荡后恢复，PDMD 却收缩到 a≈0 出不来。在两模态实验（lr 2e-3 组）里，critic 分数方向的投影（0/20）塌得比 PDMD（3/20）还少。

依据：图 7、图 8a、图 9。

10中可复现性：只有 H3 推理代码

仓库里只有 MiniMax-H3 的推理脚本（24 GB 卡、int8、每个视频约 31 分钟）和三个权重。论文承诺的训练代码、2D 代码和 Wan 学生权重都还没有放出。论文文字交代了几件事：投影作用在归一化之前的原始分子上，两个目标共用同一个归一化因子 Z（E.1）；Wan 的老师在分布匹配中用 CFG 5；视频和音频分开投影（C.2）。但没有代码，就无法核对 Z 的具体定义、"每卡 1 个样本"这个前提是否必要，以及其它实现细节。

依据：GitHub README（2026-09-30 查）；论文 Reproducibility Statement。

11低项目页上的代码片段在 batch>1 时会变成"整批共用一个方向"

项目页给的是 d = d - (d*r).sum() / r.pow(2).sum() * r。.sum() 对整个张量求和，包括 batch 维。论文训练恰好是每卡 1 个样本，所以没有暴露问题；换成每卡多个样本（例如 Self Forcing 的设置）就会变成另一个算法。正确写法是按样本、按模态分别求和（sum(dim=(1,2,3,4), keepdim=True)）。

12低2D 结果的呈现偏向 PDMD

引言里只引用了 3/20 对 14/20；正文 §4.2 其实也报了小步长组（PDMD 12/20、DMD 19/20）。只出现在附录的有两点：critic 分数方向的投影 0/20（只在 lr 2e-3 组测过）；在全部噪声水平上，critic 分数方向的 ν（0.88）略好于 PDMD（0.89）。另外，Exp 1 每个变体的训练曲线只跑了一个种子。

13低H3 上 rCM† / AnyFlow† 是打了折扣的移植

JVP 换成了有限差分，学生更新次数只有 400 和 1500，学习率只扫了 3 档。它们在 H3 上排名靠后，有多少来自方法本身、多少来自移植，无法分辨。好在论文的主结论只依赖对 DMD† 的比较。

Fig 1 写的是 1366×768，而论文自己的 Fig D1、项目页和 README 都是 1344×768；1366 也不是 16 的倍数，应是 Fig 1 的笔误。Table 2 与 Table C4 的净胜率有 0.1 的舍入差（例如 Turbo 总体 34.6 对 34.7）。VBench 通常是 946 条提示，这里是 AnyFlow 协议下的 944 条。Fig 1 的 14.4 s、768p 演示长于训练和评测用的 5 s、544p，这部分没有定量评估。

11公道话，以及对交互式视频世界模型的启示

做对了的

  • 改动极小，零额外成本，任何现成的 DMD 训练都能直接试。
  • 把"稳定"单独拿出来测：换成另外四种方向的投影、放回一半分量、学习率 ×1.25、1:1 更新比，每组都只改一个变量。
  • 在 2D 里直接测 γe、γs，而不是只看下游指标；证明部分我核对过，没有发现错误。
  • 主动写出不利结果：H3 人评仍输给老师，1 NFE 不行，多样性没有确立，理论假设在视频上无法验证。
  • 给出了票型分布和饱和度表，第三方可以据此复核。本页的许多存疑，正是用论文自己给的数字算出来的。

对 Self Forcing 类世界模型蒸馏

  • DMD 训练一旦出现过饱和或越训越差，PDMD 值得作为第一个尝试：按样本投影，动作、音频等模态各自单独投影，可以和 TTUR 叠加。
  • 同时监控四样东西：按噪声水平统计的 λ̂ 分布、范数保留比、相对老师的饱和度和对比度，以及同一提示多种子的多样性。世界模型需要的是"多种可能的未来"，收缩偏置会直接削弱规划时的分支覆盖。
  • 保守一点可以用 β∈(0,1) 的部分投影，或者只在高噪声段投影。论文 D.3 显示 β=0.5 前 2000 步和 PDMD 一样好。
  • 项目里的 DyMD（2609.31349）和 Uncertainty-DMD（2609.11265）都在处理 DMD"不动"或"不多样"的问题。PDMD 让画面动得更多（DD 升高），但可能让多样性变少，把它们组合起来测会很有信息量。

最值钱的后续实验

  1. 多样性：每条提示 8 个种子，比较样本间的 LPIPS / DINO 方差，对照老师、DMD 和 PDMD，并同时报告像素标准差和高频能量。
  2. λ̂ 日志：训练中按 σ 分桶记录 ⟨d,r⟩/‖r‖²，看它在哪些噪声段接近 1（也就是在那些段上接近 SDS）。
  3. 强基线：在 Wan 上补 DMD + TTUR（不加 GAN），并做学习率搜索；3 个训练种子；在留出提示上挑检查点。
  4. 拆开 DD：分别报告"去掉 DD 的 Total"和光流幅度、warping error，区分"动得更多"和"抖得更多"。
  5. β 与 σ 分段：β∈{0.25, 0.5, 0.75}，以及只在 σ>σ₀ 时投影，看能否既保住稳定性又减轻收缩。
  6. 可学习 critic 的高斯 / GMM 玩具：改变 critic 的容量和更新步数，测 PDMD 不动点的方差偏差，给收缩偏置在"真实 critic 误差结构"下定量。
一句话

PDMD 是一个便宜、稳定、立刻就能用的 DMD 补丁，它让训练曲线"不塌"。但它是按样本在 DMD 和 SDS 之间自动插值，稳定性的一部分是用"向均值收缩"换来的。用在世界模型上时，要把多样性和相对老师的色彩统计一起盯住。
