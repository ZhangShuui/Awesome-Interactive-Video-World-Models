LHFM 精读
一整套辛几何，最后落成一行 v = r − ∇J·u

论文先把每张图像写成余切丛里的一个精确拉格朗日子流形，再问：什么样的哈密顿流能把这族子流形一直保持成"图"？答案是 Hamilton–Jacobi 方程。由此导出的速度参数化，是一个搬运场 u加一个源项 r。这一页按推导顺序把每一层拆开：哪些是装饰，哪些真的进了代码，实验数字能说明什么、不能说明什么。

一页结论
  1. 数学是对的，但没有约束力。模型实际用的哈密顿量是 H = ξ⊤U − a⊤R，它对动量是仿射的。这类流把任何图都映成图，所以"HJ 条件"总能满足：任选 U，再令 R = ∂tF + DF·U 即可。论文自己也承认，几何"不限制图像速度"（命题 A.6），拆分也不唯一（注记 A.8）。
  2. 真正的新东西只有两样：一是速度参数化 v = r − DFJ·u，也就是带源项的平流方程；二是 LHFM-V 里一个做得很干净的数值求解器（二阶迎风 + uniformization 指数积分）。这个结构和光流亮度方程、metamorphosis、视频编码里的"运动补偿 + 残差"是同一类东西。
  3. 图像生成：FID 从 3.8241 降到 3.5809（相对 −6.36%），只多了 2,306 个参数。但只有一个种子、一个 checkpoint；本地 I-CFM 基线比 Tong 等人公布的 3.659 更弱；而且训练目标仍是像素直线插值 I − ε，理论最优速度场与 I-CFM 完全相同（§6）。
  4. 视频预测："循环模型里 FLOPs 最低"（13.1G，MSE 18.6）这个说法，依赖两件事：一张拼接起来的基线表（成本数字多数来自 OpenSTL，精度数字来自各原论文，多数训练更短、协议更老），和"只比循环模型"的划界。这些基线数字的来源论文 PredFormer 里，它自己的 3 层和 4 层版本（表 6）在参数、FLOPs、MSE、SSIM 四项上全部优于 LHFM-V，而且同样训练 2000 epoch（§8.2）。
  5. 我用论文附录 B.3 的数值格式做了 oracle 实验：给单个 MNIST 数字精确的真实速度、源项设为零，10 帧平均 MSE 约 34.5。论文报告的两个数字 MSE 只有 18.6。所以学到的 u 和 r 必然含有大量抵消数值耗散的非物理成分；"搬运 = 运动，源项 = 外观"这个解释没有被验证。论文里没有一个消融实验，也没有展示学到的场。

§01论文的推理链：哪几层进了代码

论文的论证分两层。上面一层是几何：图像 → 连续函数 → 生成函数 → 拉格朗日图 → HJ 引理 → 选定的哈密顿量。下面一层是落地：一个速度参数化，加两个模型。附录 B.3 在图像生成的数值实现里写了 "The Hamiltonian is not explicitly evaluated during sampling"。按论文对两个模型的实现描述，训练和推理只用到下面那一行，上面那层一步都不计算（后半句是我根据实现描述的归纳）。

§02动机：像素混合 vs 空间搬运

标准流匹配（FM）学的速度场作用在固定像素位置上的颜色值上。图像里的一个笔画往右移了 3 个像素，FM 只能表达成"左边这些像素变暗、右边那些像素变亮"。论文想要一种表示，把"东西在哪"和"东西什么颜色"放进同一个几何对象里，让动力学能显式地搬运空间结构。

§03拉格朗日图：探针 a 到底在做什么

这一节把论文 §4.1–4.2 的定义翻成白话。只有三步，每一步都不难。

1

把离散图像变成光滑函数。对每个通道做正交 DCT-II，保留全部 N×N 个系数，再用余弦基函数展开成连续函数 FI : ℝ² → ℝⁿ。它在像素中心上精确等于原图，处处光滑，可以求导，而且 I ↦ FI 是线性单射（定理 A.1）。偶延拓、周期为 2 是这个表示自带的边界约定。

2

引入"颜色探针" a ∈ ℝⁿ。定义生成函数 SI(x, a) = a⊤FI(x)。给定位置 x 和一个颜色方向 a，S 就是"这个位置的颜色在 a 方向上的投影"。例如 a = eR 读出红色通道；a = (eG − eR)/√2 读出"绿减红"的对比度。

3

取 S 的微分图。在底空间 Q = ℝ² × ℝⁿ 的余切丛 T*Q 上，坐标记为 (x, a; ξ, η)，典范 1-形式 λ = ξ⊤dx + η⊤da。S 的微分图是

LI = graph(dSI) = { ( x, a ; DFI(x)⊤a , FI(x) ) : (x, a) ∈ Q }式 (2)

它是精确拉格朗日子流形：λ 拉回到上面恰好等于 dS。这里的"拉格朗日"指子流形，不是作用量泛函，论文特意说明过。蓝色的 ξ = DFᵀa 表示"沿哪个空间方向，a 方向上的颜色变化最快"；橙色的 η = F(x) 就是颜色本身。

LI 上的一个点有 2(n+2) = 10 个坐标，对 RGB 图像而言：位置 2 个、探针 3 个、ξ 2 个、η 3 个。整个 LI 是 10 维空间里的一张 5 维曲面。

这个表示没有带来新信息：LI 里存的只有 F 和它的空间梯度。它的真正作用是记账：把 n 个通道打包成一个标量生成函数 S = aᵀF，这样后面就能直接套用标量 Hamilton–Jacobi 理论。在 a = 0 且 x 取像素中心时读出 η，就能无损恢复原图（命题 A.4）。

维数账

RGB、32×32 的情形：Q 是 5 维，T*Q 是 10 维，每个 LI 是 5 维子流形。但"所有图像"组成的族有 3·32·32 = 3072 个自由度。论文写道这个表示 "is not a compression to n + 2 scalar coordinates"：每张图对应一整张曲面，不是一个点。

和 WKB 的类比

表 1 把"FM 里的点"比作经典力学里的相空间点，把 LI 比作半经典 WKB 态 a(q)eiS/ℏ 对应的拉格朗日图。但振幅、ℏ、量子化在模型里都没出现。仓库名叫 Geometric_quantization_models，方法本身和量子化无关。

为什么用全频带 DCT

理论需要一个光滑的 F 才能谈 DF 和哈密顿流。代价是：对边缘和噪声求谱导数会放大高频（白噪声的梯度能量约是中心差分的 5 倍，见 §6 演示 F）。视频版干脆不用 DCT 导数，改成迎风差分（§7）。

§04哈密顿流就是特征线法：为什么"几何约束"不起约束作用

记 q = (x, a)，p = (ξ, η)，论文用的约定是 q̇ = ∂pH，ṗ = −∂qH（式 19）。哈密顿流一定保持"拉格朗日"和"精确"这两个性质，但不一定保持"是一张图"：子流形可能在动量方向折起来，某个 q 上方出现多个 p。论文的核心问题是：哪些哈密顿量能把给定的一族图 Lt 一直保持成图？

自由粒子的情形：q = q₀ + p₀t。只要 1 + t·cos q₀ = 0 有解，也就是 t ≥ 1，曲线就会出现竖直切线然后折叠，不再是图（这就是焦散）。平流型的情形：H 对 p 是线性的（或仿射的），q 的运动 q̇ = U(q) 和 p 无关，是底空间上的一个微分同胚，p 只做线性变换。任何图都会被映成图，最多变陡。这里取 U(q) = 0.5 + 0.35 sin q，W(q) = 0.4 cos q，q 按周期 2π 回绕。

引理 4.1 · 白话版

对一族图 Lt = graph(dSt)，其中 St = aᵀFt，下面三件事等价：

  1. 哈密顿流把 Ls 运输成 Lt；
  2. Hamilton–Jacobi 方程成立：∂tSt + Ht(q, dSt) = c(t)；
  3. H 可以写成 c − aᵀ∂tF + (ξ − DFᵀa)ᵀU + (η − F)ᵀB，其中 U、B 任意。

第 3 条的意思是：H 在图上的取值被 HJ 方程固定（= c − aᵀ∂tF），偏离图的部分可以随便加，前提是乘上"偏离量"。

模型实际选的 H（命题 A.6）

H = ξ⊤U(x) − a⊤R(x)

代入哈密顿方程：

ẋ = U,  ȧ = 0,  η̇ = R,  ξ̇ = −DUᵀξ + DRᵀa

白话：粒子沿速度场 U 移动，携带的颜色 η 以速率 R 变化，探针 a 保持不变。这就是一阶线性 PDE ∂tF + (DF)U = R 的特征线法，ξ 的方程只是它对 x 的导数。

关键观察 · 我的判断

这个 H 对动量 (ξ, η) 是仿射的（η 甚至没出现）。演示 C 已经说明，这类哈密顿流是底空间流的余切提升（再叠加 −aᵀR 带来的纤维方向平移），会把任何图映成图。代入 S = aᵀF 后，HJ 方程变成

a⊤( ∂tF + DF·U − R ) = 0  ⟺  R := ∂tF + DF·U

所以这不是一个需要满足的约束，而是 R 的定义：随便选一个 U，把 R 定义成上式，任何 C¹ 图像路径都有对应的哈密顿实现。论文自己在 §4.3 "Scope" 里写了："The geometry thus does not restrict image velocities"，而且标准 FM 就是 U ≡ 0 的特例。标题里的"辛"只存在于 2(n+2) 维的外围空间。图像空间里的 v = r − DF·u 是一个普通的仿射 PDE：不守恒能量，不保体积，也不保任何范数。它和 Hamiltonian NN、辛积分器那种"结构保持"不是一回事。

我逐行核对过的证明
  • 引理 4.1。(1)⇔(2)：图的切条件等价于 dq[∂tS + H(q,dS)] = 0；Q = ℝ²×ℝⁿ 连通，所以方括号里只是时间的函数。(2)⇒(3)：沿动量纤维用 Hadamard 引理。都正确，属于经典结果（Cariñena 等 2006，论文已注明 "classical in form"）。
  • 命题 A.5 和 A.6。我验证了 ξ 方程：d/dt[DF(xt)ᵀa] = (D∂tF)ᵀa + (D²F[U])ᵀa。代入 ∂tF = R − DF·U，再用二阶导数的对称性，得到 DRᵀa − DUᵀξ，与哈密顿方程一致。
  • 符号检查。∂tS + H(q,dS) = aᵀ∂tF + aᵀDF·U − aᵀR = 0 ⇔ ∂tF = R − DF·U，即式 (7)，一致。

§05一行代码：v = r − ∇J·u，以及它的亲戚们

把网格上的取值写出来（式 8），就是整篇论文真正交给神经网络的东西：

vt = J̇t = rt − ( DFJt |GN ) ut式 (8)

每个像素上，DF 是 n×2 的空间雅可比矩阵，u 是 2 维位移速度，r 是 n 维颜色变化率。白话：像素值的变化 = 源项 − 梯度 × 位移。r = 0 时就是纯平流，图像内容沿 u 移动；u = 0 时退化为普通 FM。

拆分不唯一：注记 A.8 与"孔径问题"

给定同一个 v，把 u 换成 u + δu，同时把 r 换成 r + DF·δu，v 完全不变。所以 CFM 损失本身无法辨认哪部分算搬运、哪部分算源项（注记 A.8，论文自己写的）。光流里有同样的问题，叫"孔径问题"：沿等值线方向的运动看不出来。

§06LHFM-I：在流匹配里换一个输出头

LHFM-I 的做法很直接。I-CFM 的 U-Net 输出 3 个速度通道；LHFM-I 让同一个 U-Net 输出 5 个通道：2 个搬运通道、3 个源项通道。再用当前的噪声图 J 算出 DCT 空间雅可比，按式 (8) 合成速度。损失、耦合方式（独立端点、σ = 0）、采样器都不变。

图 2 · LHFM-I 的一次前向（下方灰条是 I-CFM 基线）
这一节最重要的一点

训练目标仍是 y = I − ε，路径仍是像素直线插值 (1−t)ε + tI。对任何参数化，最优速度场都是同一个条件期望：

v*(t, J) = 𝔼[ I − ε | Jt = J ]

r 不受约束，所以 LHFM-I 的函数类能表达的 v 和 I-CFM 一样多。两者要逼近的是同一个流、同一条概率路径。于是，FID 上的差异只能来自网络的归纳偏置或优化难度，和"避免像素混合重影"（§2、论文图 4）没有关系。论文把图 4 当作动机放在 LHFM-I 前面，这个衔接不成立。

FID 收益可能从哪来（我的猜测，未验证）

  • 多了一条显式的乘法通路：网络输出 × 输入的空间导数。U-Net 很难精确表达这种乘积。
  • 多 2 个输出通道带来的轻微容量差异（2,306 个参数，影响可以忽略）。
  • 单种子噪声：只有一个训练种子、一个 checkpoint，Δ = 0.24 没有误差棒。

能区分这些猜测的消融（论文都没做）

  • 把 DFJ 换成 Sobel 或有限差分；换成打乱空间位置的梯度；换成固定的随机线性算子。
  • 推理时强制 u = 0，看 FID 掉多少，以此判断 u 实际承担了多少。
  • 3 个以上种子；比较多个 checkpoint（100k / 150k / 400k）；在 Tong 等人的原始 U-Net 上复现。

§07LHFM-V：循环网络 + 数值求解器

论文说视频预测才是主角。设定：看 Tobs = 10 帧，预测 K = 10 帧，64×64 单通道，时间单位是帧。每一帧分成两个半步（h = 1/2）。每个半步里，网络从循环状态预测一对场 (w, rnet)，它们在半步内保持不变；数值求解器用这对场推进图像；新图像再反馈回循环状态。

  • 损失（式 23）：L = (1/K)Σ MSE(Î, I) + (λr/2K)Σ mean[(rnet)²] + (λu/2K)Σ TV(w) + (λc/K)Σ MSE(Îcoarse, P₄I)，其中 λr = 10⁻³，λu = 10⁻⁴，λc = 0.05，P₄ 是 4×4 平均池化。

8.3 SSIM 的口径：data_range = 2

附录 B.4 写得很细：scikit-image 0.19.3，7×7 均匀窗，样本协方差，K₁ = 0.01，K₂ = 0.03，去掉 3 像素边框，data_range = 2。这些其实就是旧版 skimage 对浮点图像的默认行为：data_range 没指定时按 dtype 范围取，float 的范围是 (−1, 1)，所以是 2。新版 skimage 遇到这种情况会直接报错，要求显式指定。预测值在 [0,1] 时，正确的 data_range 应该是 1；取 2 会把 SSIM 往 1 的方向抬。

证据：PredFormer 表 2 和表 6；论文图 6 的 "Joint future planner"。

04"搬运 = 运动、源项 = 外观"没有被验证，而 oracle 实验显示它很可能不成立高

按论文 B.3 的格式，给真实速度、源项设为零，单个数字的 10 帧平均 MSE ≈ 34.5，两个分开的数字 ≈ 53.7。报告的总误差只有 18.6。所以学到的场必然大量用于抵消数值耗散和色散，而论文没有展示任何学到的 w 或 r。

证据：我的复算（§7 演示 E 与离线表）。求解器与 scipy expm_multiply 的差异在 10⁻¹⁵ 以内。

05代码链接无法访问高

摘要承诺代码公开，但 2026-09-30 访问返回 404，FLOPs 口径、架构细节、评测脚本都无法核对。对一篇单作者、主要结论依赖工程细节的论文来说，这是决定性的复现障碍。

证据：github.com 页面 404；git clone 要求认证。

06几何不带来约束，"辛视角"的说法偏大中

实际用的 H 对动量是仿射的，会把任何图映成图，HJ 方程只是 R 的定义。论文自己也承认几何 "does not restrict image velocities"。辛形式只在 2(n+2) 维外围空间里守恒（RGB 是 10 维，LHFM-V 的单通道是 6 维），图像空间的动力学没有任何守恒量或结构保持。读者很容易把它误解成 Hamiltonian NN 那种归纳偏置。

证据：命题 A.6、注记 A.8、§4.3 "Scope"；§4 演示 C。

07LHFM-I 的动机和它的训练目标对不上中

图 4 的动机是"避免像素混合重影"，但 LHFM-I 的条件路径仍是 (1−t)ε + tI，目标仍是 I − ε，最优速度场和 I-CFM 完全相同。所以 FID 差异只能来自归纳偏置或优化，和"搬运结构"无关。

证据：式 (9)(10)、算法 1；§6。

08CIFAR 结果：单种子、单 checkpoint、基线偏弱中

Δ FID = 0.24，没有误差棒。本地 I-CFM 是 3.82，官方 I-CFM 是 3.66（400k 步，DOPRI5）。本文训练 150k 步，没说明为什么在这一步评测。

证据：表 2、表 4；TorchCFM 官方 CIFAR-10 脚本（400001 步、batch 128）。

09生成的大部分时间里，DFJ 主要是噪声的梯度中

全频带 DCT 谱导数会放大白噪声。在 MNIST 代理上，噪声占梯度能量的比例要到 t ≈ 0.83 才降到 50%，t = 0.5 时是 96%。0.125t 的门控只解决了 t → 0 的问题。"搬运项"在中段更像一个噪声梯度特征。

证据：我的复算（§6 演示 F）。

10PredRNNv2 的 FLOPs 用错了数据集中

表 3 的 24.6M / 708.0G 是 OpenSTL Human3.6M 行的数字，Moving MNIST 实测是 23.9M / 116.6G。这不影响"最低 FLOPs"的结论，但说明基线数字是转抄的，没有逐项核对。

证据：OpenSTL 表 3 与表 12；PredFormer 表 2 已有同样的错误。

11FLOPs 口径未说明，也没有速度数字中

计数工具、是否包含求解器、单帧还是整段，都没交代。LHFM-V 的串行步骤很多（20 个半步 × L × 24 次模板运算，外加循环更新），实际延迟可能不低。OpenSTL 和 PredFormer 都报了 FPS。

证据：全文只有 FLOPs 一列。

12SSIM 口径中

本文用旧版 skimage 默认的 data_range = 2，在这个误差水平会把 SSIM 抬高约 0.015。SwinLSTM 和 OpenSTL 的代码大概率同口径；PredRNN 的官方代码库转 uint8 后再算（正确口径），但原论文的口径无法确认。表中 SSIM 列很可能混用了不同口径。

证据：附录 B.4；我的测量（§8.3）；各仓库的评测代码。

13视频模型不是理论里的那个哈密顿流低

理论建立在 DCT 导数上，视频用的是迎风差分。注记 A.7 给出的"相容源项"修正 "is not added to the numerical update"。所以 LHFM-V 和几何之间的联系是事后的解释：按命题 A.6，任何模型都能找到一个哈密顿实现。

证据：注记 A.7、式 (22)。

14视频预测里同类结构的已有工作没有讨论低

"运动场 + 强度残差"在 NowcastNet 的演化网络、各种 warp + 残差的视频预测器、视频编码的运动补偿里都有。论文只引了 metamorphosis 和 PhyDNet。

证据：参考文献表；NowcastNet (Nature 2023)。

15只在 Moving MNIST 上验证低

Moving MNIST 是刚体平移加反弹，平流先验和数据的生成方式天然吻合。没有 KTH、Human3.6M、KITTI 这类真实视频，而遮挡、显露、光照、视差恰恰是平流先验最难处理的情况。

证据：§6.2 只有一个数据集。

16训练中途人工改学习率低

第 400k 步恢复训练后把学习率减半，原因没说。论文如实记录了这一点，值得肯定；但这属于看着训练曲线做的决定，加上只有一个种子，结果的稳健性不清楚。

证据：附录 B.2。

17二阶迎风不是单调格式，评测用的是不截断的 MSE低

格式会产生负值下冲（我的测试里约 −0.17）。MSE 和 MAE 用未截断的预测计算，SSIM 用截断后的。这些对结论影响不大，但说明像素空间的欧拉型平流格式有固有的伪影。

证据：式 (24)；附录 B.4；我的复算。

18动机章节的修辞多于实质低

WKB、几何量子化、海森堡不确定性原理在方法里都没有对应物。仓库名是 Geometric_quantization_models，但模型里没有量子化。

证据：§3、表 1。

§11公道话 · 对交互式视频世界模型的启示

做对了的地方

数学干净

定义清楚，证明正确（我逐行核过）。论文主动说明了"经典形式"、"几何不限制速度"、"拆分不唯一"。自我定位也克制："do not claim state-of-the-art image generation"。

复现信息详尽

种子、数据划分、学习率曲线（包括人工干预）、SSIM 的每个参数、数值格式的每个常数都写了。这在同类论文里少见，也是本页能做 oracle 复算的前提。

求解器设计好

冻结场加 uniformization：对冻结场在时间上精确，可微，按 CFL 自动细分，μ ≤ 3 时级数截断误差可以忽略，源项也一并处理。这个模块可以直接拿来当可微平流算子用。

对交互式视频世界模型的启示

  1. "运动补偿 + 残差"是一条便宜的通路，但只覆盖容易的部分。相机平移、刚体运动可以靠搬运，而且很省算力。世界模型真正难的是遮挡、显露、视差，以及转头时看到的新区域。单层二维平流做不了这些，都得交给源项，也就是交给生成网络（参见演示 E 的"交叉"模式）。
  2. 想要可解释、可控的运动场（比如"动作 → 运动"），必须先解决不可辨识性。需要给源项加惩罚、给运动场加平滑项或光流监督，否则 u 没有含义。LHFM-I 就是反例：没有正则，u 学成什么都可以。
  3. 像素空间里别用欧拉型差分格式做长 rollout。oracle 实验里，仅数值耗散一项就超过了模型的总误差。半拉格朗日 warp（双线性采样）对整数平移没有误差，对亚像素平移的模糊也更可控。或者干脆在潜空间里做搬运。
  4. FLOPs 不等于延迟。流式世界模型关心的是每帧毫秒数。LHFM-V 这种每帧"两个半步 × 几十次串行模板运算 × 循环更新"的结构，FLOPs 很小，但可能受 kernel 启动次数限制。
  5. 拿几何或物理当卖点之前，先问一句：这个结构约束了什么？如果任何路径都有对应的哈密顿实现，这个"物理先验"就只是换了个说法。真正起作用的是参数化方式、正则项和求解器。

最值得补的实验（按性价比排序）

  1. LHFM-V 同架构的 w ≡ 0 消融，外加欧拉步 vs 指数积分器、有无 λr / λu、有无联合规划器。
  2. 可视化学到的 w 和 r，统计源项的能量占比；把学到的 w 和真实数字速度比较（Moving MNIST 的生成器可以直接给出真实速度）。
  3. 按 OpenSTL 协议，在同样 2000 epoch 下和 PredFormer、TAU 比较，同时报告 FPS 和显存。
  4. CIFAR-10 跑 3 个以上种子，在官方 TorchCFM U-Net 上复现，推理时强制 u = 0，并把 DFJ 替换成其他算子做对照。
  5. 在一个真实视频数据集上测试（KTH、Human3.6M 或 KITTI），看平流先验遇到遮挡时表现如何。
  6. 把迎风差分换成半拉格朗日 warp，看 oracle 误差和最终误差各变多少。
