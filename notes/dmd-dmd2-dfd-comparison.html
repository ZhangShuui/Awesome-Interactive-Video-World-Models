Diffusion Distillation · 方法解读

从 DMD 到 Data-Forcing：
三代「分布匹配蒸馏」的方法演进

同一条反向 KL 骨架，三种给学生"补课"的方式——教师合成配对（回归损失）→ 判别器（GAN 损失）→ 真实数据直接进入分布匹配梯度。

01

一条主线：拿什么信号防住反向 KL 的"模式坍缩"

三篇论文共享同一个训练骨架——用 反向 KL 的分数差梯度 把学生的输出分布对齐到教师分布。真正的分歧只有一个：反向 KL 天然"认高密度模式"（mode-seeking），会丢模式、丢多样性，用什么辅助信号把丢掉的东西补回来，就是三代方法的分界线。

02

共同骨架：反向 KL 的"分数差"梯度

三篇论文的学生 Gθ 都不去模仿教师的采样轨迹，而是最小化学生分布与数据分布之间的反向 KL 散度。密度本身算不出来，但它对 θ 的梯度可以写成 两个分数函数之差——而分数恰好能用扩散去噪器来近似：

DMD Eq.(2)(7) / DMD2 Eq.(2) / DFD Eq.(1) ∇θDKL(pfake ∥ preal) ≈ 𝔼t,z,ε[ wt ( sfake(xt, t) − sreal(xt, t) ) ∇θGθ(z) ],  xt = αtGθ(z) + σtε
  • 真实分数 sreal：由冻结的预训练教师给出——它是数据分布（加噪后）的分数场，指向"更真实"的方向。
  • 假分数 sfake：由一个在线训练的第二个扩散模型给出（教师权重初始化），持续用去噪损失拟合学生当前的输出分布，指向"更像学生自己"的方向。二者之差即"去伪存真"的更新方向。
  • 为什么要加噪：未加噪时 preal 与 pfake 支撑集可能不重叠、分数无定义；对样本注入不同强度的高斯噪声后两个分布处处重叠，梯度对任意 t 良定义（Score-SDE 视角）。
  • 致命弱点：期望在 学生自己的样本 上取——学生没覆盖到的真实模式贡献零梯度，反向 KL 因此"看不见"缺失的模式（§05 图解）。三代方法的全部分歧都围绕这一点展开。

①DMD — 分布匹配 + 教师配对回归arXiv 2311.18828 · CVPR 2024
单步生成图像（EDM / SD v1.5）两个损失、两条数据流
生成器总损失 LG = DKL(pfake∥preal) + λreg·𝔼(z,y)∼𝒟[ LPIPS(Gθ(zref), yref) ]
  • 定位：把 ProlificDreamer 的变分分数蒸馏（VSD）从"优化单个 3D 粒子"改造成"训练一个生成网络"，首次把分布匹配做成图像蒸馏的主损失。
  • 回归损失是刚需：消融显示去掉它 FID 从 2.62 恶化到 5.61（ImageNet），出现明显模式坍缩（同一灰车反复出现）；去掉分布匹配则结构崩坏（9.21）。两条腿缺一不可。
  • 成绩：ImageNet-64 FID 2.62（教师 EDM 512 步为 2.32）；zero-shot COCO FID 11.49（教师 SD v1.5 为 8.78），推理提速约 30×、20 FPS。
  • 遗留问题：配对数据离线生成开销大（放到 SDXL 规模约需 700 A100·天）；回归目标与"只匹配分布"的初衷相悖——学生被教师 ODE 路径上界锁死。
②DMD2 — 扔掉回归，换 TTUR + GAN，扩展多步arXiv 2405.14867 · NeurIPS 2024
1 步 / 4 步图像（EDM / SD v1.5 / SDXL）学生首次超越教师
生成器总损失（无回归项） LG = DKL(pfake∥preal) + LGAN ;  μfake / D：Ldenoise + LGAND，每个 G 步更新 5 次（TTUR）
  • 诊断：直接去掉回归损失会训练不稳（整图亮度周期性震荡、FID 2.62→3.48）。根因是 μfake 追不上非平稳的学生分布，假分数失准 → 梯度有偏。TTUR（假分数 5:1 高频更新）即可救回（FID 2.61），且比原版 DMD 收敛更快。
  • GAN 的角色：教师的分数估计本身有误差，纯 DMD 学生永远见不到真实数据、无从纠错。判别器用真实图像训练，把 真实数据信号隐式注入，FID 再降至 1.51 / 1.28，首次超越教师（ODE 2.32）。设计极简：分类分支直接挂在 μfake 瓶颈层，真假样本都先加噪再判别。
  • 多步 + 反向模拟：4 步生成按 999/749/499/249 交替"去噪→再加噪"。关键改动：训练时中间步输入不再用"加噪真图"（与推理不一致），而是让学生 自己滚动生成——消除 train/inference 失配。
  • 成绩：ImageNet-64 FID 1.28；SD v1.5 单步 COCO FID 8.35（DMD 为 11.49）；SDXL 4 步 FID 19.32 / Patch-FID 20.86，与 100 步教师打平甚至更优。
  • 遗留问题：论文自述多样性仍轻微下降（LPIPS 多样性 0.61 vs 教师 0.64）；对抗项带来调参与稳定性负担——这正是 DFD 的切入点。
③DFD — 数据强制：真实数据直接进入分布匹配梯度arXiv 2606.18478 · 2026.06
视频 · 4 步（Wan2.1-1.3B / Cosmos-Predict2.5-2B）DMD2 之上后训练 100–300 步一行代码改动无对抗训练
DFD 更新（化简后，Eq. 8–10） g(θ) = (1−w)·gDMD + w·gDFD,  w = ½ ;   gDFD = 𝔼x∼preal(·|c), z[ ( sfake(x̃tgen) − sreal(x̃tdata) ) ∇θGθ(z, c) ]
  • 诊断：视频蒸馏中 DMD2 的两大顽疾——多样性坍缩（相机轨迹多样性只剩教师的 1/6）与 过饱和（偏离真实视频观感）——同源于反向 KL 的 mode-seeking：期望取在学生样本上，学生丢掉的模式产生零梯度、永远找不回来。
  • 推导逻辑：在 DMD 梯度上加一个"教师分数差异"正则 Δ = sreal(x) − sreal(Gθ(z))（当 pfake=preal 时期望为零）。它与原梯度中的 sreal(G(z))项恰好相消——化简后就是教师改给真实样本打分，因此只需一行代码。附录进一步证明 gDFD 与真实反向 KL 梯度的 MSE 有界。
  • 与 DMD2 的本质区别：同样是"用真实数据纠偏"，DMD2 走判别器（隐式、对抗、不稳），DFD 直接写进分布匹配梯度（显式、非对抗）。消融显示在 DFD 之上再加回 GAN 无增益、动态度反而变差——判别器可以整个删掉。
  • 代价是一个前提：正则项方差受学生-数据间隙控制（有效性条件），所以 DFD 只能作为 DMD2 之上的后训练（100–300 步），不能从头训——这也是它与前两代"完整蒸馏框架"定位上的不同：它是修复层，不是替代者。
  • 数据成为一等公民：真实数据的质量与多样性直接决定学生上限，论文为此做了聚类 + 人工在环的精选管线（100 万条 → 1000 簇 → 2 万条动画集 / 3 万条混合集）。注意一个细节：所用 ViPE-Wild-1M 本身是 Wan2.1-14B 生成的公开数据集，"真实数据"在实践中是"高质量参考分布"。
  • 成绩：Wan2.1-1.3B T2V 4 步：VBench 均分 0.906（教师 0.899、DMD2 0.901）；相机轨迹多样性从 DMD2 的 4.28 恢复至 19.26（教师 26.65）。Cosmos-Predict2.5-2B I2V：均分 0.9303 超教师 0.9285。自回归（Self Forcing）设定下同样改善时序一致性与物理合理性。
  • 局限：≤2 步的极限步数下仍会模糊、丢细节、动态变弱。
04

病灶图解：反向 KL 为什么丢多样性，DFD 怎么拉回来

DMD 的解法 · 回归锚点用教师 ODE 配对 (zref→yref) 把学生钉在各模式上。有效，但锚点是教师的输出而非真实数据，且离线合成昂贵、上限锁死。
DMD2 的解法 · 判别器判别器见过真实数据，学生缺的、多的模式都会被打分惩罚——但信号隔着一层网络转手，对抗训练不稳，多样性仍有损失。
DFD 的解法 · 教师分数差异真实样本直接出现在分布匹配梯度里：显式、非对抗、一行代码；代价是需要学生已接近数据（暖启动）。
05

DFD 的全部实现：一行代码的 diff

DFD 论文 Algorithm 1（PyTorch 风格伪代码）给出了学生更新步。与 DMD2 相比，唯一的改动是决定"教师给谁打分"的那一行——注意两条前向加噪共用同一组 eps, t：

# 学生更新步（DFD 论文 Alg.1，有删节） gen_data = student_network(input_student, t_student, condition) teacher_data = gen_data.detach() # DMD / DMD2：教师给学生样本打分teacher_data = data.detach() if rand() < p else gen_data.detach() # DFD：以概率 p 换成真实样本 perturbed_data = forward_diffusion(gen_data, eps, t) # 同一 eps、同一 t perturbed_teacher_data = forward_diffusion(teacher_data, eps, t) fake_score = fake_score_network(perturbed_data, t, condition) teacher_score = teacher_network(perturbed_teacher_data, t, condition) vsd_grad = fake_score - teacher_score pseudo_target = gen_data - vsd_grad gen_loss = 0.5 * mse_loss(gen_data, pseudo_target.detach())

随机切换在期望意义下等价于混合梯度 g = (1−w)gDMD + w·gDFD（取 p = w = ½）；消融显示结果对 w 不敏感（w=1 也可行），取 ½ 是为了更好满足有效性条件并保留 DMD 的收敛速度。

08

脉络与评注

主线：真实数据信号的"三级跳" 反向 KL 骨架三代未变，变的是"数据"进入训练的方式：DMD 完全不用真实数据（锚点是教师合成的配对）；DMD2 让真实数据隐式进入（隔着一个判别器）；DFD 让真实数据显式进入分布匹配梯度本身。信号越直接，需要的附加机器越少——从"配对数据集 + 回归损失"到"判别头 + 对抗训练"再到"一行代码"。
一个耐人寻味的轮回（解读性观点，非论文原文） 展开 DFD 的伪目标可以看到：当教师给真实样本打分时，teacher_score 近似为去噪后的真实样本，于是 pseudo_target ≈ x——学生在分数空间里被"回归"向一个同条件、同噪声的真实样本。换句话说，DMD 当年被 DMD2 扔掉的"回归锚点"在 DFD 中换了一种形态回来了：锚点从教师 ODE 输出换成了真实数据，从像素空间 LPIPS 换成了分数空间，从离线配对换成了免配对（共享噪声即隐式配对）。这也解释了两者共同的作用（钉住模式、稳住训练）与关键差异（DFD 的锚不再受教师上限约束）。
教师角色的退化与数据角色的升格 DMD 里教师既是分数场又是配对数据源；DMD2 里教师只剩分数场，数据质量由判别器把关；到 DFD，教师进一步退化为"评估真实样本的一个分数场"，而数据的质量与多样性直接成为学生的上限——所以论文把相当多篇幅花在数据精选管线上。一个值得注意的开放问题：DFD 所用的"真实"视频集 ViPE-Wild-1M 本身由 Wan2.1-14B 生成，蒸馏链路里存在"以大模型生成物为目标分布"的自举成分。
实践视角怎么选 图像单步/少步蒸馏：DMD2 配方（TTUR + GAN + 反向模拟）仍是标准答案。视频少步蒸馏：先 DMD2 蒸出可用学生，再叠 DFD 后训练 100–300 步恢复多样性与保真度，顺手删掉 GAN；自回归视频（Self Forcing 一线）同样适用。若步数压到 ≤2，三代方法都还没有满意答案。
