核心思想

自回归视频扩散模型（如 Self-Forcing）流式生成长视频时会「越走越歪」：色彩漂移 → 运动停滞 → 画面崩塌。本文把这个现象翻译到频域：误差累积 = 注意力输出与像素帧的 DC / 低频能量持续漂移（低频承载色调、布局、身份等全局属性）。

解法 Spectral Self-Anchoring（SSA，频谱自锚定）：把生成早期（预训练视野内）的少量高质量帧冻结成「锚缓存」，推理时并行计算一路锚注意力；再用 3D FFT 把两路注意力输出搬到频域，按高斯低通门控 λHlp 融合——低频听锚的（稳住全局），高频听局部的（保住动态），逆变换回去继续生成。全程不训练、不改权重。

①问题：自回归视频扩散为什么会「越生成越坏」

背景设定 · 对应论文 Introduction 与 Preliminaries

Sora、HunyuanVideo、Wan 这类双向（bidirectional）视频扩散模型质量很高，但一次要看到整段视频，没法做流式、低延迟、可在线交互的生成——而这恰是交互式世界模型、具身决策等应用的刚需。自回归视频扩散因此成为主流替代：逐块（chunk-by-chunk）生成，复用 KV 缓存。本文的基座 Self-Forcing（NeurIPS 2025）在训练时就用模型自己的生成结果填充 KV 缓存（self-rollout），弥合了训练-推理差距，并把去噪压缩到 4 步，实现实时流式生成。

论文式 (1)(2)
pθ(x[0,N) | c) = pθ(x0 | c) · ∏i=1N−1 pθ(xi | x[0,i), c)逐帧（块）自回归分解；c 为文本条件
xitj−1 ≈ Ψ( Gθ( xitj, tj, Φswi, c ), tj−1 )完整历史 x[0,i) 被固定容量的滑窗 KV 缓存 Φsw 近似

关键结构是带 attention sink 的滑窗因果注意力：每层可见窗口从左到右排成三段——sink 帧 ×s（最早的几帧，常驻不换） + 最近历史 w−f−s 帧（滚动淘汰） + 当前块 ×f。本文设定下窗口 w=21 个 latent 帧（恰为预训练长度：5s ≈ 81 像素帧 @16fps，经 VAE 4× 时间压缩），每块 f=3 个 latent 帧，sink 大小 s=12。

图 1 · 误差累积的反馈回路。流式生成的效率来自复用 KV 缓存，但同一机制也把误差不断喂回模型：滑窗淘汰掉早期干净帧后，模型条件里只剩逐渐劣化的历史，形成正反馈。60–120s 尺度上表现为色彩漂移、运动停滞乃至崩塌。
已有两条修补路线

训练类（LongLive、Rolling Forcing、Self-Forcing++、Causal Forcing 等）：用更好的蒸馏 / 长视野训练策略压制漂移，有效但要花大量算力重训。免训练类（Infinity-RoPE 改位置编码、Deep Forcing 做 KV 缓存管理等）：推理期干预、即插即用，但此前在「分钟级」时长上仍稳不住画质。FreqForcing 属于后者，目标是用免训练方法逼平甚至超过训练类方法。

②频域诊断：给「崩塌」拍一张心电图

论文的分析基础 · 对应 Fig.3 与 “Error Accumulation in the Frequency Domain” 一节

作者用预训练 Self-Forcing 按 MovieGen 提示词生成 60s 视频，途中记录每层 DiT 的 self-attention 输出（latent 空间）和像素帧（pixel 空间），对这两路序列做短时傅里叶变换（STFT），追踪各频带能量随时间的变化。先弄清楚频带的语义：

图 2 · 频带的语义。低频承载「画面整体长什么样」：色调是否发灰发紫、场景布局、主体身份；高频承载「细节动不动、清不清晰」。长视频劣化的两种典型症状——整体变色褪色（低频漂移）与闪烁糊化（高频不稳）——正好按频带对号入座。

诊断结论 → 设计动机

① 误差累积在频域的「病灶」很集中：DC / 低频能量持续漂移——根因是滑窗缓存只留「最近的带病帧」，与开局高质量帧渐行渐远。② attention sink 之所以有效，是因为常驻的早期 token 隐式地稳定注意力分布、减缓频谱漂移；但它改变不了「最近 token 已被污染」这一事实，一旦条件坏了，sink 拉不回生成轨迹。③ 结论：需要一种显式的、作用在频域上的、只动低频的强引导——这正是 SSA 的设计出发点。

③方法：Spectral Self-Anchoring（频谱自锚定）

论文核心 · 两步走：双分支注意力 → 频域门控融合 · 对应 Fig.2 与式 (7)–(12)

图 4 · FreqForcing 总览（按论文 Fig.2 重绘）。两路注意力共享同一批 Query（当前块），只是看的 K/V 不同：局部分支看「sink + 最近历史 + 当前块」，锚分支只看 6 帧冻结的早期高质量帧。两路输出经 3D FFT 进频域，用高斯低通门 λHlp 做凸组合——低频段几乎全听锚的、高频段几乎全听局部的——再 IFFT 回来作为该层注意力的最终输出。

分支 ①：局部注意力——负责「动起来」

就是基座 Self-Forcing 的滑窗因果注意力，只是把 sink 加深到 S=12（论文称 deep attention sink，Deep Forcing 已证明大 sink 更稳）。它掌握最近的运动趋势与细节，是高频信息的来源；但它的 K/V 里混着被污染的近期历史，所以低频会漂。

分支 ②：锚注意力——负责「别变味」

在生成尚处于预训练视野内（前 21 个 latent 帧，画质有保障）时，每生成 3 个 latent 帧往锚缓存里收 1 帧；收满 Nanc=6 帧后冻结，之后永不更新。一旦生成长度超过预训练长度（Lgen > Lpre=21），锚分支开始工作：用当前块的 Q 去注意这 6 帧冻结的 K/V，得到一路「以高质量历史为条件」的参考输出。注意「自锚定」的含义：锚不是外部参考图，而是模型自己早期的生成结果——所以不需要任何额外输入或训练。

图 5 · 锚缓存的构建。示意图按「每 3 帧收第 3 帧」画出（论文只说明比例为 3:1，未指明取哪一帧）；6 个锚帧全部来自前 ~18 个 latent 帧，即模型最有把握的开局段。冻结意味着锚的「低频参考系」自此固定——这正是它能对抗漂移的原因，也埋下了 §⑧ 讨论的多样性代价。

第二步：频谱锚定（Spectral Anchoring）——按频段「分工」融合

拿到两路输出后，不在时空域做插值（那会把画面糊成两张图的平均），而是先用 3D FFT（沿空间 x、y 与时间 t 三个维度）把它们搬进频域，按频率逐点加权：

论文式 (7)–(8)
Aloc = Softmax( QK⊤loc / √d ) Vloc局部分支：K/V = sink + 最近历史 + 当前块
Aanc = { 0 　若 Lgen ≤ Lpre；　Softmax( QK⊤anc / √d ) Vanc 　若 Lgen > Lpre }锚分支：K/V = 6 帧冻结锚帧；预训练视野内不启用
论文式 (9)–(12)
Âloc = 𝓕3D(Aloc),　Âanc = 𝓕3D(Aanc)3D FFT：空间 × 时间一起变换
Hlp(kt, kxy) = exp( −kt2/2σt2 − ‖kxy‖2/2σxy2 )时空高斯低通门：频率越低 → 越接近 1
Âfused = (1 − λHlp)·Âloc + λHlp·Âanc = Âloc + λHlp·( Âanc − Âloc )逐频点凸组合；等价于注入「仅含低频的纠偏残差」

读式 (11) 的两种方式：门控视角——λHlp 是一个随频率变化的开关，低频处 ≈ λ（锚说了算的比例），高频处 ≈ 0（完全保留局部）；残差视角——保持局部输出不动，只把「锚与局部之差」中的低频部分按强度 λ 加回去，λ=0 时严格退化为原版 Self-Forcing。拖动下面的滑杆感受 λ 和 σ 的作用：

锚的权重 λ·Hlp(k) 局部的权重 1−λ·Hlp(k)
图 6 · 融合权重的频率响应（一维示意；论文中 Hlp 是关于时间频率 kt 与空间频率 kxy 的 3D 高斯，默认 σxy=σt=0.125、λ=0.6）。DC 处（k=0）锚占 λ、局部占 1−λ；频率升高，锚的话语权按高斯衰减，高频段局部分支几乎独享。σ 控制「低频」的边界宽度，λ 控制低频段锚定的力度。
解读（非论文原文）

为什么把干预点放在每层注意力输出而不是最终像素或 latent 上？一个自然的理由：②节的诊断本来就是在各层 attention 输出上看到漂移的——SSA 等于在「病灶原位」逐层施加纠偏，让每一层的后续计算都建立在已校正的特征上，而不是等误差传完一整条网络再去修。另外注意力输出是 3D 张量（时 × 空 × 通道），天然适合做时空 FFT，且在 latent 分辨率上变换开销极小。

④时序 RoPE 对齐：别让「距离」出卖你

配套细节 · 做法沿用 Rolling Forcing

Wan 这类 DiT 用 3D RoPE 做相对位置编码，而预训练时模型见过的最大时间距离只有 20（21 帧窗口内）。生成到第 N 帧时，sink 帧和锚帧的「出生索引」还停在 1–18 附近，与当前帧的距离随 N 无限增长——RoPE 被迫外推，注意力会算出没见过的相位差，产生不自然的伪影。解决办法很直接：每一步都把 sink 帧与锚帧的时间索引整体平移到当前窗口正前方（只改位置编码，不动帧内容），让所有 Q–K 相对距离恒落在预训练范围内。

图 7 · 时序 RoPE 对齐。论文对局部缓存里的 sink 帧与锚缓存里的锚帧统一做此处理。这一步是「让老帧永远看起来像刚发生」的位置魔术——锚提供的是内容参考，不该因为「年代久远」而被注意力机制打折或算错。

⑤效率设计：只在最该出手的时刻出手

让 training-free 真正可部署 · +16.5% 延迟的由来

SSA 的开销有两处：锚注意力的额外计算（主要项）与频谱锚定的 FFT/IFFT（在 latent 分辨率上进行，可忽略）。论文用两个设计把主要项压到最低：其一，锚缓存只有 Nanc=6 帧，锚注意力的 K/V 极短；其二，利用扩散模型「粗到细」的去噪性质——全局布局与物体结构在早期高噪步形成，细节在后期步浮现（eDiff-I、MasaCtrl 等已系统观察到）——而低频锚定恰恰只需要在「布局成形期」介入，于是 SSA 只在每块 4 步去噪的前 2 步（t=1000 与 t=937）开启。

图 8 · SSA 的选择性开启。正文只给出前两步的具体噪声水平（t=1000、937），后两步未列出，图中记作 t₂、t₁。用 2/4 步的干预换来分钟级稳定，是这篇文章「便宜」的关键。

频域引导线：FreeU（重平衡 U-Net 高低频特征）、FreeInit（迭代保留初始噪声低频）、FreqPrior（频域滤波的噪声先验）、FreeLong / FreeLong++（SpectralBlend 时域注意力融合全局与局部）——这些「Free 家族」方法都工作在双向视频扩散模型上。FreqForcing 的差异化在于把频域融合第一次搬进自回归 self-rollout 的流式推理循环：锚不是外部信号或初始噪声，而是模型自己在预训练视野内生成的高质量历史（所以叫 Self-Anchoring）。而 attention sink 这条线（StreamingLLM 在 LLM 中发现 → LongLive / Deep Forcing 等移植到视频）在本文中被频域分析重新解释：sink 有效的机理 = 减缓频谱能量漂移——这个解释本身也是论文的贡献之一。

⑧评注与局限

以下除第一条外均为本页解读，非论文原文，请据此把握置信度

论文明示的代价

一致性 ↔ 多样性的跷跷板：σ、λ 越大，Dynamic Degree 与 Overall Consistency 越高，但 Repetitive Rate 单调上升（0.647 → 0.877）。作者的说法是「对注意力输出过度的低频干预会降低视觉多样性」——锚定本质上是在用「开局的样子」约束未来，按得越紧，新内容越难长出来。

解读 · 冻结锚的适用边界

锚缓存永远取自开头 ~5s 并全程冻结，隐含假设是「这段视频的全局外观不应该变」。对单场景持续镜头（本文评测的 MovieGen 提示词多属此类）这是合理先验；但对需要场景切换、昼夜/天气变化、大幅运镜的长叙事视频，低频锚定可能把合理的全局演化也当成「漂移」压制掉——重复率上升正是这种张力的量化影子。交互式世界模型场景（用户中途改变环境）大概率需要「锚的更新/重置策略」，论文未讨论。

解读 · 读表时的口径注意

VBench 的 Subject/Background Consistency 对「褪色但静止」的视频并不敏感——基座 Self-Forcing 已经崩塌（120s OC 只剩 16.17），SC/BC 却仍有 97.02/96.29。所以这张表上真正拉开差距的是 Dynamic Degree、Overall Consistency 与定性对比；作者补充的 Repetitive Rate 也是为了堵住「静止/重复也能刷一致性」的口径漏洞。

解读 · 工程视角

对流式部署相当友好：每块只在前 2 个去噪步各多算一次「6 帧 K/V」的注意力，FFT 在 latent 分辨率上可忽略，KV 显存只多 6 帧的锚缓存；+16.5% 延迟对实时应用可接受。方法与训练类改进（LongLive、Self-Forcing++ 等）作用在不同层面，原则上可以叠加，论文未测试这种组合。

正文未报告 / 未说明

术语速览（8 条）
自回归 self-rollout
推理时逐块生成、以自己刚生成的内容为条件继续生成；Self-Forcing 把这一过程也搬进训练以消除训练-推理差距（exposure bias）。
KV 缓存 / 滑动窗口
因果注意力中缓存历史帧的 Key/Value 以免重算；固定容量、滚动淘汰最旧帧即「滑窗」。
Attention sink
永久保留在缓存最前端的少量初始 token/帧；最早在 LLM（StreamingLLM）中发现其对长序列稳定性至关重要。
DC 分量
频谱中频率为 0 的成分，即信号均值；对图像而言近似整体亮度/色调。
STFT
短时傅里叶变换：加窗滑动做 FFT，得到「频谱随时间变化」的曲线——本文用它当漂移探测器。
3D FFT（𝓕₃D）
沿空间两维 + 时间一维的快速傅里叶变换；作用于注意力输出张量。
RoPE
旋转位置编码，把相对位置写进 Q/K 的相位；只在训练见过的距离范围内可靠，超出即「外推伪影」。
VBench-Long
长视频生成基准，本文报告其中 7 项：动态度、运动平滑、总体一致性、成像质量、美学质量、主体一致性、背景一致性（均越高越好）。
